# 项目工作规则

## Git 提交规则

- **每次执行 git 提交前，必须先在聊天窗口展示待提交内容**，包括：
  - 待提交的文件清单（新增/修改/删除）
  - 拟定的 commit message
- **必须等待用户人工确认后，才能执行 `git commit`**
- 用户未明确确认前，不得自动提交

## 备份同步规则

- **每次执行 git 提交前，必须先把本次修改的文件同步到备份目录 `D:\git\python-quant\` 下对应的位置**（保持与仓库相同的相对路径结构）
- 同步范围 = 本次提交涉及的全部文件（新增/修改）；删除的文件需从备份目录对应位置一并移除
- 备份同步完成后，再按上述 Git 提交规则请用户确认并提交
