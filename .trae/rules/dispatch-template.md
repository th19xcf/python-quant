# 派单头模板

配套规则：`token-efficiency.md`（R1 引用化 / R5 预算与回报上限）。本文件只提供可直接复制的文本，不重复讲理由。

## A. 固定约束（每单原样贴这一段，不再逐条复写）

```text
固定约束按 .trae/rules/token-efficiency.md 与 .trae/rules/dispatch-template.md A 段执行，本单不再复写：
① 只读白名单以「本单」列出的目录/文件为界，越界停手先问；
② 开工前确认同一目标没有别的会话在跑（查 handoff / 台账 / 状态文件），不重复派；
③ 提交串行、备份仓同步按仓库惯例，提交后只回一句「提交成功 + 短哈希」；
④ 不贴 CSV、不贴大表正文、不贴完整参数表，明细落文件只给路径；
⑤ 回报 ≤5 行，且自带「本段调用数 + 本段耗时（分钟）」；
⑥ 60 次调用硬停：跑完手上命令即写 work/handoff.md 并回报，100 次绝对停止；
⑦ 同主题探查已有结论的，只引用结论文件，不重读原始表；
⑧ 大文件只 grep 定位后读命中行前后各 30 行，日志只读尾部 50 行；
⑨ 预算必须写死数字；核对 / 确认 / 复核 / 对拍 / 备份仓类任务预算 ≥10 次；实际调用达到预算 120% 立即硬停，只回「已用 X/N + 已完成 + 剩余步骤」，不得再试（R8 / R9）。
本单增量约束（至多三行，只写与上面不同的部分）：
- 
- 
```

## B. 30 秒最小派单样例（复制后替换尖括号内容）

```text
目标：<一句话说清可独立验收的产出>
预算：≤<30> 次调用 / 回报 ≤<5> 行 / 只读 <目录或文件清单>
落点：<文件:函数 / 表名>（先查 docs/代码地图.md，已给的不再自行遍历）
验收：<单一权威信号，如 行数对平 / 门禁通过 / 结论 JSON 字段齐全>
不可得说明：拿不到的数据写「不可得 + 证据」，不造数、不用占位值
```

### 最小样例（探源单，R4）

```text
目标：判定 <源接口> 能否按 <区间参数> 一次性取到 <指标>，不写入库
预算：≤10 次调用 / 回报 ≤3 行 / 只读 <接口文档或探针脚本>
落点：<探针脚本路径>，输出 <可得|不可得> + 证据（返回条数 / 首末日期）
验收：一条探针输出三个标量（条数、首日、末日），不产生入库文件
```

### 最小样例（执行单）

```text
目标：<表/模块/报告> 产出并落盘到 <路径>
预算：≤30 次调用 / 回报 ≤5 行 / 只读 <输入表 + 允许读的代码文件>
落点：<写入脚本:函数>、输入 <表名:关键列>、输出 <文件名>
验收：<行数守恒 / 对拍 1e-12 / 单测通过> 三项中指定一项
```
