# 文件命名规范（按需）

- **文档类一律中文命名**：文档、报告、基线、清单、证据类文件用中文文件名；需要区分版本时带 `_YYYY-MM-DD` 后缀，沿用仓库既有惯例。
- **代码与配置保持英文 snake_case**：代码文件、脚本入口、配置文件一律英文 snake_case，因为 import 路径、CLI 调用、测试发现与跨平台编码都依赖它。
- **数据表名沿用现状**：既有英文表名不改动；新建表名由任务书单独指定，不在本规则内自拟。
- **不追溯改名**：已有文件除用户点名外不做批量重命名，避免规则更新引发全仓改引用。
