# 研究纪律与停止清单（RD 系列）

> 来源：2026-11-22 研究侧统计纪律固化。适用于任何因子/信号/策略研究、评估报告与结论判定。

## RD-1 主判据用超额 DSR，不用 DSR

- 规则：任何因子/策略的显著性主判据必须是**超额收益序列的 DSR**（相对同期基准的超额），裸 DSR（绝对收益序列）只能作辅助。
- 原因：A 股 beta 与风格暴露会抬高绝对夏普，裸 DSR 会把市场收益误判为 alpha；只有超额序列剔除基准后才对应「是否真有 alpha」。
- 识别信号：报告里只有 `DSR` / `sharpe` 而没有 `excess_dsr`（或超额收益序列）→ 判为口径不合格，结论不得进入推荐。

## RD-2 任何信号研究必须带随机基线或安慰剂分布

- 规则：任何信号研究必须同时给出随机基线（随机信号 / 随机择时）或安慰剂分布（打乱标签、随机换仓日），并报告实际信号在分布中的分位。
- 原因：没有零分布就无法区分「信号有效」与「样本内多重尝试挑出来的极值」，这是 DSR 之外的第二道防过拟合闸门。
- 识别信号：报告只给单条净值 / IC、无随机分布、无 p 值或分位 → 判为证据不足。

## RD-3 三段样本外固定切分

- 规则：样本外一律固定切 `2010-01-01~2015-12-31` / `2016-01-01~2020-12-31` / `2021-01-01~2026-12-31`；任一段符号反转即判负；「三段同号但递减」不算通过。
- 原因：固定切分避免按结果挑切点；要求三段同号且不衰减，才能排除「早期有效、后期失效」的伪稳健。
- 识别信号：出现自定义切点、只跑单段样本外、或拿「三段同号但逐段递减」当通过 → 判为不合格。

## RD-5 工具口径

- 超额 DSR 与三段切分常量统一由 `src/backtest/performance/benchmark_eval.py` 提供（`deflated_sharpe_ratio` / `excess_deflated_sharpe` / `THREE_WAY_OOS_SPLITS`），评估报告复用，不得另写一套。

## RD-6 长持有期必须报独立窗口数与权重集中度

- 规则：任何持有期长于 20 日的研究，必须报**去重后的互不重叠窗口数**与单票权重 p95，不得只用「信号数」当样本量。
- 原因：重叠窗口让同一段行情被重复计数，样本量虚高数倍到上千倍，显著性检验随之失真。PEAD 60/120 日实测 46.7k 个事件，去重后独立窗口只有 63/33 个，样本量虚高约 740/1400 倍，导致聚类 t 与 NW-t 方向完全相反。
- 识别信号：报告只给事件数/信号数、无独立窗口数、无单票权重 p95，或持有期 >20 日仍按信号数算 t 值 → 判为样本量口径不合格，结论不得采信。

## RD-7 排除层 A/B 的抽样口径与传导验证（预注册，2026-11-22）

- **抽样同池**：排除层插入点固定在「评分之后、1.5N 缓冲带之前」；随机基线必须穿过同一条排除层。开/关对照只允许「是否排除」一个变量，不得同时改变池子大小。
- **三臂**：`off` / `hard-drop` / `half-weight`。必须报**右尾贡献度**（top-10 交易占总 P&L 比例）；缺此指标，Calmar 改善无解释力。
- **传导验证，不做显著性检验**：预测 `ΔE = −f̄ · Δμ_affected`，`f̄` 为受影响持仓的权重占比，`Δμ` 为事件层同口径条件收益差。必须报 `f̄` 时序、中位数与**绑定率**（`f̄<5%` 的期数占比）；先看绑定率，再谈收益。实现显著差于预测 → renormalization 或状态依赖；显著好于预测 → 集中度或运气，不得当发现。
- **融资余额诊断**：报每期排除率，检验组合 delta 符号是否随排除率升高而翻转；若翻转，只做杠杆扩张期状态开关，不做永久排除。该字段对所有排除规则复用。
- **面板前置门槛**：排除面板与人工抽查 200 个名字-日的错误率 ≥2% 时不得接线；REV5 必须统一复权口径（除权日不得造出假 -20% 进 Q1）；ATO 必须报「缺流通股本的名字-日占比」并说明低估方向；新股前 60 日、停牌、ST 单独标记，不混入同一阈值。
- **放行条件（四条全过才把默认从 off 改成 on）**：
  1. 事件层 20 日效应三段 `2010–15` / `2016–20` / `2021–26` 全正、无符号反转；
  2. 组合层对同池随机基线：Calmar 不降、最大回撤不恶化、可成交率不降（不要求年化上升）；
  3. `f̄` 中位数 ≥10%（否则不绑定，无法判定）；
  4. `half-weight` 臂不劣于 `hard-drop` 超过 1 个标准误。
  卡住时如实写明卡在哪条；卡住也是有效结论。
- **开关清单固定**：REV5 Q1、ATO Q5、融资余额增速（统一取五分位最高档 20%），叠加组为三者合并，之后不再变动。

## RD-8 数据层结论只引用定版（2026-11-22）

- **唯一来源**：数据是否收口、缺口是否补齐、体检是否健康，一律引用 `docs/数据收口定版_2026-11-22.md`，不重新论证、不重跑核对、不在报告里复述推导。历史文档只作过程记录。
- **允许重开的两种情形**（其余一律回「见定版」）：
  1. **源端出现新证据**：必须有可复现的原始返回文件，含「接口名 + 请求参数 + 返回摘要（行数 / 关键字段值 / 日期范围）」，且与定版 §4 的证据**直接矛盾**。典型形式：`logs/<run>/` 或 `_staging/<run>/` 下的 json/csv；例如 `new_share` 返回 `price>0`、`daily` 返回本次未覆盖的日期区间、交易所公告证明某行本可交易。只有截图、口头转述、"听说源端有了"不算。
  2. **体检/一致性核对回退**：按定版 §2 跑出 异常>0 或 告警>0 或 健康<47；或 ledger 的 rows/max_date/sha256 与磁盘不符；或 manifest 分区数/行数不符；或 freshness 超阈值；或**治理项回退**——`[体检] 未登记写数据脚本` 非空、裸写清单 `差 +N`（delta>0）。治理项不计入 0/0/47，但同样算回退：退出码只覆盖"异常 + 未登记脚本"，裸写 delta 需读体检输出，不能只看退出码。
- **禁止**：凭印象、凭旧文档数字、凭"再确认一下"重开；重开必须写明触发项（1/2）、证据文件路径、与定版哪一条冲突，三者缺一不得开工。

## RD-9 财务类数据参与的报告必须标注三件事（2026-11-22）

凡报告中用到财务因子（EP/BP/ROE/SUE 等）或年报类数据，数据说明或因子表注必须同时写明：

1. **是否中性化**：行业/市值中性化与否；未中性化须写明正负暴露方向。
2. **PIT 延迟**：给出 `ann_date − end_date` 的实际天数（中位/p90），或写 **"不可证"**——财务三表无版本快照时一律写"不可证"并引 G-072，不得用"已按公告日对齐"代替。
3. **财务快照时间**：写 `fin_snapshot`（当前 `2026-11`），标明数值取自哪次全量快照，跨快照比较须重述。

缺任一项，报告视为信息不完整，不得进入结论评审。

## RD-10 样本外冻结与前向记录

- 规则：
  - **冻结**：EP 主导的低估值月频横截面（当前唯一保留体系）参数已冻结，逐项取值与来源见 `work/oos_forward/frozen_spec.json`（股票池、排序口径、持仓只数 n=30、月频 T+1、0.13% 往返、中性化方式、基准 5.80%、PIT、窗口 2010-01-04~2026-11-20）。冻结后除修 bug 外不得改参。
  - **前向记录**：自 2026-12 起只记录不优化。每月末把当期标的、权重写入 `work/oos_forward/records.csv`，次月末回填实际收益、同口径基准收益与差值；字段固定为 `date,ts_code,weight,actual_return,benchmark_return,diff`。记录期不得回头调参。
  - **解冻门槛**：连续 12 个月 `diff` 月均值同号且 Newey-West(lag=3) `|t| >= 2.0`，且累计记录 ≥24 个月；或发现数据/代码 bug（修后保留旧记录并留变更说明）。解冻后只重估一次，随即重新冻结并清零记录。
  - **外部数字核实**：外部评审「全市场 PB 分位 >80% 减半仓位，回撤 −64%→−48%」在仓库内**无出处、不得引用**。本地唯一相关结果是 510880 红利 ETF 的 000015.SH PB 60 月分位择时（8.97% / −26.1% / 0.566，2009-11~2011-12 为代理段，弱证据）；−64.35% 是全 A 等权权威基准的最大回撤，并非择时前后对照。
- 原因：回溯内反复调参会把样本外变成样本内；只有先冻结、再按固定字段记录真实前向表现，才能得到真正的样本外证据。
- 识别信号：报告声称「样本外」却无冻结日期/参数清单、记录目录缺失或字段随月变化、用回溯分段冒充样本外 → 判为口径不合格。
