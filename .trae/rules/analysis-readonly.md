# 分析与回测任务只读边界（按需）

- **只读消费侧**：分析、回测、基线校准类任务默认不改引擎语义、不改数据文件、不改成本参数默认值；只读既有引擎与正式数据，产出净值/指标/报告。
- **确需改引擎或数据先停手**：先报「缺什么能力 / 最小改动方案 / 影响面（下游表、历史结果、回测口径）」，由主控决定，不由该分析任务自行实施。
- **改动必须单独成单**：引擎或数据改动由一个独立子任务显性完成，任务名里写明是「改引擎」或「改数据」，与分析任务不共用一条会话。
- **改完先跑基线对比**：改动完成必须跑一次基线或既有回归对比，证明历史段结果未被带动，才允许回到分析任务继续。
- **diff 判定越界**：分析任务提交的 diff 中出现 `src/backtest/**`、`src/data/**` 或成本默认值变更，即判越界，理由不豁免。
