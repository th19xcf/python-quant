## 任务：修复个股行情只显示1条数据的问题

### 问题原因
代码第416-420行使用 `latest_date` 统一过滤，导致只有最新日期的股票被显示。

### 解决方案（方案2）
删除统一日期过滤逻辑，让每只股票都显示各自的最新数据。

### 修改文件
`src/ui/main_window_data_mixin.py`

### 具体修改

**删除/注释掉以下代码（第416-420行）：**
```python
# 过滤出最新交易日的数据
if latest_date:
    latest_date_str = latest_date.strftime('%Y-%m-%d')
    all_stock_data = [item for item in all_stock_data if item['date'] == latest_date_str]
    logger.info(f"最新交易日: {latest_date_str}，共{len(all_stock_data)}只{stock_type}股票有数据")
```

**同时需要删除或修改相关的 `latest_date` 更新逻辑（第321-323行）：**
```python
# 更新最新日期
if latest_date is None or date > latest_date:
    latest_date = date
```

### 修改后的效果
- 每只股票读取各自的最新记录
- 不统一按日期过滤
- 显示所有符合条件的股票，而不是只有最新日期的股票
