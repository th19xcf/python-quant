# 插件间标准通信方式设计方案

## 1. 设计目标

建立插件间的标准通信方式，支持插件之间的消息传递、事件驱动和直接调用，实现插件间的无缝协作。

## 2. 现有基础

项目已基于blinker库实现了EventBus类，提供了事件发布和订阅机制。目前已定义了系统事件、数据事件、技术分析事件、策略事件和UI事件。

## 3. 通信方式设计

### 3.1 事件驱动通信

**扩展现有事件总线，添加插件间通信专用事件：**

| 事件名称              | 描述       | 事件参数                                                               |
| ----------------- | -------- | ------------------------------------------------------------------ |
| `plugin_message`  | 插件间消息传递  | `sender`, `recipient`, `message_type`, `data`, `priority`          |
| `plugin_request`  | 插件间请求-响应 | `sender`, `recipient`, `request_id`, `method`, `params`, `timeout` |
| `plugin_response` | 插件间响应    | `sender`, `recipient`, `request_id`, `result`, `error`             |
| `plugin_event`    | 插件自定义事件  | `sender`, `event_name`, `data`                                     |

### 3.2 消息格式标准

**统一消息格式：**

```python
# 基础消息结构
message = {
    'version': '1.0',  # 消息版本
    'timestamp': 1234567890,  # 时间戳
    'sender': 'plugin_name',  # 发送者插件名
    'recipient': 'target_plugin',  # 接收者插件名，'*'表示广播
    'message_type': 'data',  # 消息类型：data, request, response, event
    'data': {},  # 消息内容
    'priority': 0,  # 优先级：0-9，0最高
    'correlation_id': 'uuid',  # 关联ID，用于请求-响应配对
    'metadata': {}  # 附加元数据
}
```

### 3.3 通信接口设计

**扩展PluginBase类，添加通信方法：**

| 方法名                  | 描述        | 参数                                                | 返回值  |
| -------------------- | --------- | ------------------------------------------------- | ---- |
| `send_message`       | 发送消息给指定插件 | `recipient`, `message_type`, `data`, `priority=0` | 消息ID |
| `broadcast_message`  | 广播消息给所有插件 | `message_type`, `data`, `priority=0`              | 消息ID |
| `send_request`       | 发送请求并等待响应 | `recipient`, `method`, `params`, `timeout=5`      | 响应结果 |
| `send_async_request` | 异步发送请求    | `recipient`, `method`, `params`, `callback=None`  | 请求ID |
| `publish_event`      | 发布自定义事件   | `event_name`, `data`                              | 事件ID |
| `subscribe_event`    | 订阅自定义事件   | `event_name`, `handler`, `sender=None`            | 订阅ID |
| `unsubscribe_event`  | 取消订阅事件    | `event_name`, `handler`                           | bool |

### 3.4 直接调用机制

**添加插件间直接调用接口：**

| 方法名                   | 描述         | 参数                                                | 返回值       |
| --------------------- | ---------- | ------------------------------------------------- | --------- |
| `call_plugin_method`  | 直接调用其他插件方法 | `plugin_name`, `method_name`, `*args`, `**kwargs` | 方法返回值     |
| `get_plugin_instance` | 获取插件实例     | `plugin_name`                                     | 插件实例或None |

### 3.5 通信监控

**添加通信监控和调试功能：**

| 功能    | 描述            | 实现方式              |
| ----- | ------------- | ----------------- |
| 通信日志  | 记录所有插件间通信     | 扩展EventBus，添加日志记录 |
| 通信统计  | 统计插件间通信次数、延迟等 | 添加通信统计模块          |
| 通信可视化 | 可视化插件间通信关系    | 实现通信图生成功能         |
| 调试模式  | 开启详细通信日志      | 添加调试开关            |

## 5. 使用示例

### 5.1 事件驱动通信示例

**发送消息：**

```python
# 插件A发送消息给插件B
self.send_message('PluginB', 'data', {'key': 'value'})

# 广播消息
self.broadcast_message('data_update', {'symbol': '600000.SH', 'price': 10.0})
```

**接收消息：**

```python
# 在插件初始化中订阅消息
def on_message_received(message):
    if message['message_type'] == 'data':
        print(f"收到数据: {message['data']}")

self.subscribe_event('plugin_message', on_message_received)
```

### 5.2 请求-响应通信示例

**发送请求：**

```python
# 同步请求
result = self.send_request('PluginB', 'calculate_indicator', {'symbol': '600000.SH', 'indicator': 'MACD'})

# 异步请求
def on_response(result, error):
    if error:
        print(f"请求错误: {error}")
    else:
        print(f"请求结果: {result}")

self.send_async_request('PluginB', 'calculate_indicator', {'symbol': '600000.SH', 'indicator': 'MACD'}, on_response)
```

**处理请求：**

```python
# 实现请求处理方法
def handle_request(request):
    if request['method'] == 'calculate_indicator':
        # 处理计算请求
        return self.calculate_indicator(request['params']['symbol'], request['params']['indicator'])
    return None

# 注册请求处理器
def on_plugin_request(request):
    result = self.handle_request(request)
    return result

self.subscribe_event('plugin_request', on_plugin_request)
```

### 5.3 直接调用示例

**直接调用插件方法：**

```python
# 获取插件实例
plugin_b = self.get_plugin_instance('PluginB')
if plugin_b:
    # 直接调用方法
    result = plugin_b.calculate_indicator('600000.SH', 'MACD')

# 或使用简化接口
result = self.call_plugin_method('PluginB', 'calculate_indicator', '600000.SH', 'MACD')
```

## 6. 预期效果

1. **统一通信标准**：所有插件使用相同的通信方式，降低插件开发复杂度
2. **灵活的通信模式**：支持事件驱动、请求-响应和直接调用三种模式
3. **可靠的消息传递**：支持消息优先级、超时处理和错误重试
4. **易于扩展**：新插件可以无缝集成到通信系统中
5. **良好的可监控性**：提供通信日志、统计和可视化功能
6. **向后兼容**：兼容现有代码，不影响现有功能
