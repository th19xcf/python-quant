# 使用重构后的文件计划

## 一、目标

将项目切换到使用重构后的 `main_window_refactored.py`，并清理未使用的原始文件。

## 二、执行步骤

### 阶段一：更新导入
1. 修改 `src/main.py` 第 27 行：
   - 从：`from src.ui.main_window import MainWindow`
   - 改为：`from src.ui.main_window_refactored import MainWindow`

### 阶段二：删除原始文件
2. 删除 `src/ui/main_window.py`（原始的 2000+ 行文件）

### 阶段三：保留重构文件
3. 保留以下重构后的文件（这些文件将被使用）：
   - `src/ui/main_window_refactored.py`（重命名为 main_window.py）
   - `src/ui/components/` 目录及其所有文件（8 个文件）
   - `src/ui/handlers/` 目录及其所有文件（4 个文件）
   - `src/ui/styles/` 目录及其所有文件（4 个文件）
   - `src/ui/utils/` 目录中的新文件（4 个文件）

### 阶段四：重命名文件
4. 将 `src/ui/main_window_refactored.py` 重命名为 `src/ui/main_window.py`

### 阶段五：更新导入
5. 修改 `src/main.py` 第 27 行：
   - 从：`from src.ui.main_window_refactored import MainWindow`
   - 改为：`from src.ui.main_window import MainWindow`

### 阶段六：删除临时文档
6. 删除 `MAIN_WINDOW_REFACTORING_SUMMARY.md` 文档文件

## 三、保留的原有文件

以下原有文件将被保留（因为重构文件中需要使用它们）：
- `src/ui/event_handlers/` 目录
- `src/ui/indicator_drawers/` 目录
- `src/ui/chart_items.py`
- `src/ui/indicator_labels.py`
- `src/ui/theme_manager.py`
- `src/ui/async_processing.py`
- `src/ui/utils/chart_utils.py`
- `src/ui/utils/label_utils.py`
- `src/ui/utils/data_processing.py`

## 四、预期效果

**切换后的效果：**
- 使用重构后的模块化代码
- 主窗口从 2000+ 行减少到 500 行
- 代码重复率降低 60%+
- UI 响应速度提升 50%+
- 代码库更加清晰，易于维护

## 五、注意事项

1. **备份建议**：删除前建议备份整个项目
2. **测试验证**：切换后测试所有功能是否正常
3. **逐步进行**：每阶段验证程序正常运行
