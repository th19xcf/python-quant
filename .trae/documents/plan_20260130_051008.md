## 在虚拟环境中运行量化分析系统

### 执行步骤：

1. **激活虚拟环境**

   * 执行：`venv\Scripts\activate`

   * 确保使用项目配置的 Python 环境

2. **运行主程序**

   * 执行：`python -m src.main`

   * 启动中国股市量化分析系统

   * 程序将打开 PySide6 GUI 窗口

3. **监控运行状态**

   * 观察启动日志输出

   * 检查是否有错误或警告

   * 验证插件加载情况

   * 确认数据库连接状态

4. **测试基本功能**（如程序成功启动）

   * 查看主窗口是否正常显示

   * 检查数据管理器初始化

   * 验证插件系统工作状态

### 注意事项：

* 这是一个 GUI 应用程序，运行后会打开窗口

* 程序会持续运行直到手动关闭窗口

* 如果遇到错误，会显示详细的错误信息用于调试
