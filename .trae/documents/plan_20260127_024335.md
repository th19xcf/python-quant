# main\_window\.py 文件拆分优化计划

## 一、目标

将 2000+ 行的 main\_window\.py 拆分为多个模块，提高代码可维护性、可读性和可测试性。

## 二、新的目录结构

```
src/ui/
├── main_window.py              # 主窗口类（简化到 500 行以内）
├── components/
│   ├── __init__.py
│   ├── market_tab.py          # 行情标签页（400 行）
│   ├── tech_tab.py            # 技术分析标签页（500 行）
│   ├── finance_tab.py         # 财务分析标签页（50 行）
│   ├── navigation_panel.py     # 左侧导航栏（150 行）
│   ├── chart_container.py     # 图表容器（400 行）
│   ├── indicator_panel.py     # 指标选择面板（300 行）
│   └── status_bar.py         # 状态栏（100 行）
├── styles/
│   ├── __init__.py
│   ├── dark_theme.qss         # 深色主题样式
│   ├── light_theme.qss        # 浅色主题样式
│   └── theme_constants.py      # 样式常量
├── utils/
│   ├── __init__.py
│   ├── table_helper.py       # 表格操作工具（200 行）
│   ├── color_helper.py       # 颜色设置工具（150 行）
│   └── data_formatter.py     # 数据格式化工具（100 行）
└── handlers/
    ├── data_loader.py        # 数据加载处理器（300 行）
    ├── chart_manager.py       # 图表管理器（400 行）
    └── menu_manager.py       # 菜单管理器（200 行）
```

## 三、拆分策略

### 阶段一：创建基础结构（准备阶段）

1. 创建新的目录结构
2. 创建 `__init__.py` 文件
3. 创建样式常量文件 `theme_constants.py`

### 阶段二：提取工具类（工具层）

1. **table\_helper.py**：提取表格操作方法

   * `set_table_item_with_style()`：设置带样式的单元格

   * `create_table_row()`：创建表格行

   * `apply_color_rules()`：应用颜色规则

2. **color\_helper.py**：提取颜色设置逻辑

   * `get_price_color()`：根据涨跌获取颜色

   * `get_change_color()`：根据涨跌幅获取颜色

   * `get_foreground_color()`：获取前景色

3. **data\_formatter.py**：提取数据格式化方法

   * `format_price()`：格式化价格

   * `format_volume()`：格式化成交量

   * `format_percentage()`：格式化百分比

### 阶段三：提取 UI 组件（组件层）

1. **market\_tab.py**：提取行情标签页（第 647-717 行）

   * `create_market_tab()`：创建行情标签页

   * `add_sample_stock_data()`：添加示例数据

   * `setup_table_style()`：设置表格样式

2. **tech\_tab.py**：提取技术分析标签页（第 802-1013 行）

   * `create_tech_tab()`：创建技术分析标签页

   * `create_chart_widgets()`：创建图表组件

   * `setup_chart_layout()`：设置图表布局

3. **navigation\_panel.py**：提取导航栏（第 561-614 行）

   * `create_navigation_panel()`：创建导航面板

   * `add_nav_item()`：添加导航项

   * `setup_nav_tree()`：设置导航树

4. **chart\_container.py**：提取图表容器（第 950-1004 行）

   * `create_chart_container()`：创建图表容器

   * `setup_chart_splitter()`：设置分割器

   * `manage_chart_visibility()`：管理图表可见性

5. **indicator\_panel.py**：提取指标面板（第 1054-1221 行）

   * `create_indicator_panel()`：创建指标面板

   * `create_indicator_buttons()`：创建指标按钮

   * `setup_scroll_area()`：设置滚动区域

6. **status\_bar.py**：提取状态栏（第 1613-1638 行）

   * `create_status_bar()`：创建状态栏

   * `update_market_info()`：更新市场信息

   * `update_time_info()`：更新时间信息

### 阶段四：提取处理器（业务层）

1. **data\_loader.py**：提取数据加载逻辑（第 1646-2056 行）

   * `load_index_data()`：加载指数数据

   * `parse_tdx_file()`：解析通达信文件

   * `calculate_change()`：计算涨跌幅

2. **chart\_manager.py**：提取图表管理逻辑（第 2600-4640 行）

   * `plot_k_line()`：绘制 K 线

   * `update_chart_data()`：更新图表数据

   * `handle_chart_events()`：处理图表事件

3. **menu\_manager.py**：提取菜单管理逻辑（第 432-498 行）

   * `create_menu_bar()`：创建菜单栏

   * `add_menu_actions()`：添加菜单动作

   * `handle_menu_events()`：处理菜单事件

### 阶段五：创建样式文件（样式层）

1. **dark\_theme.qss**：深色主题样式

   * 表格样式

   * 按钮样式

   * 图表样式

2. **light\_theme.qss**：浅色主题样式

   * 表格样式

   * 按钮样式

   * 图表样式

3. **theme\_constants.py**：样式常量

   * 颜色常量

   * 尺寸常量

   * 字体常量

### 阶段六：重构主窗口（核心层）

1. **简化 main\_window\.py**：只保留核心逻辑

   * 初始化和协调

   * 事件订阅和发布

   * 组件组装

2. **实现接口方法**：完成 IView 和 IController 接口

   * `update_chart()`：更新图表

   * `show_message()`：显示消息

   * `update_progress()`：更新进度

3. **清理调试代码**：移除所有 print 语句

   * 替换为 logger

   * 添加日志级别控制

### 阶段七：优化和测试

1. **性能优化**

   * 使用异步数据加载

   * 实现数据缓存

   * 优化表格操作

2. **代码质量优化**

   * 添加类型注解

   * 完善文档注释

   * 统一命名规范

3. **测试**

   * 单元测试

   * 集成测试

   * UI 测试
