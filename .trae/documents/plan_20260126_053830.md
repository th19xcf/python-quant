# main_window.py 文件拆分优化计划

## 一、目标
将 2000+ 行的 main_window.py 拆分为多个职责清晰的模块，提升代码可维护性、可读性和可测试性。

## 二、新的目录结构

```
src/ui/
├── main_window.py              # 主窗口类（简化到 300-400 行）
├── components/                # UI 组件模块（新建）
│   ├── __init__.py
│   ├── market_tab.py          # 行情标签页组件
│   ├── tech_tab.py            # 技术分析标签页组件
│   ├── finance_tab.py         # 财务分析标签页组件
│   ├── navigation_panel.py     # 左侧导航栏组件
│   ├── chart_container.py     # 图表容器组件
│   ├── indicator_panel.py     # 指标选择面板组件
│   ├── status_bar.py         # 状态栏组件
│   └── tool_bar.py          # 工具栏组件
├── styles/                   # 样式文件（新建）
│   ├── __init__.py
│   ├── dark_theme.qss         # 深色主题样式
│   └── common.qss            # 通用样式
├── utils/                    # UI 工具类（新建）
│   ├── __init__.py
│   ├── table_helper.py       # 表格操作工具
│   ├── color_helper.py       # 颜色设置工具
│   ├── style_helper.py       # 样式应用工具
│   └── constants.py         # UI 常量定义
└── handlers/                 # 事件处理器（已有，需扩展）
    ├── __init__.py
    ├── data_handler.py        # 数据加载事件处理
    ├── chart_handler.py       # 图表事件处理
    ├── menu_handler.py        # 菜单事件处理
    └── window_handler.py      # 窗口管理事件处理
```

## 四、关键优化点

### 1. 消除重复代码
- **颜色设置重复**：提取到 `color_helper.py`
- **样式字符串重复**：提取到 QSS 文件
- **表格操作重复**：提取到 `table_helper.py`
- **按钮创建重复**：提取到工厂方法

### 2. 遵循分层架构
- **UI 层**：只负责显示和交互
- **数据层**：通过 DataManager 访问数据
- **业务层**：业务逻辑提取到服务类
- **事件层**：通过事件总线通信

### 3. 提升代码质量
- **类型注解**：添加类型提示
- **文档注释**：完善 docstring
- **命名规范**：统一命名风格
- **异常处理**：完善错误处理

### 4. 性能优化
- **异步加载**：使用 DataReadThread
- **数据缓存**：实现缓存机制
- **懒加载**：按需加载组件
- **批量操作**：优化表格和图表操作
