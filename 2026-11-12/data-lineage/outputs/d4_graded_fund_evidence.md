## 1. 判据（本轮新立，逐条可复算）

### 1.1 三个量的定义

| 量 | 定义 | 数据来源 | 是否独立 |
|---|---|---|---|
| **价格隐含步长** `step` | `qfq(t) / qfq(t-1)` | `factors/fund_adj_factor.parquet` | 是（唯一未用事件表的量，但受 §8 缺陷影响） |
| **因子隐含参考价** `ref = cprev / step` | `cprev` = 前一交易日原始 `close` | `quotes/fund/**` 原始列 | 是（原始价，非派生） |
| **akshare 隐含参考价** `ref_ak` | 有拆分比例：`cprev / share_ratio`；只有现金分红：`cprev - cash` | `factors/fund_share_change.parquet` / `fund_dividend.parquet` | **否**（见 §3，它与 `step` 是同一个数） |
| **TDX 除权参考价** | `gbbq` category=1 的除权除息记录反算 | `H:\zxzq\T0002\hq_cache\gbbq` | 是（第三方，但覆盖近零，§2） |

### 1.2 价格可行带

独立价格证据 = 通达信 `.day` 原始 OHLC（`parse_day_file`，**不经**本地行情表的 `pre_close` / `pct_chg`）。设当日涨跌幅限制 ±10%，则交易所除权参考价必落在

```
band_lo = high / 1.1        band_hi = low / 0.9
```

上界由「最低价不低于参考价 −10%」定，下界由「最高价不高于参考价 +10%」定。带宽度 `= (low/0.9)/(high/1.1) − 1`，日内振幅越大带越窄、鉴别力越强。

### 1.3 五分类与裁定规则

| verdict | 条件 | 裁定 |
|---|---|---|
| `仅因子步长在带内` | `ref ∈ band`，`ref_ak ∉ band` | 因子对、事件记录错 |
| `仅akshare在带内` | `ref_ak ∈ band`，`ref ∉ band` | 事件记录对、因子错 |
| `两者均在带内(不可区分)` | 两者都在带内 | 价格证据**不能**在两者间二选一，只能整体证实 |
| `两者均越界(需公告原文)` | 两者都不在带内 | 两者都不被价格支持，必须取第三源（公告原文） |
| `akshare无对应事件` | akshare 无该行记录 | 只说明外部源没这一行；**不能**推出「本地事件表缺登记」（§13 复核：50/50 本地均有登记） |

### 1.4 为什么不用 `pre_close` 当基准

行情 `pre_close` 是**因子派生列**：`src/data/local_store/store.py` 的 `_recompute_derived_columns` 按 `pre_close = close.shift(1) * qfq.shift(1)/qfq` 重算。用它检验 `qfq` 等于用 `qfq` 检验 `qfq`。这与「残差归零」判据作废（§7）是同一个错误，本文全部改用通达信原始 OHLC。

## 3. 结构性事实一：两个候选退化成一个

`b2s2_d4_evidence.json` → `summary.per_code_digest` 与逐事件表：

- 71 个事件在 `fund_share_change` 里有拆分比例；
- **71 / 71 满足 `|step − share_ratio| < 1e-6`**（不是近似，是逐值相等）；
- 抽 3 个：

| 标的 / 日期 | `step`（因子） | `ak_ratio`（事件表） | 相等 |
|---|---|---|---|
| `150022.SZ` 2011-01-06 | 1.0091 | 1.0091 | 是 |
| `150022.SZ` 2012-01-06 | 1.0556 | 1.0556 | 是 |
| `150172.SZ` 2018-10-18 | 0.2343 | 0.2343 | 是 |

**推论（必须写进裁定依据）**：对分级码，因子构建就是直接取用 akshare 的份额分拆比例（`calc_dividend_event_factor` 的 `share_div` 分支），不存在「因子用价格隐含、事件表用事件隐含」的两套独立口径。所以：

- 「事件记录与 TDX 除权参考价谁对」这个问题，在分级码上要改成「**这一对相同的值**是否被价格支持」；
- 「仅因子在带内」「仅 akshare 在带内」两类计数**必然是 0**（实测 0 / 0），任何报告里出现这两类非零即说明跑了另一套口径。

## 7. 旧判据「残差归零」作废：循环论证的完整说明

### 7.1 旧判据做了什么

旧判据：用 `fund_adj_factor` 重建除权参考价，再与行情表的 `pre_close` 比，残差应为 0。

### 7.2 为什么是循环论证

`pre_close` **不是独立数据**：`src/data/local_store/store.py` 的 `_recompute_derived_columns` 明确按

```
pre_close(t) = close(t-1) × qfq(t-1) / qfq(t)
```

重算。把它代回旧判据的残差式，`qfq` 在分子分母里**同时出现并相互抵消**——残差恒为 0 与数据对不对无关，只与「两列是不是同一次运行写出来的」有关。这正是 `docs/adj_factor独立源对拍_2026-11-11.md` §14.1 已记录过的问题。

更具体地说，旧判据的基准**取自同一批事件表**：`qfq` 是事件表的产物，`pre_close` 又是 `qfq` 的产物，拿后者检验前者，等于「用被解释变量检验解释变量」。

### 7.3 实测反证

若旧判据有效，则它在任何一次事件表改动后都应给出 0 残差；实测本轮 P0 重跑后残差「归零」而 406 日 / 229 只的独立基准不一致依然存在——两者同时成立，只能说明残差归零**没有鉴别力**。

### 7.4 替代判据

以通达信 `.day` 原始 OHLC 为独立基准、按 §1.2 可行带检验（旧表 406 日 / 229 只 == 新表 406 日 / 229 只、逐日明细相同）。该判据：
- 基准不含 `qfq`，不循环；
- 对 3.7~9.5 倍的大比例折算仍有鉴别力（§5.3）；
- 明确标注失效区间（单笔日 191 行、`gbbq` 零覆盖 121/122 事件、`.day` 停牌后无价格）。

**登记去向**：`docs/数据缺口登记_正式表_2026-11-12.md` G-122。

## 8. 新增发现：`qfq` / `hfq` 在 221 只上不自洽（影响判据本身）

### 8.1 应有关系

`src/data/adj_factor_calculator.py` 的口径是
`qfq(t) = prod{f_e | e > t}`、`hfq(t) = qfq(t) / prod{全部 f}`，
因此同一标的 `qfq(t)/hfq(t)` **必须恒定**。

### 8.2 实测

| 口径 | 数字 |
|---|---|
| 全表标的数 | 2,620 |
| `qfq/hfq` 不恒定 | **221** |
| 其中 `150xxx` | **180 / 218** |
| 其中 `502xxx` | **22 / 36** |
| 对照组：`510300.SH` / `159915.SZ` / `502003.SH` | 恒定（极差 0） |

### 8.3 具体反例

`150022.SZ`：

| 日期 | `qfq` | `hfq` | `qfq` 步长 | `hfq` 步长 |
|---|---|---|---|---|
| 2019-12-31 | 1.000000 | 1.471195 | 1.0 | 1.0 |
| 2020-01-06 | 1.000000 | 1.287454 | **1.0** | **0.875108** |

### 8.4 对本文结论的影响（必须一起读）

1. **事件日是从 `qfq` 步长定义的**，`qfq` 漏了事件 → 该事件根本不会进入 122 个抽样事件、也不会进入 175 事件 / 125 只的残差统计。所以 **122 是下界，175 也是下界**。

## 13. 复核纠正：42 条「事件表缺登记」不成立（2026-11-13）

### 13.1 原判定为什么错

§0 结论 4 与 §9 动作 1 曾把 50 个 `verdict = akshare无对应事件` 里落在带内的 42 个判为「本地事件表缺登记、因子步长对」。复核发现两处口径错误：

| # | 错误 | 事实 |
|---|---|---|
| 1 | 用 **±3 自然日**窗口匹配事件的 `ex_date`，命中即算「有记录」 | 事件表的 `ex_date` 是**公告折算日**，因子台阶落在**生效交易日**，两者按 `src/data/local_store/fund_factors.py` 的 `_next_trade_date` 对齐；遇到停牌/长假，间隔可达 4 个自然日以上，落在窗口外就被误判为「无记录」 |
| 2 | 把「akshare 无该行」等同于「本地 `fund_share_change` 无该行」 | 前者为真（akshare 源确实没有），后者为假（本地事件表有） |

### 13.2 复核方法与结果

判据改为「该台阶是否已被某条既有事件解释」：对每个候选事件日 `T`，取同标的所有 `ex_date ≤ T` 且 `T - ex_date ≤ 40 天` 的既有事件，计算 `_next_trade_date(trade_dates, ex_date)`，等于 `T` 即判定「已有登记」，并核对 `share_ratio` 与因子 `step` 是否逐值相等。

| 指标 | 值 |
|---|---|
| 候选（`akshare无对应事件`） | 50 |
| 被既有事件解释 | **50 / 50** |
| `share_ratio` 与 `step` 最大绝对差 | **0.0**（50 条全部 < 1e-9） |
| 真实缺登记 | **0** |

### 13.3 结论与处置

- **42 条（乃至 50 条）一条都不用补**。补进去会与既有事件在同一生效日形成重复事件，重算因子时会二次折算。
- 本轮**未向 `fund_share_change.parquet` 写入任何行**：写前断言即命中重号并中止，落盘脚本 `2026-11-12/data-lineage/work/b2s2_apply_share_change.py` 停在 `assert`；文件保持 2,738 行、`source` 中 `price_implied` 计数 0、字节数 19,631、SHA256 前缀 `07DC30C1…`。
- 关联登记：`docs/数据缺口登记_正式表_2026-11-12.md` **G-127**（K 类，本条误判已入册，供后续复用判据时避开）。

## 15. 判定规则：份额折算比例 ≠ 价格调整比例

### 15.1 规则正文

1. **分级基金（定折 / 下折）的折算比例由「折算基准日基金份额净值」决定，与二级市场成交价没有固定倍数关系**。折算完成后价格向新净值（定折多为 1.000 元）回归，成交价变动里同时含「折算」与「折价/溢价修复」两部分，因此价格隐含比例不是折算比例的估计量。
2. **比例的唯一合法来源**：① 公告原文的「折算比例」字段（精确到小数点后 9 位）；② 基金份额净值。两者都没有 → 登记 `unresolved`，**禁止**用价格反推比例写事件表。
3. **价格证据的适用范围**：只能回答「当日是否发生了权益变动」这一定性问题（有无台阶），不能回答「比例是多少」这一定量问题。
4. **单笔日（`low == high`）连定性都不可用**：可行带宽度固定 22.2%，任何比例都能落进去，必须单独标注、不参与比例裁定。
5. **本文 18 条的走势完全符合该规则**：`150022` 四条价格隐含比例 0.878~0.981，而折算比例 1.045~1.114（方向相反）；下折四条价格隐含 0.271~0.353，折算比例 0.105~0.234（差 3.3~4.6 倍）。这类偏差不构成「因子错」的证据。
