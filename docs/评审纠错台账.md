## 使用说明

1. 同源评审报告先按「断言关键词」查本表，命中即引用本表判定，不再重复实测。
2. 本表只登记**已被推翻或改判**的条目；复核仍成立的问题不收录，避免与问题清单混淆。
3. 新增条目须满足：有明确证据（`文件:行` 或 `docs/`、`work/` 报告路径），且能定位到修复提交；无证据不登记。
4. `_staging/`、`_backup/` 下的历史快照不作为当前 HEAD 证据（第 8、3 条即因引用旧快照而误判）。
