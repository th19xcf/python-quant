# 多指标共振择时 v2 回测结果（2026-11-20）

## 0. 结论

**不可用。**

三条判据同时成立：① 口径仍未修好——「震荡低吸 / 震荡高抛」两行在 11 个标的、12 年样本里最终触发 0 次，
按本轮验收第 6 条属于「口径仍有不可达动作」；② 绩效全面劣于 v1：年化 -0.20%（v1 +0.41%）、
最大回撤 28.58%（v1 11.23%）、夏普 0.049（v1 0.13），换手从 19% 升到 274%/年；③ 把信号整体再延迟 1 天
反而略好（年化 +0.01%、夏普 0.07、回撤 27.65%），说明 v2 没有可提取的择时边际。

v2 只在「结构」上修好了两项：三维度不再互相蕴含（P 条件概率全部 <1），买卖信号数量从 28:218 拉平到
2083:1909；但代价是把低吸/高抛之外的所有规则都放得极宽，交易从 51 笔涨到 670 笔，结果更差。

## 1. v1 四个结构问题：v2 的处置与证据

| # | v1 问题 | v1 证据 | v2 处置 | v2 证据 | 是否修好 |
|---|---|---|---|---|---|
| 1 | 条件 A 冗余（「低位金叉」已含金叉） | A 在 C 成立时恒真，实际等于 B AND C | 拆成 D1 方向 / D2 位置 / D3 动能，D1 与 D2 互不蕴含 | P(D2|D1)=0.76、P(D3|D1)=0.41、P(D1|D3)=0.31，无任何条件概率=1 | 是 |
| 2 | 同日 AND 太严导致买入消失 | 买入 28 次 vs 卖出 218 次（1:7.8） | D1/D3 放宽为「近 3 日内曾成立」 | 买入 2083 vs 卖出 1909（1.09:1），成交 51→670 笔 | 是（但过校正） |
| 3 | 五行动作三行不可达 | 低吸 / 高抛 / 持股 = 0 / 0 / 0 | 低吸高抛改近 5 日 RSI 极值 + 近 3 日交叉；持股去掉「死叉不破位」 | 持股 9126 次，低吸 0、高抛 0 | **否（2/5 仍为 0）** |
| 4 | 卖出过松（拐头单独即可） | 卖出/买入 = 7.8 倍，平均仓位 12.1% | 卖出共振必须 D1 与 D3 同时具备且当日 DIF>0 | 卖出 1909 ≈ 买入 2083，平均仓位 52.7% | 是 |

不可达的两行已定位到具体条件：
- 低吸：`不创新低 & 近5日 RSI<=25` 在 11 标的共有 51 天命中，再叠加「近 3 日金叉」后为 **0 天**；
- 高抛：`不创新高 & 近5日 RSI>=75` 共有 126 天命中，叠加「近 3 日死叉」后只剩 1 天，该日同时满足
  卖出共振（优先级更高）被覆盖，最终 0 次。
- RSI12 本身不是瓶颈（全样本 33,036 个交易日中 <=25 有 844 天、>=75 有 1,008 天），瓶颈是「极值窗口」与
  「交叉窗口」的时序错位——这与 v1 的「同日错配」是同一类问题，只是从买入侧转移到了震荡侧。

### 3.6 v1 五项验收的延续

- 无未来函数：策略仍只用 `shift(1)/shift(2)`；执行时点由 `execution_core.py:1686-1721`「先执行今日挂单、
  再登记当日信号为次日挂单」保证 T→T+1 开盘。延迟对照：v2 年化 +0.01% 优于基线 -0.20%、夏普 0.07 优于
  0.049、回撤 27.65% 优于 28.58%，**出现「延迟后反而更好」的异常（幅度小但方向一致）**，已如实记录，
  这是 v2 无边际的独立证据。
- 产物：`v2净值曲线_2026-11-20.csv`（3,032 行）、`v2交易明细_2026-11-20.csv`（695 笔，其中 25 笔落在
  2014 年暖机期，绩效窗口内 670 笔）、`v2参数敏感性_2026-11-20.csv`（9 行）、`work/v2_metrics.json`。
- 绩效、敏感性、样本内外：见 3.3~3.5。

## 4. 复现方式

```
.venv\Scripts\python.exe scripts\run_multi_resonance_backtest.py --variant v2
.venv\Scripts\python.exe scripts\run_multi_resonance_backtest.py --variant v1   # 复现 v1
```

`--variant` 默认 v2；v1 模块与 v1 产物未改动，两个变体在同一脚本内各跑 9 组敏感性并互相出对照表。

## 5. 局限与下一步建议

1. 本期只解决「同日错配」与「维度冗余」，没有解决「极值窗口与交叉窗口的时序错位」——低吸/高抛要求
   RSI 极值与 MACD 交叉发生在 3~5 天窗口内，在该样本上仍为 0。若要真正让这两行可达，需要放宽为
   「近 10 日」或改为状态机（极值后进入待触发状态，等待后续金叉），但这属于改口径，须另行批准。
2. 样本仍是 2015-01-05 成交额前 10（银行/保险/建筑）+ 上证指数，买入持有 12 年 -3.5%，结论不可外推到
   成长股；低 RSI 阈值（25/75）在这类低波动权重股上本就稀疏。
3. 未做滑点/佣金敏感性；v2 换手 274%/年，成本敏感度高于 v1，若计入更高滑点结果只会更差。
