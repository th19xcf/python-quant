# vol20+rs20 组合核查（2026-11-22）

规则：验证段 2021–2026；vol20 ≥ 0.039437（训练段最高 25%）、rs20 ≤ 0.062492（训练段最低 60%）；T+1 开盘买、T+4 收盘卖、扣 16.5bp。

## 一、逐笔复算

- 样本 53,155；复算最大偏差 2.97e-08（与存储 ret 一致）。
- 入场/出场：T+1 开盘 / T+4 收盘；持有 3 个交易日，平均自然日 4.5 天。
- 净收益：均值 +0.896%、中位 +0.182%、正收益比例 51.26%、命中率 25.21%。
- 成本：每次往返 16.5bp；按年成本 = 笔数 × 0.165pp（见 yearly.csv）。
- 重叠：34,252/53,183 笔（64.4%）与同票其他交易持仓窗口重叠，涉及 4,220 只。
- 集中度：top-10 笔占全部净收益 1.6%；单票最大 42 笔（0.08%，300588.SZ）。

## 四、结论

- 0.89% 逐笔复现：是（53,155 笔、复算净均值 +0.896%、最大偏差 3e-8、top-10 占净收益 1.6%）。
- naive vol20 25.99%/+0.868% 与组合 25.21%/+0.896% 并排：组合净增量仅 +0.028pp、命中还低 0.775pp；rs20 最弱十分位净 +1.451%，仍高于组合 → **无拐点增量**。
- 年度依赖：2024 占验证段 45.7% 笔数（净 +1.710%），2021/2023 净为负（−0.400%/−0.304%）。
- 归因：**收益来自波动率与行业反转暴露，不是拐点结构；且高度依赖 2024**。
