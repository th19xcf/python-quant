# 组合仓位、风控与收益归因方法

- 版本：2026-11-16 / v1
- 适用范围：主界面「仓位与风控」「收益归因」两页，以及回测记录层的逐期持仓表
- 只读边界：不改 `data/` 原始数据、不改回测引擎的成交与成本逻辑、不新跑策略回测（验证用的最小 run 除外）

## 1 术语

| 术语 | 含义 |
|---|---|
| 档位仓位 | 市场趋势总分映射的基础仓位（0 / 30% / 60% / 100%） |
| 波动率目标 | 以沪深 300 近 20 日已实现年化波动率为分母，把仓位缩放到目标波动 |
| 回撤制动 | 指数自 250 日高点回撤达到阈值后强制降杠杆 |
| 风险预算 | 已实现波动与目标波动之差、距制动阈值距离、年化风险敞口 |
| 约束校验 | 目标持仓的单行业、单标的、单边换手上限检查 |

## 3 目标仓位三层链

总仓位 = 档位 × 波动率缩放 × 回撤制动系数，三步依次相乘、每步输出调整量。

### 3.1 档位映射（市场趋势总分）

`总分 ≥0.40 → 100%（进攻）｜≥0.15 → 60%（偏多）｜>−0.15 → 30%（中性）｜≤−0.15 → 0%（防守）`

### 3.2 波动率目标

```
ret_t     = ln(close_t / close_{t-1})            # 只取最近 VOL_WINDOW+1 个收盘价
realized  = std(ret_t) × sqrt(252)               # 20 日已实现年化波动
vol_scale = min(1.0, TARGET_VOL / realized)      # TARGET_VOL = 15%，不加杠杆
```

`realized` 缺失（样本不足 21 个点）时 `vol_scale = 1.0`，页面如实标注。

### 3.3 回撤制动（连续化）

```
peak      = 最近 250 个交易日收盘价的最大值
drawdown  = close_t / peak − 1
factor    = 1.0                          dd ≥ −10%
          = 0.0                          dd ≤ −15%
          = (dd + 15%) / 5%              −15% < dd < −10%   # 线性插值
```

- 不用全历史高点，避免 2015 年高点让当前仓位长期为 0；250 日窗口与动量口径一致。
- −10% 时仓位减半（factor=0.5），−15% 时清仓（factor=0），中间连续过渡；三者相乘，百分比调整量页面逐环节列出。

## 4 风险预算

`目标波动 TARGET_VOL = 15%（年化）｜已实现波动 = 同 3.2 的 20 日年化｜波动差 = realized − TARGET_VOL｜距制动距离 = drawdown − (−15%)（负值已清仓）｜年化风险敞口 = target_position × realized`

## 5 约束校验

| 约束 | 上限 | 实际值算法 |
|---|---|---|
| 单行业权重 | 25% | 最新目标持仓按申万一级行业求和 |
| 单标的权重 | 8% | 最新目标持仓单票权重 |
| 单边换手 | 20% | 台账同一交易日 Σ|变动金额| / 资金规模 / 2 |

- 权重合计 > 1 时先归一化，≤ 1 时按原值（避免把部分快照放大）。
- 无持仓文件时页面显示「未生成」，不估算、不造数。
- 违规项标红并给出实际值；未违规项同样列出，便于看余量。

## 6 回测持仓表 `positions.parquet`

| 项 | 约定 |
|---|---|
| schema 版本 | `backtest_positions/v1` |
| 列 | `date`(Utf8) / `code`(Utf8) / `weight`(Float64) / `shares`(Int64) / `close_raw`(Float64) |
| 写入时机 | run 收尾时由记录层一次性落盘（`src/backtest/runner/records.py::_write_positions`） |
| 数据来源 | 引擎在每个成交日收盘后冻结的持仓快照（只读账本，不参与撮合与成本计算） |
| 权重口径 | `shares × close_raw / equity`，`equity` 为该日收盘总权益 |
| 元数据 | `metrics.json` 的 `positions` 字段登记 `file` / `rows` / `snapshots` / `first_date` / `last_date` / `schema` |
| 兼容性 | 老 run 无该文件时归因自动走降级口径，页面标注「该 run 无持仓明细」 |

## 7 Brinson 两段分解

对相邻两个持仓快照区间 `[t, t+1]`，用 `t` 日权重与 `t+1` 日区间收益：

```
区间收益   R_i = adj_close_{t+1} / adj_close_t − 1      # adj = close × hfq_factor
配置效应   A = Σ_i (w_p,i − w_b,i) × R_b,i
选择效应   S = Σ_i w_b,i × (R_p,i − R_b,i)
交叉项     I = Σ_i (w_p,i − w_b,i) × (R_p,i − R_b,i)
超额       E = A + S + I = R_p − R_b
```

- 现金按伪行业「现金」处理（收益 0），停牌 / 缺价个股权重并入现金桶，不用 0 收益伪造个股收益，保证 `A + S + I = R_p − R_b` 恒等。
- 区间收益必须用两个快照日的后复权价直接相除 `adj_{t+1} / adj_t − 1`；先在全交易日上 `shift(1)` 再筛快照日会退化成快照日单日收益，
  跨月区间被压缩成一天（2026-11-16 修正：574 期里 205 段长区间受影响，等权累计超额由 −19.49% 回到 −15.67%）。
- 多期累计为各期效应直接相加（算术和）；`IR = mean(period_excess) / std(period_excess) × sqrt(periods_per_year)`。
- `α` 为区间超额年化（`mean × periods_per_year`），`t = mean / (std / sqrt(n))`。

## 8 基准选择

| 选项 | 权重构造 | 说明 |
|---|---|---|
| 全市场等权 | 当日有收益的个股各 `1/N` | 主基准：最贴近「选股能力」，无市值加权的大盘偏向 |
| 中证全指（000985.SH） | 指数日线，仅收益对照 | 第二个主基准；2011-08-02 起，早于该日的区间截断；本地无成分权重，三效应不计算并在页面标注 |
| 行业等权 | 行业先 `1/K`，行业内再等权 | 剔除行业分布差异 |
| 沪深 300 | 调仓日之前最近一期月末成分权重，归一化到合计 1 | **仅作参考，含大盘风格偏差**：策略池偏中小盘，沪深 300 会把「小盘暴露」误记为个股选择效应（选择效应 +88.55%、配置效应 −12.04%） |

- 页面默认「全市场等权」，并排展示「全市场等权 + 中证全指」两档主基准，沪深 300 保留为参考项；下拉即时切换，不缓存混算。
- 为什么换掉沪深 300 主基准：它市值加权、成分偏大盘，与策略池（全市场、中小盘占比高）风格错配，超额里混入大小盘 beta，无法回答「选股是否有效」；全市场等权把基准拉到同一股票池，中证全指再补一个可投资宽基对照，两者一起看才能区分「选股」与「风格」。
- 有 `positions.parquet` 的 run 走完整分解；无持仓的 run 只做 run 级超额 + 行业/风格暴露；沪深 300 权重文件缺失或早于 2005-04 时退回指数收益对照。
- 归因 run 选择：先剔除 `spec.name` 命中 `app_ui_click` / `smoke` / `migrate_smoke` 等测试关键字的 run，
  再按「非实验 → 含持仓 → 区间达标（净值 ≥250 行）→ 净值行数 → created_at」排序取第一条；
  页面固定显示「已跳过 N 条测试/冒烟 run」。没有任何非测试 run 时提示「暂无可用正式回测，请先跑一次正式 spec」，
  不退回测试样本；若选中 run 命中测试关键字则直接报错，不静默出数。

## 8.1 零成本实验 run

- 表达方式：配方写「印花税 固定千0」，`stamp_tax_basis = fixed_0.0%`，滑点/佣金/冲击全 0。
- 强制护栏：spec 必须带 `experimental: true`，否则 `validate_spec` 抛错；正式 spec / `formal` run 拒绝 0 税率；
  `metrics.json` 写 `experimental=true` 与 `cost_note = 零成本实验，不得用于正式结论`。
- 用途：只用于把「成本拖累」从超额里单独拆出来，不进入正式归因默认选择；选中时页面顶部加警示。

## 9 缺失处理与已知边界

| 情形 | 处理 |
|---|---|
| run 无 `positions.parquet` | 降级：run 级超额、Beta、跟踪误差、IR、行业暴露、风格暴露；页面标注「口径降级」及缺失项 |
| 沪深 300 权重缺失 | 该期退回指数收益对照，三项效应留空，页面标注 |
| 选中 run 命中测试关键字 | 直接报错并提示，不计算、不展示测试样本结论 |
| 个股区间内停牌 / 缺价 | 该股权重并入现金桶（0 收益），不参与个股选择 |
| PB 2015–2017 全空 | 风格分位只统计 `pb > 0` 的样本；样本不足时显示「—」，不插值 |
| 持仓快照少于 2 期 | 不做 Brinson，退回降级口径 |
| 中证全指无成分权重 | 只做收益基准（run 级超额、IR、α、t）；三效应留空并标注「该基准无成分权重，不计算三效应」，不用自由流通市值重建 |
| 选中零成本实验 run | 页面 banner 前置「该 run 为零成本实验，不得用于正式结论」；默认选择让位给正式 run |
| 等权基准 ≠ 指数 | 等权基准的超额与 run 级（对 000300）超额不是同一口径，页面分栏展示，禁止相加 |

## 10 验收与实跑记录（2026-11-16）

- 正式 run：`20261116-153105_v3_monthly_4f306fb`，spec `v3_monthly`（价量估值等权基线，全市场、月频），
  区间 2010-01-04～2026-11-13，调仓 205 次、标的 5,583 只、净值 4,197 行；年化 9.13%、最大回撤 −61.08%、
  双向换手 1.9961、成本占比 6.23%。
- 零成本 run：`20261116-154702_v3_monthly_cost0_e4efb74`（同 spec、印花税固定千0），年化 9.74%、最大回撤 −60.60%、双向换手 2.0048。
- 耗时：回测 228.1 s（引擎 147.9 s）；修正口径后三档 Brinson 合计 23.8 s，三块拆解 16.7 s。
- `positions.parquet`：1,566,657 行 / 575 个快照 / 2009-12-01～2026-11-13，schema `backtest_positions/v1`；
  各期权重合计 0.8557～1.0000（差额即现金占比），用 `Σ(shares×close_raw)/Σweight` 反推权益与 `daily_nav.csv` 最大差 0.005 元。
- 区间口径自证：23 个 6 期窗口做「逐期区间收益连乘 == 直接区间收益」检验，最大误差 **1.78e-15**；
  修正前单日口径会让 205 段跨月长区间退化，等权累计超额虚低 3.82pp。
- 净值对照（只作方向参考，不作恒等校验）：持仓加权后复权收益连乘 +325%，run 净值 +335%（差 −10.24pp）、
  零成本 run 净值 +379%（差 −53.72pp）；差额来自净值含费用与分红入账、现金桶按 0 收益、快照日与执行日错位。
- 完整 Brinson（逐期明细落 run 目录 `attribution_brinson_equal_all.csv` / `attribution_brinson_csi_all.csv` / `attribution_brinson_csi300.csv`）：

|---|---|---|---|---|---|---|---|---|
| 全市场等权（主基准） | 574 | −11.47% | −6.42% | +2.22% | −15.67% | −0.18 | −0.92% | −0.72 |
| 中证全指（主基准，仅收益） | 513 | — | — | — | +100.11% | 0.67 | +6.55% | 2.63 |

- 沪深 300 的「选择效应 +88.55%」不是选股能力：策略池偏中小盘，沪深 300 把大小盘风格差记成了选择效应，
  这正是把它降为参考项、改用双主基准的原因；三档「累计超额」为算术和，与几何年化差不是同一口径。
- 超额三块拆解（全市场等权，574 期，闭合差额 0.00）：

| 块 | 值 | 口径 |
|---|---|---|
| 总超额 | −15.67% | equal_all 逐期相加 |
| 成本拖累 | −9.55% | 同 spec 零成本 run 与正式 run 的净值区间收益差 |
| 剔除标的效应 | +7.11% | 实盘持仓集合等权 − 全市场可交易等权（按持仓集合差） |
| 残差 | −13.23% | 倒推：个股权重、整手取整、现金缓冲、信号与执行日错位 |
| 闭合差额 | 0.00 | 成本 + 剔除标的 + 残差 − 总超额 |

- 结论：相对全市场等权的 −15.67% 里，剔除标的不是拖累（+7.11%，选的池子略好于全市场），拖累来自成本（−9.55%）与权重/执行残差（−13.23%）；明细落 `attribution_cost_decomposition.csv`。
