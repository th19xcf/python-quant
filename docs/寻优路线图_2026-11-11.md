## 1. 试验预算（Bonferroni 口径）

### 1.1 可承受多少次独立尝试

- 显著性口径：`α* = 0.05 / N`，N = 累计独立尝试次数；双侧 t 检验，自由度 18。
- **N=20 → α*=0.0025 → 临界 t≈3.10**。以逐期 σ=3.52% 计，最小可检出优势 = `3.10 × 3.52% / √19` = **2.50%/期**（≈ 年化 10.9%，60 日复利 4.2 次/年）。
- 若只用 6 个有持仓期（σ=6.4%），最小可检出优势 = `3.10 × 6.4% / √6` = **8.1%/期**。
- **因此：N 不得超过 20。** 任何小于 2.5%/期（≈11% 年化）的改善，一律判「与噪声不可区分」，不得写进结论。

### 1.2 已经用掉了多少

| 项 | 次数 | 处置建议 |
|---|---|---|
| `baseline_v1` 基线评测 | 1 | 计入 |
| 门槛敏感性 12 档（1.0/1.2/1.5/2.0 × 4/4、≥3/4、≥2/4） | 12 | **推荐标 `purpose=diagnostic` 不计入选参预算**，但必须在 `experiments.csv` 落 12 行，且**禁止**从这 12 档里直接挑一档当最终参数（否则就是选择性推断） |

- 采用推荐口径：**已用 1 次，剩余 19 次**。
- 若用户坚持「诊断扫描也计入」：已用 13 次，**剩余 7 次**，四层必须压缩到 7 次以内（L1 2、L2 2、L3 2、L4 1）。
- 超预算的判定：**停止新增试验**。只能等 OOS 区间延长（新数据）后重置预算，或把多个变体合并成一个「族级」假设并预先声明族定义，否则不得继续。

### 1.3 预算分配（推荐口径，共 19 次）

## 2. 四层路线与验收标准

每层的判定只允许三种结论：**有效 / 无效但无害 / 有害必须回退**。判定阈值全部预先写死，事后不得调整。

### 第一层：可买只数（先做）

**目标**：把「每日可买只数」做成时间序列，而不是只看 19 个调仓日的均值。

**产出**（`reports/strategy_tuning/buyable_count_daily.csv`）：
`date, pool, pass_score, pass_amount, pass_vol, pass_atr, pass_soft, eligible_final, market_ma_bull_share`
覆盖 2022-01-01~2026-10-31 每个交易日。

**验收标准（全部用数字判）**：

| 判定 | 条件（19 个调仓日口径） |
|---|---|
| **有效** | 中位可买只数 **≥8**；0 只期数 **≤2**；净年化 **≥ −1.45%**（基线 −0.64% 减 1 个 SE=0.81%）；最大回撤 **≤25%**；年化换手 **≤2.0×** |
| **无效但无害** | 中位 5~7，其余三项达标 → 记录并停止该层，**不得据此宣称「只数问题已解决」** |
| **有害** | 净年化 < −3%，或最大回撤 > 35%，或换手 > 3.0× → **回退**，并写明是哪一项越界 |

**基线事实（先把话说清楚）**：现行 19 期**中位 0 只、均值 1.84、13 期空仓**。所以「从 1.84 提到 ≥8」实际是「从 13 期空仓降到 ≤2 期空仓」，难度比数字看起来大得多。

**允许的手段**：绝对阈值改当日截面分位（消除 §2 诊断里的分位漂移）、软筛选由「四项全过」改为「关键项 + 计分」、扩充抽样池、把市场状态（全市场 MA 多头占比）作为仓位调节而不是硬门槛。

**禁止的手段**：直接把 `max_atr_pct/max_volatility` 乘系数放宽——已实测只数几乎不动（1.84→2.79）且 2026-07-20 仍为 0；放宽软筛选则收益恶化。

### 第二层：因子去重

**已有优势**：16 因子 × 3 期限共 48 组 OOS `sign_consistent` 全 True，**方向不用再挑**。

**要做的事**：算因子间相关性矩阵，合并**真正同义**的因子，说明权重折算。

**验收标准**：

| 判定 | 条件 |
|---|---|
| **有效** | 3 对同义因子（`momentum_6m`/`momentum_12m` ρ=0.62、`momentum_6m`/`trend_slope_60` ρ=0.51、`gtja_003`/`gtja_024` ρ=0.66）合并；合并后 5 个固定信号日 Top15 的 MA 多头只数 **均 ≥1**；新旧 Top15 平均重合 **≤10/15**（证明确实去重）；净年化 ≥ −1.45% |
| **无效但无害** | MA 多头只在 1~2 日为 0，且净年化在 ±1 SE 内 → 记录「去重不改变选股质量」，可继续第三层 |
| **有害** | 净年化 < −3% 或回撤 > 30% → 回退；或合并后 MA 多头在 **≥3 日**仍为 0 → 判定「方向冲突未解决」，停止，转 §5 |

**硬约束**：不重新拟合方向；ρ<0.3 的因子对一律不合并（legacy↔extended 动量 ρ=0.11~0.23、趋势 ρ≈0.03，属于此类）。

### 第三层：权重合成

**只比三种**：等权 / IC 加权 / 风险平价。**不给「优化出来的最优权重」留位置**，理由：17 个因子 × 19 个 OOS 期，自由度远大于样本；任何「最优权重」都是在样本内拟合噪声，且会额外消耗试验预算。

IC 加权必须在 IS（2015-01-05~2021-12-31）上估计权重，OOS 只用于评价，禁止用 OOS IC 回填。

**验收标准**：

| 判定 | 条件 |
|---|---|
| **有效** | 某一方案相对基线净年化提升 **≥2.5%/期**（Bonferroni N=20 口径），且回撤不增加 >5pp |
| **无效但无害** | 三种方案差异 < 1 SE（0.81%/期）→ **判「无差别」，保持等权**，这是合法结论，不是失败 |
| **有害** | 回撤 > 基线+10pp，或净年化 < −3% → 剔除该方案 |

### 第四层：交易约束

单变量扫描，每次只动一个，逐次写入 `reports/strategy_tuning/experiments.csv`（时间、参数、from→to、结果、相对基线 delta）。

扫描清单（每个 = 1 次试验）：
1. `max_atr_pct`：0.040 → 0.060 / 0.080
2. `max_volatility`：0.50 → 0.70 / 1.00
3. `min_amount`：5e7 → 2e7 / 1e7
4. 持有期：60 → 20 / 5（仅作对照，不改变主口径）
5. 成本：0.724% → 1.0%（压力测试，不改变主口径）

**验收标准**：只有同时满足「净年化提升 ≥2.5%/期」且「回撤增加 ≤5pp」才接受该改动；否则保持现值。任何一项都不得「打包」与其他改动一起提交。

## 3. 不允许做的事

1. **全样本一次性优化**：禁止在 2022-2026 全区间上同时调多个参数再挑最好的组合。
2. **按 OOS 结果反复微调**：禁止看到 OOS 结果后改同一参数再跑（每次都是新试验，计入预算）。
3. **打包改动**：禁止把「去重 + 改权重 + 改门槛」放进同一次评测或同一次提交。
4. **看结果后再定验收阈值**：所有阈值必须在跑之前写进本文档。
5. **用 IC 或毛收益当目标函数**：只允许净年化或期胜率。
6. **为了让名单有票而放宽门槛**：已实测有害（−0.64%→−10.31%）。
7. **选择性报告**：只报最好的那档、不报全部档位，或把 diagnostic 扫描结果当作选参依据。

## 4. 每层「通过 / 不通过」的记录格式

每层收口在 `docs/` 下追加一节，必须含：

- 试验编号与累计尝试数 N（跑完后立即更新 `experiments.csv`）
- 该层的全部变体结果（不得只报最优）
- 判定：有效 / 无效但无害 / 有害必须回退，并给出触发阈值的那一个数字
- 若回退：回退到哪个提交或哪个参数值，回滚命令

## 5. 如果一层的结论是负面的怎么办

**不要硬推下一层。** 每层的负结论都有对应的退路与表述方式：

### 5.1 第一层提不上去（中位 <5）

- 退到「策略定位修正」：把 `max_positions` 从 15 调到与实际可买只数匹配的值（如 3~5），并把策略表述为**低频、低仓位、非满仓策略**。
- 结论表述：「不是门槛坏了，是这套打分在当前市场状态下只能选出 0~5 只；15 只组合是错误的产品假设。」
- **不得**把「只数不够」包装成「因子没用」——两者是不同命题。
- 不进入第二层，因为去重解决不了「市场里没有符合方向的票」。

### 5.2 第二层去重后 MA 多头仍为 0

- 说明冲突不在因子重复，而在**打分方向与软筛选方向**。
- 此时需要一次「口径决策」（改软筛选语义或改打分方向），属于「改变既定口径且无实测证据」的停手类，必须先向用户报，不能自行改。
- 结论表述：「去重不是解药；冲突在打分与软筛选的方向约定，需先决定长线档到底要选上行趋势还是下行反转。」

### 5.3 第三层三种合成无差别

- **这是合法结论**：保持等权（自由度最小），把「权重不是瓶颈」写进结论文档，然后直接进第四层。
- **不得**因为「没差别」就去尝试「优化权重」——那正是预算与自由度最不允许的做法。
- 结论表述：「等权 / IC 加权 / 风险平价在 19 期 OOS 上差异小于 1 SE，权重合成不是当前瓶颈，保持等权。」

### 5.4 第四层扫描全部无效

- 保持现值，把「门槛与持有期在当前区间已接近局部平坦」写进结论。
- 若所有层都无改善，最终结论应为：**「当前打分体系在 OOS 上不具备可辨识的超额，应先回到因子有效性与数据区间扩展，而不是继续调参」**，并列出需要延长 OOS 或增加数据的具体需求。

## 6. 执行顺序与依赖

```
L1 可买只数时间序列（4 次）
   └─ 有效 → L2 因子去重（3 次）
                 └─ 有效 → L3 权重合成（3 次）
                               └─ 有效/无差别 → L4 交易约束（8 次）
   └─ 无效但无害 → 只做 L2 的「方向一致性」验证，不宣称收益改善
   └─ 有害 → 回退，停止
```

每层开工前必须先更新 `experiments.csv` 的累计次数，并在 `docs/` 写明本次要动的唯一变量。
