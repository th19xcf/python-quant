## 二、收口定义（可验证）

同时满足以下两条才算数据收口，缺一条即为未收口：

1. **矩阵条件**：`reports/数据可用性矩阵_2026-11-10.md` 的红格为 0；或每个红格都归入「源端无」并附取证（端点、返回值、同日同端点其他代码可取的反证）。
2. **登记条件**：`docs/数据缺口登记.md` 的 G-001~G-058 每条都落到下列四档之一，落不进即为未收口。旧编号 G-040~G-043（收益率曲线缺期限 / 保证金率与手续费 / 分评级信用债 / 中债成分）已由 G-054~G-057 取代，不重复计数；去重后为 **54 条**。

三档判定标准：

| 归档 | 判定标准 |
|---|---|
| 已补 | 正式路径已写入并通过 DG-20 四项（行数守恒、逐值对拍、SHA256、抽样断言）；或产出方已恢复且数据不再缺失 |
| 源端无（有证据） | 有取证说明源端确无，且排除「链路未接线 / 开关未开 / 时间范围错」；本地也无可用推导路径 |
| 接受偏差 | 缺口仍然存在，但影响面已量化并写明、不影响收口窗口内的结论，且写明重开条件 |
| 未收口 | 上述三档都落不进，或已开工/待口径但尚未通过收口判定标准 |

### 2.1 判定口径（2026-11-11 起生效，替代原「红格清零」硬条件）

数据是否收口，以**是否影响分析与回测**为准，不以矩阵红绿定生死：

| 归档 | 判定标准 |
|---|---|
| **必须补（阻断收口）** | 缺口所在年份区间落在**在跑链路实际读取的范围**内，且该链路服务于已交付结论 |
| **不影响可收口** | 该数据集**没有消费方**，或消费方只读缺失年份之外的区间；须给出「文件:行号 + 起点常量」证据链，不接受「影响不大 / 建议关注」这类表述 |
| 能补但窗口外 | 不阻断收口，仍按并行补数推进，补完按 DG-20 四项验收 |

在跑链路实际读取范围（截至 2026-11-11）：

| 链路 | 起点 | 依据 |
|---|---|---|
| 个股动量回测（样本内 / 样本外） | 2015-01-01 / 2023-01-01 | `docs/个股端动量回测协议_2026-11-05.md` L91–L93 |
| 日度建议评估（基本面因子唯一入口） | 2021-01-01 | `tools/eval_daily_advice.py` L334 `--start` 默认值 |
| 六维状态向量 | 1990-12-19 | `meta/state/state_vector_daily.parquet`；但 1990–2005 估值维为空（`dims_available` 1–2，2006 起 5–6），属研究账 |

**四要素强制项（2026-11-11 起，任一缺口缺一项即不得判「不影响可收口」）**

| # | 要素 | 写法要求 | 反例（不得出现） |
|---|---|---|---|
| 1 | **消费方路径** | 必须给到 `文件:行号` + 起点常量（如 `tools/eval_daily_advice.py:334` 的 `--start` 默认 2021-01-01）；无消费方的要说明「`src/` 全库 grep 零命中」 | 「多个模块会用到」 |
| 2 | **缺失影响** | 缺了让哪条链路少算什么（具体到函数 / 因子 / 决策），不是「可能受影响」 | 「影响不大」 |
| 3 | **量级** | 受影响标的数 / 事件数 / 交易日数，占比，以及是否改变结论方向 | 「影响很小」 |
| 4 | **判定** | 只能取「必须补（阻断收口）」/「不影响可收口」/「能补但窗口外」三值之一 | 「建议关注」 |

**据此 2026-11-11 的收口判定：可以收口。** 118 个红格全部为「不影响可收口」，必须补 0 格；逐块四要素见 `reports/数据可用性复核_20261111/数据收口记录_2026-11-11.md` §3。分红覆盖率 67%–79% 已按三种分母重算 + 外部抽检复核，判定为口径问题而非漏数据，复核过程见同一文件 §7。
