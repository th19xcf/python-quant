## 1. 背景

`meta/financials/valuation_daily.parquet` 中 `pb`、`dv_ratio` 在 2018-01-01 之前整段为空（2015-01-01~2017-12-31 共 1,948,774 行，`pb` 非空 0 行，`dv_ratio` 非空 0 行），导致 2015-2017 的价值/股息类因子无原始输入。同一张表的 `total_mv`、`close` 在该区间完整，`meta/financials/balance.parquet` 提供季度净资产，`factors/stock_dividend.parquet` 提供 1991 年以来的分红事件，具备重建条件。

## 2. 字段与口径

| 来源 | 字段 | 含义 | 单位 |
|---|---|---|---|
| `valuation_daily` | `total_mv` | 东财口径总市值 | 元 |
| `valuation_daily` | `close` | 当日收盘价（不复权） | 元 |
| `valuation_daily` | `pb` | 原表市净率（东财 `stock_value_em`），2018 年起有值 | 倍 |
| `valuation_daily` | `dv_ratio` | 原表股息率，2018 年起有值 | % |
| `balance` | `total_equity` | **股东权益合计（含少数股东权益）**，来自 `akshare:stock_zcfz_em` 的「股东权益合计」列 | 元 |
| `balance` | `ann_date` | 公告日期（`em_notice`，缺失时回退法定披露截止日） | 日期 |
| `stock_dividend` | `cash_div` | 每股现金分红（税前，元/股），与采集器计算 `dv_ratio` 时使用的字段一致 | 元/股 |

**关键口径说明**：本地 `balance.parquet` 没有「归属于母公司股东的净资产」字段，只有「股东权益合计」。因此本补丁的 BP 分母是**含少数股东权益的合并净资产**，而原表 2018 年起的 `pb` 是东财的归母口径。这是本次交叉验证残余误差的唯一系统性来源，第 4 节给出量化。

## 3. 公式与对齐规则

- 点对点 PIT 对齐：对每个 `(ts_code, trade_date)`，取 `ann_date <= trade_date` 的最近一期资产负债表（`merge_asof`，按 `ts_code` 分组、`ann_date` 升序）；`ann_date` 全部有值，未使用法定截止日回退。
- 账面市值比：`bp = total_equity / total_mv`（仅当 `total_equity > 0` 且 `total_mv > 0`，否则留空）。
- 市净率（冗余列，便于与原表直接对照）：`pb = total_mv / total_equity = 1 / bp`。
- 股息率：`dp = 近 365 天每股现金分红合计 / 当日 close × 100`，仅统计 `cash_div > 0` 且 `ex_date` 非空的事件；窗口为 `(trade_date - 365 天, trade_date]`，与 `src/data/financials/collector.py::_attach_dividend_yield` 的实现逐条一致；该标的在窗口内无分红时记 `0.0`（与原采集器语义一致，不记为缺失）。

## 6. 局限

1. **口径不连续**：2018 年前 `bp` 为合并净资产口径，2018 年起原表 `pb` 为归母口径。对少数股东权益占比高的个股，两个区间拼接时会出现水平跳变（个股中位比值 p5~p95 为 0.77~1.01）。做跨 2018 的长周期因子时，建议按个股或行业做口径对齐，或将 2015-2017 段单独标注。
2. **bp 缺失 6.3% 行 / 209 只标的**：这些标的在 `balance.parquet` 中 2015-2017 无任何记录（非负净资产被过滤，而是完全缺行），未做任何估算填补。
3. **仅补 2015-2017**：2010-2014 的 `pb`/`dv_ratio` 仍为空（虽然 `balance` 自 2010-03-31 起有数据），按本次任务范围未扩展。
4. **极端尾部未裁剪**：净资产接近 0 的个股 `bp` 可低至 2.9e-5 或高至 32，未做 winsorize，使用方需自行去极值。
5. **分红为除息日 TTM 口径**：不做年度归属调整，与原采集器一致；`cash_div_fix` 在 2015-2017 段无值，未使用。
6. **未做 PIT 行业/市值中性化**，也未处理财报重述（同一 `end_date` 有多版时按 `ann_date` 取最新一版，仍属 PIT）。
