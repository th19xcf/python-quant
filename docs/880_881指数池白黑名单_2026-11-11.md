## 二、这 217 只为什么会被算成「月收益 >50pp」

四条互不相同的机制，不能糊成一类（同一只可同时命中多条，故相加不等于 217）：

| 机制 | 数量 | 证据 |
|---|---|---|
| ① 统计量序列被当价格算收益 | 41 | 例 `880036.SH` 创业停板：点位 0.01~245、整数占比 97.1%，实际是「停板家数」；`880046.SH` 科创停板、`880044.SH` 科创均价（全市场均价）同理 |
| ② 交易日缺口 × 月末尾部门控 | 42（其中 23 只全部异常月都由缺口造成） | 门控条件是 `date == CAL[ym]`（`CAL` = 000300.SH 每月最后交易日）。代码在月末日停牌/无该行时整月被丢，前后两月被合并成一次「月收益」。例 `880634.SH` 含GDR：2006-05 无月末行，2006-06 收益 +98.5% 实为 04-28→06-30 的跨月涨幅 |
| ③ 单日断点/合成段 | 76 | 例 `880633.SH` 汽车热管理 2022-07-28 单日 −70.43%、次日 +179.89%（前收 4230.45 → 7.32 → 20.49），是编制重建的行情断点；`881364.SH` 产业互联网 2017-11 连续 19 日每日 >+2%、单月 +217%，是合成/回填段 |
| ④ 序列本身有长空洞 | 42（全库 119 只） | 最长缺口 >120 天的有 42 只，`defect` 类空洞中位数达 860 天（如 `880683.SH` 星闪概念 1,457 天、`880527.SH` 承诺不减 1,674 天）。跨空洞算出的「月收益」不是收益 |

## 七、交付格式与过滤方式

CSV 列：`ts_code / name / segment / class / reason / rows / start / end / close_min / close_max / int_frac / max_abs_daily / jump_days_15 / jump_date / up_streak / up_cum / dn_streak / dn_cum / max_gap_days / corr_mkt / bad_month_n / bad_month_gap_n / max_month / max_month_ret / max_month_span / in_anomaly_50pp`

直接用 `class` 过滤：

```python
import polars as pl

pool = pl.read_csv('reports/data_audit/index_880_881_pool_classification_20261111.csv')
white = pool.filter(pl.col('class') == 'white')          # 891 只，可直接入行业池
black = pool.filter(pl.col('class') == 'not_price')      # 55 只，永久排除
usable = pool.filter(pl.col('class').is_in(['white']))   # 需要断点/合成段截断后再放宽到 defect
```

四条使用注意：

1. **月末尾部门控要改成「每月取最后一个可用交易日」**，不要用 `date == CAL[ym]` 严格相等。本次 217 只里有 42 只的异常月由该口径产生，其中 23 只全部异常月都是这个原因——它们不是数据错误，改口径即可消掉。
2. `defect` 的 179 只不是「脏数据不可用」，而是「某一天有断点」。断点日已在 `jump_date` 给出，可据此截断历史起点；但要先排除 R6 的已知误判（盐湖股份这类真实无涨跌幅限制事件，见 §三）。
3. `max_gap_days > 120` 的有 119 只（217 中 42 只），这类序列中间有整年空洞，任何跨空洞的收益都不是真实收益，入池前必须按连续段截断。
4. `881` 段可以直接全量使用（无统计量序列）；`880` 段必须先过本节黑名单。

## 八、局限（未做的事）

- 未修任何行情：`defect` 的断点日只做标注，没有回补或重算；`synthetic` 只标注不截断。
- 未用个股成分股做交叉验证：判断「行业指数是否真实」只用了与 000300.SH 的相关性和序列结构。个别窄行业（如 `881077.SH` 白银 2026-01 +131%）是 2~5 只成分股的极端行情，与本判定不冲突，但对 σ 而言噪声很大。
- 未区分调整前后口径：判定用的是本地落盘的 `close`（原始收盘），未使用复权序列；880/881 段本身没有分红复权事件。
