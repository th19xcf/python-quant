## 五、主力连续构造口径（G-051，最终实现）

不使用任何第三方「连续合约」（新浪起点被截断到 2017-01-17、持仓量恒 0；tushare `IF.CFX` 换月规则不透明），改为**从单合约自建**，规则写在 `tools/build_futures_continuous.py` 的 docstring 与 `futures_manifest.json`：

1. **候选**：交割日晚于当前主力、且 `oi > 0` 的合约中 `oi` 最大者。
2. **切换条件**（满足其一）：候选 `oi ≥ 当前 oi × 1.05`；或当前主力距最后交易日 ≤ 7 个自然日。
3. **硬约束**：绝不回退到交割日更早的合约。
   > 实测依据：纯「oi 取最大」会在换月前后横跳（IC 2018 年出现 IC1804→IC1806→IC1805、IC1809→IC1808→IC1809），
   > 一年多出 3 次无意义换月；回退等价于「重新买入即将交割的合约」，不可执行。
4. **价格两列**：`close_raw` 为活跃合约原始收盘（可与交易所逐值对拍）；
   `close_adj` 为逐日收益链式累乘（换月日收益 = 新合约收盘 / 旧合约前收盘 − 1）。
5. **换月事件表**同时给两个口径：`return_pct`（含当日行情涨跌）与 `roll_gap_pct`（两腿**同日**收盘差，纯展期价差）。
   两者不可混用：把 `return_pct` 当展期成本会把行情涨跌算进去。
