## 一、策略是什么

**一句话**：D0 收盘后，只用当天已知的数据，给每只股票估计"D1 开盘买入、D3 收盘涨幅 ≥5%"的概率，概率明显高于平均的全部买入，持有最多 3 个交易日。

动机：此前三轮"上涨启动拐点"研究（`docs/上涨启动拐点_2026-11-22.md` 等）都是"连涨 3 天确认后、D4 才买"，买入时涨幅已经发生过。本策略改为**在 D0 就预测、D1 买入**。

### 1. 达标标签
```text
达标 = close[D3] / open[D1] − 1 ≥ 5%
```
- D1、D3 是该股 D0 之后的第 1、第 3 个交易日；
- D1 一字涨停买不到 → 记"未成交"，不计入收益，单独统计。

### 2. 样本池（每天按 D0 当时状态剔除）
| 剔除项 | 标准 |
|---|---|
| ST / *ST、退市整理期 | 按 D0 当日状态（PIT） |
| 新股 | 上市不足 60 个交易日 |
| D0 不可用 | 停牌，或一字涨停 / 一字跌停 |
| 近期长停牌 | 前 20 日内停牌超过 5 天 |
| 冷门股 | 20 日平均成交额 < 5,000 万元 |
| 小市值 | 流通市值处在当日最低 30%（Liu, Stambaugh & Yuan 2019 的壳价值剔除） |
| 成交过热 | 20 日平均换手率处在当日最高 5% |

区间 2015-01 ~ 2026-10，沪深 A 股（不含北交所、B 股），含退市股。主口径样本 535 万个"股票 × 日"。

### 3. 特征（10 个，均为 D0 收盘可得）
| # | 特征 | 定义 |
|---|---|---|
| F1 | 波动收敛 | 20 日波动率在自身过去 250 日中的分位 |
| F2 | 箱体振幅 | 60 日最高 / 60 日最低 − 1 |
| F3 | 离高点距离 | 收盘价 / 60 日最高 − 1 |
| F4 | 放量 | D0 成交额 / 前 20 日均额 |
| F5 | 缩量 | 前 5 日均额 / 前 60 日均额 |
| F6 | D0 涨幅 | D0 日收益 |
| F7 | 收盘位置 | (收盘 − 最低) / (最高 − 最低) |
| F8 | 20 日收益 | 动量 / 反转 |
| F9 | 行业强弱 | 所属申万一级 20 日收益 − 全 A 等权 20 日收益 |
| F10 | 市场宽度 | 全 A 过去 20 日上涨家数占比均值 |

F1~F9 每日横截面转分位，F10 用原值。

### 4. 模型与选股
- 逻辑回归（L2），只用 2015–2020 训练一次，系数固定；
- 基础概率 p0 = 训练段可交易池的达标率 = **13.72%**；
- **选股**：模型概率 ≥ k × p0 的股票全部买入（满足即买，不限资金、不限只数），k 在验证段从 {2, 3} 里选一个。

### 5. 交易规则
- D0 收盘出信号，**D1 开盘买入**；
- 每天收盘检查，满足任一条件则**次日开盘卖出**：
  - 止盈：收盘 ≥ 买入价 × 1.05；
  - 止损：收盘 ≤ 买入价 × 0.97；
  - 到期：都未触发，D4 开盘卖出（最长持有 D1~D3）；
- 卖出日开盘跌停顺延；
- 成本：A 股往返 21.9bp，卖出印花税按历史税率（2023-08-28 前 0.1%）。

### 6. 检验设计
| 段 | 区间 | 用途 |
|---|---|---|
| 训练 | 2015–2020 | 拟合模型、估计 p0 |
| 验证 | 2021–2023 | 在 k=2 / k=3 中选一个；两个都不比"没选中"赚钱 → 早停 |
| 留出 | 2024–2026-10 | 只打开一次（**未打开**） |

对照组：A 选中 / B 没选中 / C 全池 / D 随机抽同数量 200 次。
通过需 6 条全部满足：命中率 ≥ 2 倍全池；A−B 每笔净收益 ≥ +0.5pp 且 t ≥ 2；高于随机 95 分位；三段及 2024–2026 每年为正；组合年化超额 ≥ 2pp 且 DSR ≥ 0.95；扣除市值/波动/近期涨幅/行业强弱暴露后仍有超额。

## 三、判定与原因

**判定**：验证段 A − B = −0.75pp ≤ 0，k=3 无信号，按预注册**早停 → 不可用**，留出段未打开，未在验证段调参重跑。

**原因（推论，与数据一致）**：
1. **可预测的是"波动幅度"，不是方向**。区分度最大的是 60 日振幅：振幅大的股票更容易 3 天涨 5%，也更容易跌 3%。选中股票里 50% 触发止损、只有 33% 止盈，每笔亏 3%+成本的笔数多于赚 5% 的笔数，期望为负。
2. **模型主要在押市场**。F10 市场宽度系数最大（+3.65），信号集中在少数普涨日（验证段只在 81 天出现，单日最多 60 个），本质是择时而非选股。
3. **预想中的"启动形态"信号很弱**。缩量后放量、贴近前高、收在高位等形态，单独的提升倍数只有 1.0~1.2，扣成本后不够。
4. **命中率 ≠ 赚钱**。止盈把达标样本的收益封在 +5% 附近，未达标样本却频繁止损。

**有效的部分**：D0 数据确实能把"3 天涨 5%"的概率提高到约 2 倍，训练段和验证段都显著（t = 6.8 / 5.0），可作为"波动/弹性预测"留档，不能直接用作买入信号。
