### 0.2 口径核对（这步不能省）

任务把 `Δ=+1.1708pp、t=0.668、p=0.51` 描述为 h=20 的实测。核对原始表发现：

- **效应量**：按要求仍用 +1.1708pp/期 作为「待检验的效应量」（这是对结论最有利的写法——假设效应有这么大）。
- **σ**：必须取 **h=20 Δ 序列**的离散度，不能拿 h=60 的 t 反推。由 h=20 mid 行 `σ = Δ√n/t = 0.1872 × √56 / 0.180 = 7.783pp/期`。NW(1) 修正后的 t 对应的 σ 是**上界**（正自相关下 NW 标准误大于朴素标准误），所以 MDE 3.43pp 是**偏保守（偏高）**的估计；用真实 σ 只会让 MDE 更低、结论更强。
- 若把 `t=0.668` 直接套到 n=81 上（σ=15.774、MDE=6.96pp），属于把 60 日 t 与 20 日设计混用，只作为敏感性上界列出。

## 1. MDE 数字

### 1.1 公式与计算

双侧检验、显著性 `α*`、功效 `1-β` 下，均值差的最小可检测效应：

```
MDE = ( t_{1-α*/2, n-1} + t_{1-β, n-1} ) × σ / √n
```

代入主口径：

```
t_crit = t_{0.99875, 80} = 3.1220
t_80   = t_{0.80,     80} = 0.8461
σ      = 0.1872 × √56 / 0.180 = 7.7826 pp/期
MDE    = (3.1220 + 0.8461) × 7.7826 / √81
       = 3.9681 × 7.7826 / 9
       = 3.4314 pp/期
```

**MDE ≈ 3.43pp/期**（相对基线的每期净收益差，统计口径，不是策略收益预测）。

### 1.2 折年化：两个口径都写清

假设：每期 20 个交易日、每年 252 个交易日 ⇒ **12.6 期/年**；期与期不重叠；每期收益可全额再投入；不计空仓与追加成本。MDE 本身是「每期净收益差」，年化只是把它放大到可读量级。

| 年化方式 | 公式 | 结果 |
|---|---|---|
| **算术年化** | `3.4314pp × 12.6` | **43.24%/年** |
| **复利年化** | `(1 + 0.034314)^12.6 − 1` | **52.97%/年** |

算术口径与 `tools/tune_advice.py` 的「净年化 = 逐期净收益均值 × 252/h」一致；复利口径仅用于说明量级。**43%/年是「要过显著性门槛所需的年化超额」，不是「策略能赚 43%」**。

### 1.3 敏感性：σ 来源不确定不改变结论方向

| 场景 | σ (pp/期) | n | MDE (pp/期) | 算术年化 | 复利年化 |
|---|---|---|---|---|---|
| **主口径**：σ 由 h=20 Δ 序列反推（NW 上界） | 7.783 | 81 | **3.431** | **43.2%** | **53.0%** |
| h=60 对反推（n=19 个有效独立样本） | 7.638 | 81 | 3.368 | 42.4% | 51.7% |
| h=60 对反推（n=20） | 7.838 | 81 | 3.456 | 43.5% | 53.4% |
| 只用 56 个有效期 | 7.783 | 56 | 4.178 | 52.6% | 67.5% |
| t=0.668 视为 81 样本实测（上界） | 15.774 | 81 | 6.955 | 87.6% | 133.3% |
| h=60 降频（26 期，4.2 期/年） | 7.783 | 26 | 6.436 | 27.0% | 30.0% |

前四种读法的 MDE 都在 **3.4~4.2pp/期**，比 1.17pp 大 3 倍左右；结论不依赖 σ 的具体来源。

## 2. 与实测对照：够大没测准，还是本来就太小

### 2.1 放到同一把尺子上（pp/期）

年化绝对值先按 `÷12.6` 折成每期（MDE 是每期口径，必须先同尺度）：

| 量 | pp/期 | 占 MDE(n=81)=3.431pp 的比例 |
|---|---|---|
| **MDE（80% 功效门槛）** | **3.431** | 100% |
| A 档 Δ（h=60 实测，当作待检验效应） | 1.171 | **34.1%** |
| 年化 +13.3% 折期（算术 / 复利） | 1.056 / 0.996 | 30.8% / 29.0% |
| 年化 +12.5% 折期（算术 / 复利） | 0.992 / 0.939 | 28.9% / 27.4% |
| 年化 +10.6% 折期（算术 / 复利） | 0.841 / 0.803 | 24.5% / 23.4% |

```
pp/期   0        1         2         3         4
        |---------|---------|---------|---------|
MDE    3.431                              |========|  ← 80% 功效门槛
A Δ    1.171  |=====                                  ← 点估计，t=0.668
+13.3% 1.056  |====                                   ← 绝对年化折期
+12.5% 0.992  |====
+10.6% 0.841  |===
```

### 2.2 判定

- **A 的 +1.1708pp/期只有 MDE 的 34%**，`t=0.668`、`p≈0.51`，与 0 不可区分；当前 n=81 设计对该效应的功效只有 **4.04%**（56 期口径 2.3%，26 期口径 0.8%）。
- 年化 +13.3% / +12.5% / +10.6% 是**绝对净收益**，不是相对同池随机组的超额。折成每期 0.84~1.06pp，同样全部低于 MDE；其中还混有市场 beta 与股票池本身的收益（v1 未做基准中性化、不含 ST/事件过滤），不能当作选股能力。
- **判定：本来就太小**，不是「够大但没测准」。所谓「没测准」只是结果——真正的问题是点估计本身在门槛之下：即使完全无测量误差，1.17pp/期的效应在 n=81、α*=0.0025 下也几乎不可能被判显著。
- 不能反向解释为「效应够大、只差样本」：把样本翻倍到 162 期，MDE 也只降到约 **2.39pp**，仍高于 1.17pp。

## 3. 要达到 80% 功效需要多少样本

保持效应量 `Δ=1.1708pp/期`、`σ=7.783pp/期`、`α*=0.0025` 不变：

| 目标 | 所需独立样本 n | 折年数（×20/252） |
|---|---|---|
| 50% 功效（期望 t 刚好压线） | ≈ **409 期** | **≈ 32.5 年** |
| **80% 功效** | ≈ **665 期** | **≈ 52.8 年** |
| 80% 功效（σ=15.774 上界读法） | ≈ 2,716 期 | ≈ 215.5 年 |
| 80% 功效（按 h=20 实测 Δ=0.1872pp） | ≈ 25,823 期 | ≈ 2,049 年 |

### 3.1 延长样本的边际收益（效应固定 1.17pp/期）

| 样本长度 | n | MDE (pp/期) | 算术年化门槛 |
|---|---|---|---|
| 现状 ≈6.5 年 | 81 | 3.431 | 43.2% |
| 再等 3.5 年（10 年） | 126 | 2.725 | 34.3% |
| 20 年 | 252 | 1.911 | 24.1% |
| 30 年 | 378 | 1.556 | 19.6% |
| 52.8 年 | 665 | 1.167 | 14.7% |

MDE 随 `1/√n` 下降，10 年只从 3.43 降到 2.73，仍高于 1.17；要到 1.17 需 52.8 年。

### 3.2 降频（h=60）

h=60 时 26 个独立期、`σ≈7.78pp`，MDE 升到 **6.44pp/期**。按 4.2 期/年折算术年化 27.0%，看似比 h=20 的 43.2% 低，但这是「每年只有 4.2 次下注机会」造成的错觉：要达到同样的 80% 功效，需要 665 个 60 日期，折 **158.3 个日历年**，比 h=20 的 52.8 年更差。降频减少独立样本、放大单期波动，不是提高功效的手段。

### 3.3 这意味着什么

- **「再等几年数据」不是可行路径**：3~5 年的新增数据只能把 MDE 从 3.43 压到 2.7 左右，仍比 1.17 高一个量级。
- **样本长度不是主要瓶颈，效应量/噪声比才是**：给定 σ≈7.8pp、α*=0.0025、80% 功效，n 必须到 665 期才能分辨 1.17pp 的效应；在 20 日持有期上就是 52.8 年。
- 用 h=20 的实测效应（0.1872pp）算，所需样本是 2,049 年——这条链在个股 Top15 粒度上无法用「加长样本」解决显著性。

## 4. 结论倾向

### 4.1 三个方向逐一判断

| 方向 | 判断 | 理由（数字） |
|---|---|---|
| **继续找因子**（同一 Top15 链、同一检验口径） | **不推荐** | MDE=3.43pp/期；股票因子可实现的相对超额通常在 0.5~2pp/期，落在这个门槛以下是常态。继续筛等于在噪声里挑，还会消耗 N=20 预算（已用 3 次）。除非候选因子的先验效应 >3.4pp/期，否则测不出来。 |
| **延长样本 / 降频** | **不推荐** | 80% 功效需 52.8 年（h=20）或 158.3 年（h=60）；10 年样本 MDE 仍 2.73pp。两者都不改变「效应太小」这一主要矛盾。 |
| **改做低噪声标的（ETF 轮动、行业轮动）** | **推荐为主线** | 它改的是 MDE 分母里的 σ，而不是硬碰效应量。若 σ 从 7.8pp 降到 4pp，n=81 时 MDE≈**1.76pp/期**（年化 22.2%）；降到 3pp 时 MDE≈**1.32pp/期**（16.7%）。行业/宽基轮动的标的少、个股特质噪声低，σ 有实质下降空间。**但必须先实测目标品种的 σ 再决定**：建议门槛 `σ≤4pp/期`，达不到就不进入正式试验。 |

### 4.2 关于「数据长度不足以判断」

- **不能**下「策略没有 alpha」的结论：无证据不等于证据不存在，`t=0.668` 的置信区间仍包含正效应。
- **可以**下「在现有样本与 α*=0.0025 口径下，+1.17pp/期 与噪声不可区分」的结论；且原因是**效应量相对噪声太小**，不是单纯的样本长度。
- 因此不应把「等数据变长」当作行动方案，也不应把「不显著」直接写成「因子无效」。

### 4.3 建议的下一步

1. **停**：不在当前个股 Top15 链上继续加因子或调参（功效 4.04%，预算已用 3/20）。
2. **转**：用同一套滚动前推框架，先对 ETF / 行业轮动候选做 σ 与 MDE 核算；只有 `σ≤4pp/期` 才进入正式试验，试验预算另开一轮并重新声明 N。
3. **留**：现有链保留为「低频、低仓位、非满仓」产品候选，按绝对收益与回撤考核，不再对外宣称统计显著的超额。
4. **可并行但不能替代**：若要继续研究因子有效性，改用**截面池化检验**（每天数千只股票，样本量以万计）可以提高对 IC 的检验功效；但它回答的是「因子有没有信息」，不是「Top15 组合扣成本后能否赚钱」。按 `docs/策略调优纪律_2026-11-11.md` §5，IC 不得作为选参数的目标函数，因此这条路只能用于因子初筛，不能替代策略显著性检验。

## 5. 复现命令

在仓库根执行（只读计算，不写任何文件）：

```powershell
.venv\Scripts\python.exe -c "
import math
from scipy import stats
alpha = 0.05 / 20          # α* = 0.0025 双侧
n = 81                     # 设计独立样本
df = n - 1
tc = stats.t.ppf(1 - alpha/2, df)   # 3.1220
zp = stats.t.ppf(0.80, df)          # 0.8461
# σ：由 h=20 mid 行的 Δ=0.1872pp、t(NW1)=0.180、56 个出单日反推（NW 上界）
sigma = 0.1872 / 0.180 * math.sqrt(56)
delta = 1.1708             # 待检验效应量（A 档，任务给定）
mde = (tc + zp) * sigma / math.sqrt(n)
print('tcrit', round(tc, 4), 't80', round(zp, 4), 'sigma', round(sigma, 4))
print('MDE pp/期', round(mde, 4))
print('算术年化 %', round(mde * 12.6, 2))
print('复利年化 %', round(((1 + mde/100) ** 12.6 - 1) * 100, 2))
ncp = delta * math.sqrt(n) / sigma
print('power@n=81', round(stats.t.sf(tc, df, ncp) + stats.t.cdf(-tc, df, ncp), 4))
for target in (0.5, 0.8):
    for nn in range(10, 6000):
        tc_n = stats.t.ppf(1 - alpha/2, nn - 1)
        p = (stats.t.sf(tc_n, nn - 1, delta * math.sqrt(nn) / sigma)
             + stats.t.cdf(-tc_n, nn - 1, delta * math.sqrt(nn) / sigma))
        if p >= target:
            print('power', target, 'n', nn, 'years_h20', round(nn * 20 / 252, 1))
            break
# 交叉核对：把给定的 h=60 对直接反推
print('sigma_h60_n20', round(1.1708 / 0.668 * math.sqrt(20), 4))
"
```

预期输出：`tcrit 3.122 t80 0.8461 sigma 7.7826` / `MDE pp/期 3.4314` / `算术年化 % 43.24` / `复利年化 % 52.97` / `power@n=81 0.0404` / `power 0.5 n 409 years_h20 32.5` / `power 0.8 n 665 years_h20 52.8` / `sigma_h60_n20 7.8383`。
