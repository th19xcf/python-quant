# 自学习第一阶段：L1 参数自适应 vs L2 因子权重学习

> 生成日期：2026-11-03　口径：后复权、T+1 开盘建仓、停牌/涨跌停不可成交、volume=手、amount=元

## 0. 结论

按 2018–2026 年的样本外滚动回测，这套自学习是**赚钱的**：扣掉交易成本后，因子加权组合年化约 8%–10%、最大回撤约 36%–37%，比“因子等权”（年化约 -12%、回撤约 73%）有本质改善；推荐先采用 L2 的 IC 加权（年化 10.11%、回撤 35.87%），L1 状态自适应虽然年化约 11.35%，但回撤更大（约 43.60%）、稳定性证据不足，暂不作为交易建议的依据。

**推荐采用：L2 因子权重学习（IC 加权，半衰期 126 个交易日）。** 在 13 个样本外窗口里，该方案年化 10.11%、回撤 35.87%；静态 IC（只在首个训练窗拟合一次）年化 7.94%、回撤 36.97%，与滚动版本相差 2.2 个百分点，尚在单次回测的噪声范围内，因此以滚动版本为默认、静态 IC 作为更简单的兜底。

**L1 参数自适应：保留为研究分支，暂不上生产。** 它年化 11.35%、回撤 43.60%，横截面 IC 为 0.039（L2 约 0.080）；按波动率 × 趋势切出的状态桶后，每个状态可用于选参的训练样本有限，当前更像阶段性有效，还不足以支撑稳定推荐。

**还撑不住的：** LightGBM 对照因可选依赖未安装而未参与评估；滚动 Ridge 当前 IC 0.053、年化 8.27%，不如 IC 加权；等权组合成本后年化 -12.10%，说明这 12 个原始因子里多数方向是反的，不能直接等权使用。

**读表提醒：** 前瞻收益标签跨 10 个交易日，逐日 IC 存在重叠，表中的 t 值与 ICIR 会高估显著性；判断方案优劣请以 5 分组单调性和扣费后的组合收益/回撤为主。

## 3. L1 参数自适应（样本外）

按波动率分位（低/中/高）× 趋势方向（上/下）分档，在每个训练窗内用各状态的历史超额收益选择动量回看参数与方向；测试窗按当日状态取参。「固定参数-全样本最优」使用全样本信息，仅用于展示过拟合风险。

结论要点：状态自适应把固定默认参数的 -10.88% 拉回到 11.35%，并略高于含未来信息的「全样本最优」（9.42%），说明按状态切换方向/回看窗口确实抓到了样本外的风格变化，IC 只有 0.039、回撤 43.60%，每个状态的有效训练样本有限。

## 7. 纪律、局限与复现

- 样本外：滚动窗训练、embargo ≥ 持有期、训练标签按 ``t+1+H`` purge，测试窗内不重新拟合也不回看未来。
- 组合成本：佣金 0.03%（最低 5 元）、卖出印花税 0.05%（按历史时点表）、过户费 0.001%、双边滑点 0.02%。
- 成交约束：停牌（成交量缺失/为 0）不可成交；开盘涨停不买、跌停不卖；退出受阻最多顺延 1 个交易日（只容忍单日停牌），超过即挂单作废（记入 `expired_orders`），不按旧信号成交。
- 局限：股票池按本地列存文件大小抽样并做近期成交额过滤，存在幸存者偏差；不含退市股票；不含日内数据与做空；ETF/基金尚未纳入同一份评估。
- 标签重叠：前瞻收益跨 ``horizon`` 个交易日，逐日 IC 样本重叠，t 值与 ICIR 的显著性被高估；方案取舍以分层单调性和扣费后组合绩效为准。
- 复现命令：

```powershell
poetry run python -m src.quant.learning --limit 600 --start 2018-01-01 --end 2026-10-31
```
