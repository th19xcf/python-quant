# 涨跌停新表切换前置：风控 sector 派生与 legacy 首日口径（2026-11-22）

新表：`data/local_store/meta/limit/daily`（逐股逐日涨跌停/可成交标记）
对拍窗口：2015-01-01 ~ 2026-11-20，5,837 只 / 2,887 个交易日 / 1,188.5 万个股日

## 1. 风控 sector 由 board + ST 派生

此前风控 `PriceLimitTradable` 只认调用方传入的 `Order.sector`，新表要成为唯一
输入时，风控不能再依赖另一条 `resolve_sector(ts_code)` 链路。现改为：

- `Order.sector` 留空 → 由 `Order.board`（交易所板块）+ `Order.is_st` 派生；
- `board` 也缺 → 回退 `ts_code` 派生；
- `Order.sector` 显式传入 → 仍覆盖派生结果，旧调用方行为不变。

派生入口在 `src/core/market_rules.py`：

- `resolve_limit_pct_by_board(board, is_st, trade_date)`：board 先映射到该板块
  代表代码，再走与 `resolve_limit_pct` **同一套** `_resolve_board_limit_pct`
  与 `_apply_st`，不另写档位表；
- `resolve_sector_by_board(...)`：保证
  `PriceLimitTradable.DEFAULT_LIMITS[返回值] == resolve_limit_pct_by_board(...)`；
- board 标签与 `meta/limit/daily.board` 同口径：沪市主板 / 深市主板 / 创业板 /
  科创板 / 北交所。

规则矩阵（`trade_date` 参与创业板改革日判断）：

| board | 常规幅度 | ST 处理 | 风控标签 |
| --- | --- | --- | --- |
| 沪市主板 / 深市主板 | 10% | 收窄为 5% | ST / 主板 |
| 创业板（2020-08-24 起） | 20% | 不收窄 | 创业板 / ST 仍 20% |
| 创业板（改革前） | 10% | 收窄为 5% | ST / 主板 |
| 科创板 | 20% | 不收窄 | 科创板 |
| 北交所 | 30% | 不收窄 | 北交所 |

`tests/test_limit_table_contract.py::test_board_derivation_agrees_with_code`
对 12 组 board×ST×改革日逐组断言 board 派生与代码派生完全相等。

## 2. legacy 首日制度口径

新表原先对 `listing_phase='legacy'` 一律 `can_buy=can_sell=False`。核对制度后
分两段，不能再用「是否触及板块涨跌停」判断（这些股日没有板块涨跌停）：

| 上市日 | 真实制度 | 本表口径 |
| --- | --- | --- |
| `< 2014-01-01` | 新股上市首日不设涨跌幅限制 | 可买可卖只由停牌决定，价格列留空，`limit_basis='new_stock_legacy_no_limit'` |
| `>= 2014-01-01` 且早于板块注册制改革 | 首日有效申报价格区间为发行价的 64%~144%（+44%/-36%），涨跌幅相对**发行价**而非前收盘 | 本地无发行价，无法复算边界，保留双禁，`limit_basis='new_stock_legacy_unpriced'` |

关键事实：对拍窗口内的 1,584 个 legacy 股日全部落在 2014 年之后，属于
「发行价 64%~144%」制度，不是「无涨跌幅限制」。它们双禁的原因是数据缺口
（`stock_basic` 无发行价、行情首日 `pre_close` 为空），不是制度结论；补全
发行价后应改为按 144%/64% 判定，而不是继续双禁。`manifest.caveats` 已写明。

对回测的影响：这 1,584 个 legacy 股日维持保守双禁（拒绝成交）；2014 年前
的 legacy 首日改为可按实际价成交。对拍策略（MA(5,20)、47 只）在这些股日
无订单，A/B 成交笔数与金额均为 0 差异；若未来策略参与新股首日，双禁会
低估可成交性，属保守偏差，不会产生虚假成交。

## 4. 是否具备切默认条件

规则层已具备：翻转只剩 legacy/exempt 两类可解释项，residual 归零，风控
sector 可由 board+ST 派生且与幅度规则同源。

切默认前仍需明确一件事：是否接受 2014 年后 legacy 首日因缺发行价而保守
双禁；若不接受，需先补发行价并按 144%/64% 重建新表。本次**未切默认输入**。
