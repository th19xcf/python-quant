## 3. 口径差异

| 差异点 | A 侧（src/alpha） | B 侧（factor_lib） |
| --- | --- | --- |
| 布林位置公式 | `(close - MA_{t-1}) / (2·STD_{t-1})`，窗口整体错位一期 | `(close - MA_t) / (2·STD_t)`，含当日 |
| 标准差自由度 | `ddof=0`（总体标准差） | `ddof=1`（样本标准差） |
| 首个有效行 | 前 20 行缺失 | 前 19 行缺失，第 20 行即有效 |
| 结果关系 | 与 B 侧**不构成固定倍数**，任何强行对齐都会破坏现有取值 | 同左 |

差异来自「窗口错位一期 + ddof 0/1」两处叠加，不是单一系数，因此不能靠乘除换算。

### 不可对齐的测试证据

- `tests/test_indicator_consistency.py:559-565`：`test_boll_position_two_conventions_are_not_two_times`
  断言 `|2*A - B| < 1e-6` 在同一序列上命中 0 行（最小差值 0.0533），真实全市场数据命中率同样为 0.0%，
  并明确「任何『对齐』都会让本用例变红」。
- `tests/test_indicator_consistency.py:530-556`：分别锚定 B 侧 `tech_boll_pos_20` 的期望值
  （`got[19] == 0.6775…`、`got[59] == 0.9695…`），确认 B 侧为 contemporaneous + ddof=1。
- `src/alpha/factors/technical.py:66` 的注释亦复述了 B 侧公式，说明两套口径差异是已知设计而非笔误。
