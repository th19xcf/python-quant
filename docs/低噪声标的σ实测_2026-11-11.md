## 0. 口径与两个容易混淆的 σ

### 0.1 计算口径

| 项 | 取值 |
|---|---|
| 频率 | 月末收盘（月频，1 期 ≈ 20 个交易日，与 h=20 对齐） |
| 价格 | ETF 用 `close × hfq_factor`（后复权，含分红）；指数用 `close` |
| 月历 | 以 `000300.SH` 每月最后一个交易日为准；标的该月最后一条记录必须等于月历日，否则该月不计 |
| 未完成月 | `2026-11` 最后交易日 = 11-11 < 11-30，已剔除；数据止于 2026-10-30 |
| 收益 | `r_t = P_t / P_{t-1} − 1`，单位 pp |
| σ | 样本标准差（`ddof=1`），单位 pp/期 |
| 数据源 | `data/local_store/quotes/{fund,index}/{sh,sz,bj}`、`data/local_store/meta/{fund_basic,index_basic}.parquet` |

### 0.2 两个 σ 不是一回事（本节是全文的关键前提）

| | 定义 | 用途 | 量级 |
|---|---|---|---|
| **σ_abs** | 组合**绝对收益**序列的标准差 | 描述这只组合本身有多颠 | ETF/宽基 5~6pp，行业 6~8pp |
| **σ(Δ)** | **Δ 序列**（规则组合 − 同日随机组合）的标准差 | **MDE 公式里那个 σ** | 宽基 2.3~3.2pp，行业 5.3~6.2pp |

`docs/因子选股功效核算_2026-11-11.md` 里的 σ=7.7826pp 是**后者**（由 h=20 mid 行 `Δ=0.1872`、`t=0.180`、`n=56` 反推），不是个股组合的绝对波动。

**为什么必须分开**：规则组合与同日随机组合共享同一批市场 beta，市场涨跌在相减时抵消。所以 `σ(Δ)` 通常明显小于 `σ_abs`。用 `σ_abs` 直接套 MDE 公式会**高估门槛**。§2 给 `σ_abs`（按任务要求），§3 给 `σ(Δ)`（真正该对准的门槛）。

## 3. σ(Δ) 实测：MDE 真正要的那个 σ

方法：在每个月初，用过去 `mom` 个月收益排序，取前 K 只等权持有下一个月；同日从**同一可投域**随机抽 K 只（B=200 次，种子 7）取均值；`Δ_t = 规则组合_t − 随机组合_t`。
σ(Δ) 由 Δ 序列算。这不是在找有效策略，只是给「K 选 1 的跟踪误差」一个实测值——**σ(Δ) 主要由可投域的截面离散度和 K/池子大小决定，对排序信号本身不敏感**，所以用动量只是拿一个具体实例去测。

要点：

1. **宽基指数轮动的 σ(Δ) 只有 2.35~3.13pp**，全部低于 4pp。原因是宽基之间高度同涨同跌，选 5 只和随机选 5 只的差别很小（σ(rand)≈5.0，σ(rot)≈5.4~5.7）。
2. **行业指数轮动的 σ(Δ)=5.34~6.16pp**，比 4pp 高 34%~54%。行业之间离散度大，选错就是真差。
3. **ETF 全池轮动的 σ(Δ)=6.03~8.98pp，最差**。这一档没有剔除债券/货币 ETF（与 §6.1 的 `ETFEQ` 行不同），是「全池」口径。因为 900+ 只 ETF 里有大量跟踪同一指数、以及跨境/商品类，随机篮子本身噪声就大；2022+ 池子扩到 621 只后 σ(Δ) 升到 7.59~8.98。
   把债券/货币剔掉只会更差、不会更好：同池的 σ_abs 已经从 7.22 升到 7.46（全历史）、5.01 升到 5.45（2019+），所以这里的 ETF 全池 σ(Δ) 可以当作**乐观读数**。
4. 规则本身在这三个池上都没有信号（Δ 均值 −1.27~+0.09，|t| 全部 <1.8）。**本节只测 σ，不测 alpha**；Δ 均值为负不能推出「轮动无效」，只能说明这个 3~6 月动量规则没抓到。

### 3.2 为什么 σ(Δ) 比 σ_abs 小

以宽基 16、2019+、K=5 为例：σ(rot)=5.42、σ(rand)=4.99、反解相关系数 ρ=(5.42²+4.99²−2.52²)/(2×5.42×4.99)=**0.89**，`σ(Δ)=√(5.42²+4.99²−2×0.89×5.42×4.99)=2.52`。同日市场涨跌是共同项，相减后基本消掉，剩下的是「选股差异」那一小块。
**个股链的 σ(Δ)=7.78pp，恰恰因为它选的是 15 只个股、个股特质波动不会被另一组 15 只个股抵消。**

## 4. 对准门槛

### 4.1 MDE 换算（N=20，α*=0.0025，80% 功效，df=n−1）

```
MDE = ( t_{1-α*/2, n-1} + t_{0.80, n-1} ) × σ / √n
```

任务给的两条基准线复核后一致：`σ=4pp, n=81 → 1.7636pp/期（算术 22.2%）`；`σ=3pp, n=81 → 1.3227pp/期（16.7%）`。

### 4.4 压到 4pp 以下的三条路，哪条真有用

| 手段 | 效果 | 是否真正提高检验功效 |
|---|---|---|
| **加宽分散**（K 从 5 → 10） | 880 行业 6.16 → 5.37 | **是**。分散降低跟踪误差，且不改变效应量级（若规则真有 alpha） |
| **换品种**（行业 → 宽基） | σ(Δ) 5.37 → 2.35 | **是，且是最大的一档**。宽基间相关性高，但可实现的 Δ 也同比变小，见 §5.2 |
| **降频**（月频 → 季度） | σ(Δ) 随持有期约按 √h 增长 | **否**。降频减少独立样本、单期方差变大，MDE 反而升（见 `docs/因子选股功效核算_2026-11-11.md` §3.2） |
| **加债券/黄金降波动**（股票 70/30） | σ_abs 6.01 → 4.23（2022+） | **否**。仓位同比例缩放，Δ 与 σ 同时 ×0.7，t 不变，MDE 的 pp/期 数字虽降但效应也同比例缩 |

## 5. 结论

### 5.1 直接回答「σ≤4pp 够不够得着」

**分两个口径答，答案相反：**

- **绝对收益 σ_abs：够不着。** 所有纯多头股票池最低是红利 4.67pp（2022+）/ 4.69pp（2019+），差 0.67pp。单只股票型 ETF 达到 4pp 的概率约 1%。只有掺 30%~40% 债券才能到 3.6~4.2pp，但那是缩仓、不提高功效。
- **Δ 序列 σ(Δ)：够得着，但只在宽基上。** 宽基指数轮动 2.35~3.13pp，4pp 门槛全过、3pp 在 2019+ 窗口也过；行业轮动 5.34~6.16pp，差 34%~54%；ETF 全池轮动 6.03~8.98pp，差 51%~125%。

所以「σ≤4pp 这个入场条件」**本身需要改写口径**：它作为 σ_abs 条件永远不成立，作为 σ(Δ) 条件则是一个**品种筛选器**——只放行宽基轮动。

### 5.2 这个改善的代价（必须写明，否则会误导）

宽基轮动 σ(Δ)=2.35pp 的低噪声，来自宽基之间高度同涨同跌（σ(rot)≈5.4、σ(rand)≈5.0、相关≈0.89）。
**同一件事让 Δ 的可实现空间也变小了**：规则组合与随机组合几乎一样，想拉开 2pp/期的差距本身就很难。
实测宽基轮动的 Δ 均值是 −0.32~−0.01pp、t 全部 |t|<0.8，与 0 不可区分。

所以正确的读法是：**门槛降下来了，但能不能跨过去仍是未知**。这是一个可以**被检验**的设置（MDE=0.99~1.05pp/期 ≈ 12.5%~13.2%/年），而不是一个**已被证明有 alpha** 的设置。
相比之下，行业轮动的 MDE=2.23~3.30pp/期（28%~42%/年），要求太高，几乎不可能被任何真实规则跨过。

### 5.3 能不能在现有数据上开一轮正式低噪声试验

**能，但候选池必须限定为宽基/红利，不能是行业或 ETF 全池。**

| 项 | 建议 |
|---|---|
| **候选池** | 宽基可投资子集 16 只（§1.1 清单） |
| **可选层（落地）** | 对应的宽基 ETF（`510050` / `510300` / `510500` / `512100` / `159915` / `588000` / `159922` 等），ETF 与指数跟踪误差需单独核 |
| **K** | 5（σ(Δ)=2.35~2.52pp，n=91）。不要用 K=10：池子只有 16 只时集中度过高 |
| **样本区间** | **2019-01 ~ 2026-10**（n=91，σ(Δ)=2.35~2.52pp）；2022+ 只有 n=55、σ(Δ) 升到 2.93~3.13pp，只作稳健性 |
| **门槛** | N=20、α*=0.0025 不变 → `t*>3.11`；MDE≈**1.0pp/期**（12.5%~13.2%/年） |
| **成本** | 沿用 0.724%/往返；ETF 一次往返按同口径，若实际更低需注明 |
| **不需要的** | 不需要新数据；`quotes/index/*` 与对应 ETF 行情已齐全 |

**不建议开的两个池**：
- **行业轮动**：σ(Δ)=5.34~6.16pp，MDE 2.23~3.30pp/期（28%~42%/年），在没有多空对冲的情况下不可能达标。
- **ETF 全池**：σ(Δ)=6.03~8.98pp，比行业更差；主因是 900+ 只 ETF 里大量重复跟踪与跨境/商品，随机篮子噪声被放大。

### 5.4 缺什么数据、要不要补

| 缺口 | 影响 | 要不要补 |
|---|---|---|
| `880xxx → 行业 ETF` 映射表 | 行业轮动只有不可交易的板块指数，无法落地 | **不补**。行业轮动已在 σ(Δ) 上被判不达标，补了也用不上 |
| 行业指数元数据（`category=行业` 只登记 1 只） | 无法从元数据筛行业指数 | **不补**。通达信 880 已覆盖，且该池不进入试验 |
| 股指期货 / 融资融券数据 | 无法做多空中性，无法把 σ_abs 压到 2pp 以下 | **看后续**。若宽基轮动试验被证明有 Δ>1pp 的迹象，再考虑用 IF/IC 对冲把 σ(Δ) 进一步压到 1pp 量级 |
| 宽基 ETF 与指数的跟踪误差 | ETF 落地层可能与指数层有偏差 | **建议开工时顺手核**，不阻塞 |
