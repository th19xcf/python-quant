## 一、结论三句

1. **4 个因子按统计口径全部可用**（|ICIR|≥0.30 且 |t|≥2）：`turnover_20` IS ICIR **+0.921**（t +9.03）、`accruals` **-0.414**（t -4.05）、`sue` **+0.434**（t +4.25）、`roe_stability` **+0.361**（t +3.54）。OOS 同向但衰减（`sue` OOS ICIR +0.197、`accruals` -0.459）。
2. **按"增量"看只有 `sue` 与 `accruals` 提供了价量簇之外的新信息**：对 23 个价量因子正交后，`sue` IS ICIR **+0.834**（t +8.17）、OOS **+0.380**（t +2.55）；`accruals` IS **-0.422**（t -4.13）、OOS **-0.259**（t -1.74）。`turnover_20` 正交后只剩 **+0.002**（t +0.02），`roe_stability` 只剩 **+0.073**（t +0.71）——这两个基本是重复押注（`turnover_20` 与 `atr_pct`/`volatility_20` 秩相关 -0.694/-0.678，`roe_stability` 与 `ff_value_ep` +0.536）。
3. **这批因子补不上动量线的收益缺口**：中性化分位多头相对同月样本内等权的超额，IS 最高是 `turnover_20` **+12.22%**（t +6.39），`sue` **+5.19%**（t +2.71）、`accruals` **+2.72%**（t +2.16）、`roe_stability` **+1.66%**（t +1.27）；OOS 最高为 `turnover_20` **+11.99%**（t +2.78）。量级在 2~12pp、且 OOS 不稳，**不能把多空差（如 `turnover_20` Q5−Q1 IS +26.27%）当可实现收益**。

### 2.1 财务因子的可用起点（新口径已回补到 2015）

新口径重建后，财务历史随面板一并回补，**三个财务因子的首个有效月末均为 2015-01-30**（旧口径为 accruals 2017-01-26 / roe_stability 2018-04-27 / sue 2018-07-31）。因此本文件 4 个因子的 IS 区间统一为 2015-01~2022-12（96 个月），**可以直接横比**，不再需要"组内比较"的免责声明。`sue` 的 IS 覆盖仍最低（82.75%），原因是部分标的季节差分不足 8 期。

### 2.2 因子定义（逐条对齐任务书）

| 因子 | 计算 | 方向 |
|---|---|---|
| `turnover_20` | 日 `volume(手)×100 / 当期流通股本(股)` → 20 日均值（`min_samples=15`）→ 月末取值 → **取负** | 正 ICIR 表示低换手更好 |
| `accruals` | `(归母净利TTM − 经营现金流TTM) / 总资产`，取 T 时已公告的最近一期；`pub_date = max(三表 ann_date)` | 负 ICIR 表示低应计更好 |
| `roe_stability` | `ROE_TTM = 归母净利TTM / 期末归母权益`；取 T 时已公告最近 8 期（≥6 期有效）的 `均值/标准差` | 正 ICIR 表示越稳越好 |
| `sue` | 单季归母净利 `Q_t`；`_d = Q_t − Q_{t-4}`；取 T 时已公告最近 8 个 `_d`（≥6 个有效）的 `std` 作分母，分子为最近一期 `_d` | 正 ICIR 表示盈余超预期越好 |

严格 TTM：`TTM = 本期累计 + 上年年报 − 上年同期累计`，且上年年报与上年同期累计的公告日都必须 ≤ 本期公告日，否则该期 TTM 置 null。

## 八、这批因子能否补上收益缺口

### 8.1 匹配样本的可实现多头对照

口径：中性化分位 Q5（`accruals` 取 Q1）等权复利年化，减同月样本内等权年化；IS 样本内等权 **18.90%**、OOS **8.56%**。

> `turnover_20` 的 IS +12.22pp 最高，但它是"低换手 + 低波 + 小市值"的合成暴露，且正交后没有增量；`sue`/`accruals` 的 2~5pp 更接近真实增量，仍不足以把一条负超额策略推过 +5%。

### 8.2 定性判断

- 4 个因子合计最多提供 **2~5pp** 的年化增量（扣除混合与成本后更低），**补不上动量线 7pp 以上的负超额**。
- 真正值得保留的是 `accruals` 与 `sue`（正交后显著），`turnover_20` 只作确认项，`roe_stability` 不入模。
- 多空差（`turnover_20` Q5−Q1 IS +26.27%）不是可实现收益，不能拿来补缺口。
