## 2. 盘点：依赖顺序与重建方式

依赖链（每层只吃上一层结果）：

```

 ├─ meta/daily_index                     （layer 0，前序已刷新）
 ├─ factors/stock_adj_factor（内嵌 qfq/hfq，回写 000016 行情列）
 │   ├─ factors/stock_turnover（baostock 派生，不重算）
 │   ├─ meta/suspension/suspension_daily → meta/universe/listing_intervals / stale_status
 │   ├─ meta/universe/universe_price_jumps / universe_exclusions
 │   ├─ meta/breadth/breadth_daily → breadth_ma_daily

 │   └─ meta/universe/layers L0→L5
```

重建方式一律是**外科补丁**：以「17 只修复前备份 vs 当前」的逐日贡献差（或旧表基线 + 原位掩码）落到正式表，**不跑全量重建**。原因：今日 13:09 坏 bar 剔除、20:00 pre_close 修补、20:29 1992 板块重排等他路改动已进入行情，全量重建会把它们的漂移一并写进历史（实测 `breadth_daily` 全量候选残差 5,801 行、`listing_intervals` 会改 9,410 只…），违反「非目标行 0 改动」。

备份：每层重建前把现有正式目录整体移到 `_backup/derived_1993b_20261113/<层>/` 并回拷，移动前后逐文件 SHA256 一致（`layer*_before_sha.json` / `layer5_prepare.py` 断言）。换手表单独备份到 `_backup/factors_turnover_1993b_20261113/`（`before.json` 含 SHA/bytes/rows）。

## 6. 000016.SZ 复权因子：可复算推导与结论

除权事件 1993-05-03：`cash_div=0.09`、`share_div=0.35`（10 送 3.5 派 0.9）、无配股（`rights_ratio=0`）。口径（`src/data/adj_factor_calculator.py::calc_dividend_event_factor`）：

```
factor = (prev_close − cash_div + rights_price×rights_ratio) / (prev_close × (1 + share_div + rights_ratio))
       = (prev_close − 0.09) / (prev_close × 1.35)
```

- 旧：`prev_close = 17.45`（修复前 05-03 的前一行是 05-02 合成 bar）→ `factor_old = (17.45−0.09)/(17.45×1.35) = 0.7369203013902154`，`1/factor_old = 1.3569988479262673`
- 新：`prev_close = 24.75`（04-30 真实收盘）→ `factor_new = (24.75−0.09)/(24.75×1.35) = 0.7380471380471381`，`1/factor_new = 1.35492700729927`
- 比值：`factor_new / factor_old = 1.0015291160452453`
- qfq 侧（除权日前累乘 factor）：`0.06573112549054977 × 1.0015291160452453 = 0.0658316360092094`
- hfq 侧（除权日及之后累乘 1/factor）：末值 `15.21349273326791 → 15.190265055240413`（同比例反向）
- 影响区间：qfq 274 行（1992-03-27 ~ 1993-04-30，单值）、hfq 7,915 行（1993-05-03 ~ 2026-09-03，全部后续累积因子同比例缩放）

**方向更正**：调用方描述为「0.065832 → 0.065731」，实测方向相反，是 `0.065731 → 0.065832`（因子比值 1.001529 > 1，qfq 略增）。

**旧 05-03/05-04 内嵌因子错值成因**：合成 bar 插入时 `prev_close` 取到 05-02 合成行（17.45），把除权因子算成 0.736920；属**更早的错**，不是本次日期重排造成的。本次 layer 1 已随之修正，故不再另立缺口，作为独立归因条目记在本节，不计入「1993-05 删行」账。
