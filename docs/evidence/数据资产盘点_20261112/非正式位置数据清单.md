## 0. 口径与测量方法

| 项目 | 口径 |
|---|---|
| 文件数 / 体积 | `os.walk` 实测，排除 `__pycache__/`、`*.pyc`、`*.pyo`（字节每次重新生成，计入会制造假差异，与项目规则一致） |
| 日期起止 | ① parquet 有 `date/trade_date/notice_date/publish_time/announce_date/month` 等列时，用 `pyarrow.compute.min/max` 实测；② 文件名含 `YYYYMMDD` / `YYYY-MM-DD` 时取 min/max；③ 文件名带 `YYYYMM` 月度分片按月份报；④ 备份/快照类无业务日期，报「不适用」 |
| 是否被 `.gitignore` 覆盖 | 逐条对照 `.gitignore` 实际行号；「已跟踪」另用 `git ls-files` 实测 |
| 是否已镜像 `G:\git\python-quant` | **实测**：相对路径集合差 + 逐文件大小差 + 抽样逐文件 SHA256，不采用历史结论 |
| 只在本机一份 | 判定为「不在 Git 且不在 `G:` 镜像」；`E:\www\tmp` 本身在仓库外，天然无 Git |
