# 场内基金「hfq 未反映除权」75 事件查证（只读）

> 任务：查清已补 78,999 行里 75 个「`hfq(t)/hfq(t-1)=1.0` 而前收链比例≠1」事件的真实性质，给出可复核证据。
> 硬约束：只读，不改任何行情/因子文件、不跑回测、不提交。**不得用前收链比例自行推定性质**。
> 结论日期：2026-11-10

## 1. 判定（先给结论）

| 判定 | 数量 | 含义 |
|---|---|---|
| **有证据支持「hfq 漏记折算」** | **0 个** | 没有一个事件能用公告、份额变动或净值复位证明「该日确实除权而 `hfq_factor` 未动」 |
| 证据充分且表明 hfq **已经正确** | 21 个（17 强 + 4 中） | 真折算事件，`hfq_factor` 已在当日或复牌日同步跳变 |
| 无公司行为证据 | 54 个 | NAV 无跳变、无折算型份额变位、无分红记录；反证指向 `pre_close` 字段侧缺陷 |

**因此：不建议对本轮 75 个事件改动任何 `hfq_factor`。** 若按「前收链比例」硬改，会动 **66 个行情文件、12,050 行**（见第 6 节），且会把 21 个已经正确的折算点二次翻倍。

真正的缺陷在 `pre_close` 一侧，而不是复权因子一侧：2020-02-26 全市场 **243/761 只（31.9%）** 出现 `pre_close ≠ 上一交易日 close`，而 2020-02-25（745 只可比）与 2020-02-27 均为 **0 只**——这不是「40 只分级基金同日集体折算」，而是该日 `pre_close` 字段的整体性污染（阶段二单独查根因）。

## 2. 口径与取证方法

### 2.1 缺陷口径（沿用既有统计，不重新定义）

对每个事件日 `t`：

- `actual = hfq_factor(t) / hfq_factor(t-1)`（本地行情文件内相邻两行）
- `chain  = prev_close(t) / pre_close(t)`（`prev_close` = 本地上一根 bar 收盘，`pre_close` = 上游前收盘）
- `gap    = pre_close(t)/prev_close(t) - 1`
- `|actual/chain - 1| > 1e-4` 判为偏差；`actual == 1.0` 即「hfq 未反映」

75 事件 / 66 只标的，其中 57 个事件 `actual` 恰为 1.0。

### 2.3 判定规则（先定规则再看数据，避免「按比例凑结论」）

- **折算确认**：`unit_nav` 单次跳变 `x<0.62` 或 `x>1.62`（上折≈x0.5、下折≈x4），或取得公告/拆分记录直证。
- **hfq 已同步**：事件日（或复牌首根 bar，±5 根内）`hfq_factor` 出现比值跳变，且该比值与 `chain` 相差 <1e-3。
- **分红**：`fund_div` 或 `fund_dividend.parquet` 的 `ex_date` 落在 ±6 天。
- **无证据**：以上三项全部不成立。此时**不推定**性质，只记录「无证据」。
