# G-074 东财兜底：字段映射表（东财 → 目标 schema）

任务：`2026-11-12/gap-rootcause/work/fetch_g074_eastmoney.py` 用东方财富公告接口补巨潮空响应月份。
本表是「东财原始字段 → `research/events` 目标九列」的唯一映射口径，代码实现见
`research/events/fetch_announcements.py::_em_records`。

接口：`GET https://np-anotice-stock.eastmoney.com/api/security/ann`
必需请求头：东财自有 `Referer: https://data.eastmoney.com/notices/` + 完整 Chrome UA；
沿用巨潮那套头会返回 **567（HTML 挑战页）**，不是 200 空结果。

## 1. 目标 schema（九列，与巨潮分片完全一致）

`keyword, art_code, stock_code, short_name, title, column_name, display_time, notice_date, url`

## 2. 字段映射

| 目标列 | 东财原始路径 | 类型/转换 | 备注 |
|---|---|---|---|
| `keyword` | 无（检索参数） | 常量 `'股权激励'` | 与巨潮分片同值，保证后续按关键词聚合不分叉 |
| `art_code` | `data.list[].art_code` | str 原样 | **东财体系 `AN202102011457151278`，与巨潮数字 `1209233491` 不互通**；跨源不得当去重键 |
| `stock_code` | `data.list[].codes[].stock_code` | str，过滤 `ann_type` 以 `A` 开头、6 位纯数字 | 一个 `art_code` 可能挂多个 `codes`（A/B/H 股），只取 A 股 |
| `short_name` | `data.list[].codes[].short_name` | str 原样 | 与 `stock_code` 同源取，避免 A/B 股名称串行 |
| `title` | `data.list[].title` | `html.unescape` + 去标签 + strip | 东财标题**带「股票简称:」前缀**，巨潮不带；跨源按标题精确匹配必然为 0 |
| `column_name` | `data.list[].columns[0].column_name` | 取首个分类 | 东财自有分类（如「股权激励进展公告」「法律意见书」），巨潮该列为空串，两侧不可直接对齐 |
| `display_time` | `data.list[].display_time`（毫秒）回退 `eiTime`（秒） | `_parse_display_time` → `datetime`；两者皆空则 `None` | 事件研究真正读取的时间戳；历史数据可能为空/偏移（见模块 docstring） |
| `notice_date` | `data.list[].notice_date` | 取 `[:10]` | 东财 `notice_date` 常比真实发布晚 1 个自然日，只可作为日期级对齐键 |
| `url` | 无（拼接） | `https://data.eastmoney.com/notices/detail/{stock_code}/{art_code}.html` | 与巨潮 `static.cninfo.com.cn` 域名不同，消费侧不得假设同一域名 |

## 3. 跨源对齐口径（对拍结论，实测）

| 键 | 可用性 | 实测（2021-02） |
|---|---|---|
| `art_code` | **不可用** | 两源命名体系不同，`both=0` |
| `(stock_code, title)` | **不可用** | 东财带简称前缀、巨潮不带，`both=0` |
| `(stock_code, notice_date)` | **可用** | 巨潮 15 个唯一对全部被东财覆盖（`only_cninfo=0`），东财多出 72 个 |

因此跨源去重一律用 `(stock_code, notice_date)`；同源内部去重仍用 `art_code`。

## 4. 已知口径差异（不改，只登记）

1. 东财 `title` 为**标题模糊检索**，召回面比巨潮 `searchkey` 全文检索宽：同一
   2021-02 区间东财 110 条 / 巨潮 17 条，且 20 条人工抽检全部为真实股权激励公告，
   未见误召回 —— 差异是**召回率**，不是正确性。
2. 因此「用东财补巨潮缺页」在语义上不是等量替换，而是**口径放宽**。凡引入东财行的月份，
   须在缺口表与结论文档登记该月为「东财口径」，不得与纯巨潮月份在无标注情况下混算。
3. 逐条来源写侧车 `_staging/events_g074_20261112/source_map.csv`
   （`month,dedup_key,source`），主表**不加整行标记列**。
