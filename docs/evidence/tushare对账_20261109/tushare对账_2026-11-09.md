## A.2 裁决锚点（不依赖任何一方）

除权日交易所强制把「前收盘价」置为官方除权除息参考价：

```
pre_close_ex = (prev_close - D) / (1 + 送转比例)
⇒ D = prev_close - pre_close_ex × (1 + 送转比例)
```

`prev_close` / `pre_close_ex` 取自 tushare `daily`（交易所行情快照，独立于其 `dividend` 表），送转比例取该除权日全部「实施」行的 `stk_div` 最大值（更正行常把 `stk_div` 置 0，取 max 更稳）。该式**不含任何行情噪声**，精度仅受报价分位（±0.01）与送转比例影响。
