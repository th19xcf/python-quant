判定：**1,171 条均非数据错误，也非缺事件**。`AdjFactorCalculator.calculate_factors` 用
`pos = searchsorted(trade_dates, ex_date, side='left')` 把事件映射到「第一根 `trade_date >= ex_date` 的 bar」，
除权日当天若该股无 bar（停牌、或全市场非交易日），因子步长必然落在除权后首根 bar，与 ex_date 不可能是同一天。

## 1. 口径与复算

- **步长定义**：`stock_adj_factor` 按 `(ts_code, trade_date)` 排序后，`hfq_factor / hfq_factor.shift(1) != 1`（阈值 `1e-9`）。合计 58,299。
- **同日命中**：`stock_dividend` 去重 `(ts_code, ex_date)` 共 59,409 个事件，与步长按 `(ts_code, trade_date)` 精确等值连接，命中 57,128。
- **事件因子**（`src/data/adj_factor_calculator.py:24-70`）：
  `factor = (prev_close - cash_div + rights_price*rights_ratio) / (prev_close*(1+share_div+rights_ratio))`，
  `hfq` 在 ex_date 及之后累乘 `1/factor`；`prev_close` 取 `prev_bar` 的 close。同日多行先按 `merge_same_day_events` 合并。
- **归因判据**：对每条未命中步长，取窗口 `prev_bar < ex_date <= 步长日` 内的事件，按上式算 `implied_ratio = 1/∏factor`，与实测 `hfq_ratio` 比相对误差。
  - `ex_date` 不在全市场交易日历（`index/sh/000001.SH` ∪ `index/sz/399001.SZ` 的日期并集）→ `A1`；
  - 在日历内 → 该股当日停牌 → `A2`。
- **复算命令**（仓库根，全部只读）：

## 3. 三个疑因的排除（均给出可复算判据）

### 3.1 「送转/配股缺 ex_date」→ 不成立

- 934 只标的中确有 **101 行** `ex_date` 为空的分红记录，其中 **64 行**参数非零（53 只）；但本批 **1,171 条步长全部已由「有 ex_date」的事件逐位解释**（`rel_diff` 最大 4.44e-16），没有一条需要依赖缺日期行。
- 判据：若某步长由缺 `ex_date` 的事件产生，则窗口 `prev_bar < ex_date <= 步长日` 内不会有事件、`implied_ratio` 为空 → 归入 `C_窗口无可用事件`；实测 `C` 类 **0 条**。

### 3.2 「股本变动误触复权」→ 不成立

- 复权因子只由分红事件驱动。抽样 30 只（幅度前 10 只 + 每 40 只取 1 只）用 `AdjFactorCalculator.calculate_factors` 仅凭「行情 close + 分红事件」重算，与存量 `hfq_factor` 逐行比对：**30/30 完全一致（最大绝对差 < 1e-9）**。
- 若存在「股本变动触发」的步长，重算结果会缺少该步长，必然对不上；实测无此现象。

### 3.3 「行情价格跳空被误算成跳变」→ 不成立

- 步长定义在 `hfq_factor` 上，与 close 的跳空无关；上条重算已证明因子序列可由事件完全复现。
- 反向核对：`C_窗口无可用事件` 0 条，即不存在「有价格跳空、无事件」的步长。

## 5. 修法建议与影响面

1. **不改数据**（推荐，1,171 条占比 2.01%，比率与事件逐位一致，改任何一条都会破坏「因子=事件推导」这条唯一口径）。
2. **改验收判据的表述**：`docs/evidence/data_lineage_governance_20261113/b2_slice4_check.md` §5.2 的
   `prev_bar < ex_date <= step_date` 已是正确口径，本报告为其补充「同日命中率 97.99%、其余 2.01% 全部为停牌/非交易日顺延」，
   避免后续审计把「1,171 未命中」重新当成缺口立项。
3. **消费侧口径**：凡按 `trade_date == ex_date` 精确 join 计算「除权当日收益/换手」的路径，在这 1,171 天会漏事件；
   应改为「取 `ex_date` 之后第一根 bar」或按 `prev_bar < ex_date <= trade_date` 匹配。影响 934 只标的、1,171 个交易日。
4. **无需补事件源的类别**：本次 `C` 类为 0，故不存在「必须先补事件源才能重算」的部分；若将来出现 `C` 类，再按 DG-16 逐字段取证。
