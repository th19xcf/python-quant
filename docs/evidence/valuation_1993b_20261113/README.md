1. `1993-05-01` 是周六、`1993-05-02` 是周日，而 `05-03`~`05-07` 恰好是周一到周五。
2. 本地行情 `quotes/stock/sz/000018.SZ.parquet` 的 1993 年 250 行里**周六 0 行、周日 0 行**，窗口内只有 `04-26~04-30`、`05-03~05-07`、`05-10`，没有任何周末行——1993 年不存在周末交易。
3. 两只代码的 `05-01`/`05-02` 行 `vol × close == amount` 逐值成立，不可能是「不存在的交易日」凭空产生的记录。

2. TDX 的**日期标签不可信**：前两行标成周末（真实是 `05-03`/`05-04`），`05-04`/`05-05` 标早 1 天（真实是 `05-05`/`05-06`），只有 `05-07` 落在真实交易日上。它能提供的可信信息只有 5 个 `(close, vol, amount)` 元组，**日期必须以本地行情为准、按顺序对齐**。
3. valuation 原始表沿用了这条错轴：2026-11-12 删掉 `05-01`/`05-02` 两行（它们承载的其实是 `05-03`/`05-04` 的报价）后，`05-04`/`05-05` 两行仍保留着 `05-05`/`05-06` 的值，于是表现为「close = 行情次一交易日」。三处实测可复算：

## 八、DG-31 兜底与断言自测

写回用 `pl.when(命中).then(新值).otherwise(原值)` 逐列三表达式，**没有 `coalesce` 无兜底写法**：未命中任何目标键的行一律回写原值。断言侧：

- 空值计数逐列比对（改前 + 新增行应贡献的 null 数），任一列不等即报错并在报错信息里点名列与期望值；
- 自测 1：把 `total_mv` 前 5 行注入 null → 断言如期失败：`total_mv 空值 0 -> 5，期望 0`；
- 自测 2：把 `close` 第 1 行注入 null → 断言如期失败：`close 空值 0 -> 1，期望 0`。

两条自测证明该断言能对「空值从 0 变 N」失败，不是恒真。
