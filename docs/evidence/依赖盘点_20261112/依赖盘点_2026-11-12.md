### 4.1 结论先说：没有任何包落后一个大版本

对 `pyproject.toml` 声明的 35 个包逐一比对（`.venv` 实际 vs PyPI 最新），**major 号全部相同**，最大差距是 `loguru` 的 1 个 minor（`0.7.3 → 0.8.0`）。因此「落后一个大版本以上」这一类为**空集**。

**已知安全公告**：OSV.dev 批量查询 37 个「包名+已装版本」（32 个直接依赖 + 5 个高风险传递依赖），**命中 0 条**。因此这一类也为**空集**。

### 4.3 非主版本落后、但需要单独决策（4 条，附 release notes 原文依据）

**1) `loguru 0.7.3 → 0.8.0`（落后 1 个 minor，2026-11-11 发布）**

Release notes（`gh_Delgan_loguru.json`）里与本项目直接相关的三条：

- 「Change the default log format to include the timezone offset since it produces less ambiguous logs」——**默认日志格式会变**，`src\utils\logger.py` 的 sink 格式与任何断言日志文本的测试都可能受影响。
- 「Fix possible regular expression denial of service (ReDoS) when parsing color markups in strings containing long sequences of backslashes」——安全相关修复（非 CVE 编号，属上游自行加固）。
- 「Fix a `ValueError` raised on Windows when system clock was set far ahead in the future」——**Windows 专项修复**，本项目正在 Windows 11 上运行。
- 另有「Fix `logger.parse()` decoding log files with the locale encoding instead of UTF-8… failed on non-ASCII logs… on Windows」（GBK 中文日志解析失败）与「Add new `logger.reinstall()`」。

**影响**：升级需同步核对 `src\utils\logger.py` 的格式串与任何按日志文本断言的测试。

**2) `scikit-learn ^1.5 → 1.9.1`（未安装，声明下限跨 4 个 minor）**

Release notes：`1.9.0`「adds narwhals as a new dependency」；`1.9.1`「first version supporting Python 3.15」并含若干 bug fix。声明 `^1.5` 允许解析到 `1.9.1`，但 `poetry.lock` 里已锁 `scikit-learn 1.9.1`（说明 lock 已按新版本重算过），本机 `learning` 组未安装。

**影响**：本项目 `learning` 组仅用于 LightGBM 对照，`src\quant\learning` 缺失时自动跳过；启用时才会引入 `narwhals` 这个新传递依赖。

**3) `lightgbm 4.6.0 → 4.7.0`（落后 1 个 minor，lock 仍是 4.6.0）**

Release notes `v4.7.0`：「The Python package now supports `polars` inputs, thanks to `narwhals`」「Significantly improved GPU support including the first ROCm builds」。`pyproject.toml` 钉死 `==4.6.0`，所以 lock 与 `.venv` 都不会自动前进。

**影响**：本项目主力列存是 **Polars**，4.7.0 的 Polars 输入支持对 `learning` 组有直接价值；但 `pyproject.toml` 是 `==` 硬钉，升级必须同时改声明与重生成 lock。

**4) `pandas 3.1.0 → 3.1.1` / `SQLAlchemy 2.1.6 → 2.1.8`（patch 级，风险低）**

- pandas `v3.1.1` release note：「This is a patch release in the 3.1.x series and includes some regression fixes and bug fixes.」
- SQLAlchemy `2.1.7` 新增 `SessionTransaction.connections` / `bound_connection()`（只增 API）；`2.1.8` 的正文**只有发布流程变更**：「All files published to PyPI … now uploaded using PyPI's trusted publishing … include a PEP 740 attestation」，无运行时行为改动。

**影响**：pandas 3.1.1 属回归修复，回归测试可覆盖；SQLAlchemy 2.1.8 基本只有供应链证明（PEP 740 attestation），对代码零影响。
