## 2. 三条实现的细节

### 2.1 V-20：MySQL TLS 开关（默认逐位不变）

改动两处：

- `src/utils/config.py::DatabaseSettings` 新增 `ssl_ca: str = Field(default="")`，并补 `DATABASE__SSL_CA` 的内联配置表行；
- `src/database/db_manager.py::connect()`：把 `create_engine` 实参收进 `engine_kwargs` 字典，**只有 `ssl_ca` 非空才写 `connect_args`**：

```python
engine_kwargs: dict[str, Any] = {
    'pool_size': ..., 'max_overflow': ..., 'pool_timeout': ...,
    'pool_recycle': ..., 'pool_pre_ping': True, 'echo': False,
}
ssl_ca = getattr(db_config, 'ssl_ca', '')
if ssl_ca:
    engine_kwargs['connect_args'] = {'ssl': {'ca': ssl_ca}}
self.engine = create_engine(connection_url, **engine_kwargs)
```

为什么不是「传一个空 `connect_args`」：空字典仍是一次实参变化，无法用「实参集合逐字相同」自证默认路径未变，因此做成条件写入。`getattr` 仅为兼容测试里 `SimpleNamespace(database=...)` 注入的旧式 config，不引入 fallback 语义。

测试（`tests/test_p1_hardening.py::TestDatabaseTls`）：

| 用例 | 断言 |
|---|---|
| `test_ssl_ca_default_is_empty` | 字段声明默认值为 `''`（读 `model_fields`，不受 `.env` / 环境变量影响） |
| `test_empty_ssl_ca_keeps_engine_kwargs_identical` | 截获的 `create_engine` 实参（去 `url`）**等于写死的旧集合**，且 `'connect_args' not in kwargs`、无任何含 `ssl` 的键 |
| `test_ssl_ca_passed_through_as_driver_arg` | 只增量多出 `connect_args == {'ssl': {'ca': ...}}`，其余实参仍等于旧集合 |
