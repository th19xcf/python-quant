## 2. 证据方法（可复核）

本地日线表在除权日的 `pre_close` 等于**交易所公布的除权参考价**，满足

```
pred = (前收 - 现金 + 配股价×配股比例) / (1 + 送转比例 + 配股比例)
残差 = pre_close(除权日) - pred
```

- 049 用 000001.SZ 2024-06-14 实测：前收 10.80、现金 0.719 → pre_close 10.081，精确到 0.001 元。
- 024 **对照组**：57,303 个严格一致事件中取 27,756 个做残差检验，**99.798% 的 |残差| ≤ 0.005 元**，中位数 0，95% 分位 3.6e-15。→ 该方法可以把「谁与交易所一致」判到元以下。

## 8. 复核更正（2026-11-10 晚，定向修正前的二次核验）

**本节推翻前文的 3 个结论，后续任何人读本报告都必须先看这一节，不要照着第 0 节第 3、7 条的「14 条本地错」去改数。**

### 8.1 错在哪：本轮比的是原始列，消费方读的是修正层

前文对拍取的是分红表的原始列 `cash_div` / `share_div`；而复权因子实际读的是：

```python
# src/data/adj_factor_calculator.py:352-360
divs = divs.with_columns(pl.col('share_div_fix').fill_null(pl.col('share_div')).alias('share_div'))
divs = divs.with_columns(pl.col('cash_div_fix').fill_null(pl.col('cash_div')).alias('cash_div'))
```
