## 为什么零改动

第一轮对拍取的是分红表的**原始列** `cash_div` / `share_div`，而复权因子的消费方取的是**修正层**：

```python
# src/data/adj_factor_calculator.py:352-360
divs = divs.with_columns(pl.col('share_div_fix').fill_null(pl.col('share_div')).alias('share_div'))
divs = divs.with_columns(pl.col('cash_div_fix').fill_null(pl.col('cash_div')).alias('cash_div'))
```

即：`cash_div_fix` / `share_div_fix` 非空时覆盖原值，原值只保留作追溯。于是「原始列与源端不一致」并不等于「因子用错了数」。

逐条核验（本目录 `verdicts.csv`）：

| 类别 | 条数 | 有效层与交易所除权参考价残差 | 处置 |
|---|---|---|---|
| 有效层一致（原值错、fix 已修正） | 14 | 全部 0.000000 | 不动 |
| 有效层与参考价吻合、源端错 | 6 | 全部 0.000000，源端残差 -0.1 ~ -2.51 | 不动 |
| 日期口径差 | 3 | 无参考价可比 | 不动 |
