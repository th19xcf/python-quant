## 0. 一句话结论

**判为第 1 类（真实成交），但只有 173 行成立**：1991 年 50 个周六的 173 条 bar 与前后交易日价格连续、周五/周一 bar 同时存在（不是把工作日挪到周六）、覆盖当时深市全部上市股、成交量真实且逐日不同 —— 这是真实的周六交易记录。
另 39 行落在 6 个**周日**，制度上不可能是正常交易日，形态是「额外多出的一天」而非重复行，判 **unresolved**（需外部交易日历定案）。
剩 6 行（`000012.SZ` 1993 年 6 个周六）+ 2 行（1992-02-01）形态与 1991 年不同，判**来源侧残留，待核**。

## 2. 五条判据逐条实测

### 2.1 同日全市场分布（E1）

| 指标 | 值 |
|---|---|
| 有 bar 的周末日期 | 63 个 |
| 每个日期的标的数 | 1 ~ 14 只，中位 **3** 只 |
| 只有 1 只标的的日期 | **12** 个（其中 6 个是 1993 年 `000012.SZ` 周六） |
| 全市场同日有 bar 的股票数 | 与这 16 只**完全一致**（220 = 220），无第二个来源 |
| 1991 年周六的标的集合 | 等于**当时深市全部上市股票**（1~5 只，逐周 3.4 只均值） |

1991 年深市只有 5~6 只股票，周六 bar 恰好覆盖当周全市场（`codes_equals_week_universe` 命中 23/52 个 1991 日期，未命中的是当周有新股上市、周末尚未纳入的周）；这说明它是「全市场一起多出一个交易日」，不是个别标的的数据毛刺。

### 2.2 指数与全市场同日（E2）

| 指标 | 值 |
|---|---|
| `000001.SH` 在 63 个日期上的 bar | **0** |
| `000001.SH` 全历史周末 bar | **0**（权威日历 9,023 个交易日，1990-12-19 起） |
| 因子表在这 63 个日期的行数 | 220（与行情一致） |
| 换手表在这 63 个日期的行数 | 219（缺的 1 行是 volume=0 那行） |

指数序列本身**从不含周末**——这正是 G-112 的根因：权威日历按 `000001.SH` 构造，天然没有周六，于是深市 1991 年的周六成交量全部落在日历之外。因此「指数没有 bar」不能作为「股票也没交易」的证据，只能说明指数源是工作日口径。

### 2.3 相邻交易日指纹（E3 / F2）

| 指标 | 值 |
|---|---|
| 与**前一条 bar** 的 OHLCV 完全重复 | **0 / 220** |
| 与**后一条 bar** 的 OHLCV 完全重复 | **3 / 220**（`000002.SZ` 1991-09-29、`000004.SZ` 1991-08-10、`000004.SZ` 1991-08-24） |
| 1991 周六行中，该周**周五有 bar** | 163 / 173（94%） |
| 1991 周六行中，该周**周一有 bar** | 151 / 173（87%） |
| 周六行 \|日收益\| 中位 / p95 | **0.53% / 5.36%**（173 行里 170 行 < 11%） |

**这是最关键的一条**：若属于「日期错位」，周六 bar 会顶掉周五或周一，两者不会同时存在；实测 94% 有周五 bar、87% 有周一 bar，且价格是连续日序列（例：`000001.SZ` 1991-04-03→04-08 收盘 49.00 / 48.76 / 48.52 / **48.28（周六）** / 48.04，逐日 −0.24，周六不是周五的复制）。只有 3 行是整行重复，属个别毛刺，不代表整体。

### 2.4 通达信 `.day` 独立第二源（E4 / F5）

| 指标 | 值 |
|---|---|
| 220 行中，当日在该标的 `.day` 文件里存在 | **203**（92.3%） |
| 缺失 | **17**，全部是 `000004.SZ` 的 1991 年周六 |
| 缺失行里的周日行 | **0** |

通达信侧 92% 有原始记录；缺的 17 条集中在单一只标的的 1991 年周六，是「该标的早期周六记录在 TDX 侧不全」，不是「整批周末 bar 都不在源端」。

### 2.5 量价合理性（E5）

| 指标 | 值 |
|---|---|
| `volume > 0` | **219 / 220** |
| `amount > 0` | **219 / 220** |
| 换手表 `turn` 非空且 > 0 | **219 / 219**（中位 0.083） |
| `volume = 0` 的唯一一行 | `000004.SZ` 1991-08-10（且与 1991-08-12 全字段重复 → 该行是重复行） |
| 成交量量级 | 逐日、逐只都不同（同日期内 2 ~ 2,530 手，中位随行情变化），不是常数填充 |

量不是占位值：同一只标的的周六成交量与相邻交易日同量级但不同值（如 1991-09-07 周六 4 只中位 1,946 手、1991-09-14 周六 899 手），符合真实撮合。

## 4. 供拍板的结论

1. **判 1 的 173 行（1991 年周六）成立**：价格连续、周五/周一并存、覆盖当时全市场、量真实、无重复。这一批是真实观测，C 开启后会被丢弃。
2. **判 unresolved 的 39 行（周日）**：既不能证真（无周日交易制度依据、无外部日历），也不能证伪（非重复行、价量连续、整市场一起出现）。按 DG-18 保留现状，单列登记。
3. **判 2/3 的 8 行**：`000012.SZ` 1993 年 6 个周六 + 1992-02-01 的 2 行；证据是「同期同市场其他标的零周六 bar」+「双周一次」+「量级比同标的日均低两个数量级」。建议单列核查，不影响主结论。
4. **对 C 的影响：默认开不成立**。以「丢真实观测」计，C 默认开会删掉 173 行真实周六成交（1991 年），并在 1991-1993 面板上改变 **188 行** `ret`、剔除 **220** 行。若要保留 C 的收益（220 行不进面板），可行形态是**默认关 + 显式开启**，或「按日期白名单保留 1991 年周六」——两者都可回滚，取哪个由你拍。
