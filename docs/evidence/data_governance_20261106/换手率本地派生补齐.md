# 换手率补齐：从「等上游」改为「本地派生」

- 生成时间：2026-11-06 16:45
- 结论：换手率**不需要联网**。`turn` 可由本地 `volume` 与流通股本精确复现，
  已固化为 CLI 子命令 `derive-turnover`；本轮补入 162,316 行，全表
  17,870,598 → **18,032,914** 行，0 只标的历史减少。

## 1. 起点：baostock 不可用

上一轮 `sync-turnover --workers 4` 有 1,556 只标的补数失败。`turnover_parts/failed.csv`
记录 196 条 `RuntimeError: baostock 登录连续失败，已熔断`（`retries_used=3`）。
复测单进程登录直接返回错误码 `10002007 网络接收错误`——账号仍在冷却。

模块文档早已写明「>1 并发登录会被上游拉黑」，本轮 `workers=4` 又踩了一次。

## 2. 关键发现：换手率可由本地数据算出

行情 `volume` 单位为「手」，`turn` 存百分数，因此：

```
turn(%) = volume(手) × 100 ÷ float_share(股) × 100
        = volume × 10000 / float_share
```

`float_share` 来自 `meta/factors/stock_shares.parquet`（166,276 行 / 5,812 只，
`effective_date` 覆盖 1979-02-23 ~ 2026-11-05，按 `join_asof backward` 对齐）。

### 口径等价性实测

| 样本 | 行数 | 中位相对误差 | p90 | p99 | 偏差 >1% 占比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 近 5 日 25 只 | 325 | 0 | 1.2e-5 | — | 0 / 325 |
| 全历史分层抽样 316 只 | 995,653 | **0** | 0 | **9e-6** | 0.128% |

按年看 p99：2020 = 3.8e-5、2022 = 2.5e-5、2024 = 1.4e-5、2025 = 1.0e-5、
2026 = 1.7e-5。偏差 >1% 的 1,271 行**全部落在 1992–1995 年**，成因是股本表
最早记录只到 1991-05-02，早期统一取同一个 `float_share`，与 `turn` 口径无关。

另需注意：表里原本就有 1,768 万行 `source = derived:quotes_volume+float_share`
（占 99%），说明这条本地派生路径历史上已在使用，只是没有固化成工具，最近两天
的增量因此走了上游。

## 3. 落地：`derive-turnover` 子命令

新增 `src/data/local_store/turnover.py::derive_turnover_local` 与
`build.py derive-turnover`：

```bash
# 默认 dry-run，只统计缺口
python -m src.data.local_store.build derive-turnover
# 写入（只补缺失，不覆盖既有行）
python -m src.data.local_store.build derive-turnover --commit
# 限定区间 / 标的
python -m src.data.local_store.build derive-turnover --start 2026-11-04 --end 2026-11-05 --commit
```

设计要点：

- **只补缺口**：按 `(ts_code, trade_date)` anti join 现有表，绝不覆盖已有行；
  `source` 标 `derived:quotes_volume+float_share`，与历史派生值同口径。
- **无股本不瞎算**：`join_asof` 找不到当日及以前的股本记录 → 计入
  `no_share_rows` 并跳过，不落任何猜测值。
- **停牌不算缺口**：`volume` 为 null 或 ≤0 的行不进入候选集（停牌日本就无换手）。
- **写后断言**：写入后行数必须等于 `before + 新增`，否则抛异常（防重复键静默膨胀）。
- 性能：全历史扫描 + 18M 行重写 **5.5 秒**，无需分块、无需联网。
