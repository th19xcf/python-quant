针对「估值 2018 起、财务 2016 起、行业 PIT 11-03 起、指数成分 11-05 起，
这些是明示边界不是漏采，能否补齐」——**不复用旧结论，重新联网探测上游接口

### 3.2 估值 1990-12-19 起（纯本地重算）

`tools/backfill_valuation_history.py`：

- `total_mv = 不复权 close × 当日总股本`、`circ_mv = close × 流通股本`，
  股本按 `effective_date` 做 backward asof，不会用未来股本污染历史；
- `pe / pe_static / ps` 用财务三表按 `ann_date` 计算 TTM：Q4 用全年累计，
  其余 `本期累计 + 上年年报 − 上年同期`，只采用「截至该交易日已公告且报告期
  最新」的一期；补发更早期报告不会让可见状态回退；
- 只写 `trade_date < 2018-01-02` 的行，落到
  `parts/valuation/batch_historical_9xxx.parquet`（命名排在东财 `batch_00xx`
  之后，后续 `resume_valuation --commit` 重新合并不会覆盖历史段）。

**主表 9,777,131 → 17,952,399 行，起点 2018-01-02 → 1990-12-19，
5,718 → 5,811 只，主键 `(ts_code, trade_date)` 17,952,399 / 17,952,399 唯一。**

| 段 | 行数 | 总市值空值 | PE 空值 | PS 空值 |
|---|---|---|---|---|
| 1990–2009 | 3,610,687 | 0 | 全空 | 全空 |
| 2010–2014 | 2,615,807 | 0 | 712,957 | 705,602 |
| 2015–2017 | 1,948,774 | 0 | 141,144 | 132,321 |

即：**市值/规模类因子补齐到 1990；PE/PS 从 2010 年财报可见起逐步覆盖，
2017 年段覆盖率约 93%**。2010 前无本地财报，PE/PS 保持空而不是外推。

**2018 重叠段全市场对拍（367,238 行，口径可信度证据）**：

| 字段 | 中位相对偏差 | p95 | 1% 内占比 |
|---|---|---|---|
| `total_mv` | 0 | 1.7e-16 | 100% |
| `circ_mv` | 0 | 1.7e-16 | 100% |
| `pe` | 8.1e-11 | 0.360 | 81.0% |
| `ps` | 9.8e-10 | 0.126 | 82.8% |
| `pb` | **0.0326** | **0.379** | **26.0%** |

市值/流通市值是恒等式重算，与东财机器精度一致；PE/PS 中位偏差也是机器精度，
p95 差异来自个别公司的财报重述/更正，跨段使用需留意；**PB 写入被禁用**：
东财 `stock_zcfz_em` 只有「股东权益合计」（含少数股东权益），而东财 PB 用归母
净资产，全市场存在系统性差异，硬写会污染因子。`--include-pb` 可显式开启，
但不建议跨 2018 边界使用。所有新增行 `source=local:shares_x_close+fin_ttm`，
与 `akshare:stock_value_em` 分段隔离（主表还存在既有的 117 只 baostock 补充行，
不受影响）。

### 3.3 行业历史 PIT（换源，独立口径）

`tools/backfill_reference_pit.py --target industry`：

- 并发采集踩到真实坑：`stock_industry_change_cninfo` 内部用
  `py_mini_racer`(V8) 生成签名，**V8 全局状态不是线程安全的**，多线程并发直接
  触发 `IsConfigurablePoolInitialized` 进程崩溃；改为 `ProcessPoolExecutor`
  每进程独立 V8 后稳定。Polars 2.0 也移除了 String→Date 的 `cast`，统一走
  `str.to_date`。
- 产物：`meta/industry_pit/industry_change_pit.parquet` +
  `cninfo_coverage.json`，按 `(ts_code, standard)` 把变更点切成 PIT 区间，
  `end_date = 下一条生效日 − 1 天`，末段为 `null`（开放区间，不伪造结束日）。
- 全市场扫描 **5,813 只**：**5,579 只有变更事件**、54,763 段 PIT 区间、
  **1990-01-29 ~ 2026-11-06**、12 套分类标准、45,854 段开放区间；
  234 只（退市 / 巨潮无记录）无事件。首轮有 152 只因代理抖动失败，
  逐票缓存 + 自动重试后**第二轮 0 失败**，不缓存失败结果的设计生效。

覆盖明细见 `artifacts/p1_backfill/reference/industry_pit_report.json`。

**不覆盖** `industry_pit.parquet`（通达信 T 代码树），coverage 恒
`complete=false`：巨潮是第三方聚合、11 套分类标准混用、退市股无变更记录、
口径与生产链路不同。消费方必须显式选定 `standard`，否则同一标的会同时命中
多个行业。

## 五、补齐之后仍然成立的边界（不得误读）

1. **历史行业中性化 / 指数成分内选股仍不可用**。新产物是独立口径的能力储备，
   恒 `complete=false`，且和 `industry_pit.parquet` / `membership_intervals.parquet`
   一样**尚无分析/回测消费方**。好处是不会静默前视，代价是功能未接线。
2. **2018 边界依然存在，只是性质变了**：市值/流通市值可全段连续使用；
   PE/PS 在 2010 前后、2018 前后应按 `source` 分段；PB 在 2018 前为 null。
3. **1990–2009 没有 PE/PB/PS**：本地财报最早 2010Q1，第三方源（baostock
   peTTM/pbMRQ）在本机全历史逐票查询不稳定，未纳入生产链路。若确实需要，
   可另接乐咕 `stock_a_indicator_lg`（单票、约 2005 起）并同样做重叠段对拍。
4. **PB 口径要修必须换源**：东财批量资产负债表只有「股东权益合计」，
   需接 `stock_balance_sheet_by_report_em` 等单票接口取归母权益，重采后按
   同一 TTM 可见性重算并对拍，才能把 PB 补进历史段。
5. 行业 PIT 的多标准、退市股缺记录；指数成分的幸存者偏差；1990 年代早期
   股本/行情稀疏——这些是源端事实，不通过插值或回填伪造。
6. 门禁 `reference_contracts` 仍只监控原 3 张生产契约表（受控 partial 白名单、
   复审到期 2027-02-07），新独立产物不纳入门禁，避免把「能力储备」误判为
   「生产依赖」；若要接分析消费方，应同步补契约条目与白名单。
