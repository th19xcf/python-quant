## §1 策略定义与标签

### 1.1 一句话定义

在 D0 收盘后，仅使用当日已收盘、已确定的数据，对全池股票打分，选出次日 D1 开盘买入、D3 收盘卖出的标的，赚取 3 个交易日的短线价差。

### 1.2 标签

```text
y_i = 1[ P_adj(D3 close) / P_adj(D1 open) − 1 ≥ 5% ]
```

口径约定：

1. 使用**后复权价**，规避除权除息造成的价格跳变。
2. D1、D3 均按**个股自身可交易日**计数，遇停牌顺延。
3. 自 D1 起 15 个交易日内仍无法凑齐 D3，则该样本剔除，不进训练。
4. D1 开盘即涨停的样本**保留在训练集**，但打 `untradable` 标记；回测中不计入可成交信号。
5. 5% 为绝对阈值，不按波动率标准化（如需标准化，另开一版，不得与本版结果混比）。

### 1.3 时间轴

| 时点 | 含义 | 已知信息 |
|---|---|---|
| D0 | 信号日 | D0 收盘价、成交量、当日全部行情 |
| D0 收盘后 | 打分、排序、定 K | 全池特征 |
| D1 开盘 | 买入 | D1 开盘价 |
| D1 收盘起 | 风控检查 | D1 收盘价 |
| D3 收盘 | 到期卖出 | D3 收盘价 |

基准持有期 N = 3；敏感性测试 N ∈ {3, 5, 10}。

## §2 样本池（Universe）

### 2.1 当日快照过滤

逐条剔除，顺序执行：

1. ST、*ST、退市整理期股票。
2. 上市不足 60 个交易日的股票（新股波动结构不同）。
3. D0 停牌。
4. D0 一字涨停或一字跌停（无法形成有效收盘信号，次日亦难成交）。
5. 前 20 个交易日内停牌天数 > 5。
6. 20 日平均成交额 < 5000 万元（流动性不足，3 万单笔已接近冲击成本边界）。

### 2.2 截面剔除

7. 剔除流通市值最小的 30%。
8. 剔除 20 日平均换手率最高的 5%。

第 7 条针对 2024-01 微盘股流动性踩踏的结构风险；第 8 条针对游资封板、次日无法成交的问题。

### 2.3 规模预期与数据要求

- 预期每日池子 1500–3500 只。
- **必须使用包含已退市股票的全历史行情**，否则存在幸存者偏差；仅用当前在市股票回测，历史命中率会被系统性高估。
- 池子规模若长期偏离该区间（例如 < 800 或 > 4500），先检查退市股是否缺失、ST 标记是否对齐。

## §3 特征工程

### 3.1 特征清单

| 编号 | 名称 | 定义 | 预期方向 |
|---|---|---|---|
| F1 | 20 日波动收敛分位 | 当日 20 日收益率标准差，在过去 250 个交易日中的分位 | 负（越收敛越好） |
| F2 | 60 日振幅 | `(H60 − L60) / mean(C60)` | 正（振幅大，弹性足） |
| F3 | 离 60 日高点距离 | `C0 / H60 − 1` | 正（贴近前高） |
| F4 | D0 放量比 | `V0 / mean(V20)` | 正（异动放量） |
| F5 | 缩量比 | `mean(V5) / mean(V60)` | 待定，交由模型 |
| F6 | D0 涨幅 | `C0 / C(−1) − 1` | 正（启动日） |
| F7 | 收盘位置 | `(C0 − L0) / (H0 − L0)`，若 `H0 = L0` 则记 0.5 | 正（收在高位） |
| F8 | 20 日动量 | `C0 / C(−20) − 1` | 正 |
| F9 | 行业相对强弱 | 个股 20 日收益 − 所属申万一级行业 20 日收益中位数 | 正 |
| F10 | 全市场上涨家数占比 | 当日全 A 上涨家数 / 有效交易家数 | 调节变量，见 §5.3 |

F4 与 F5 并列是为了把"一次性异动放量"和"持续缩量后的首次放量"区分开——两者形态相近，后续走势差别很大。

### 3.2 预处理

1. **缩尾**：每个特征在训练期内做 1%/99% 缩尾，上下界固定，验证段沿用。
2. **行业中性化**：F1–F8 在申万一级行业内做去均值；F9 本身已中性，不再处理；F10 为全市场变量，不中性化。
3. **标准化**：z-score 的均值与标准差**只在训练期估计一次**，验证段、留出段一律沿用。任何"在全样本上标准化"的做法都引入前视偏差。
4. **缺失值**：单特征缺失 → 行业内中位数填充并打标记；超过 2 个特征缺失 → 从当日池中剔除。

## §4 模型

### 4.1 主模型

L2 正则逻辑回归。选择理由：可解释、系数可做归因、小样本下比树模型更稳、不会因为训练期结构变化而剧烈漂移。

| 项目 | 设定 |
|---|---|
| 训练区间 | 2015-01-01 – 2020-12-31 |
| 样本权重 | 时间衰减，半衰期 500 交易日：`w_t = 0.5^((T−t)/500)` |
| 交叉验证 | 5 折**时序**切分，不打乱 |
| 正则强度 | 在 `λ ∈ {0.01, 0.1, 1.0, 10}` 中按时序 CV 的 AUC 选，平手取更强正则 |
| 截距 | 保留 |

### 4.2 稳健性对照

walk-forward：每季度末用截至当时的数据重训一次，逐日输出排序。要求与主模型逐日排序的 Spearman 相关系数 ≥ 0.7。不达标视为模型不稳定，停止推进，先排查特征或训练窗口。

### 4.3 辅助诊断模型（不参与决策）

用实际规则算出的净收益做标签：`y_net = 1[r_net > 0]`，同样训练一个逻辑回归。目的：检验"预测 5% 命中"与"预测赚钱"是否同向。

要求两者排序 Spearman ≥ 0.6。不达标时**先调止损参数**（止损位与持有期），不要急着进验证段——这通常意味着止损失效在吃收益。

## §5 每日选股数量 K

### 5.1 基本公式

```text
K_t = min( K_free_t ,  floor( C_t / (S × 1.05) ) ,  N_signal_t )
```

| 符号 | 含义 |
|---|---|
| `K_free` | `32 − H_t`，即空余仓位数，`H_t` 为当日开盘前持仓数 |
| `C_t` | 可用现金（先卖后买，当日卖出回款可用） |
| `S` | 单笔金额，默认 30000 元 |
| `N_signal` | 当日可成交信号数：池内、非 `untradable`、非 `missed` |
| `1.05` | 预留滑点与费用缓冲 |

### 5.2 排序与成交

按模型输出 prob 降序排列，依次填到 K_t 为止。超出 K_t 的合格信号记为 `skipped`，只记录不交易。

### 5.3 风险闸门

若当日全市场上涨家数占比 up_ratio < 30%（普跌日），

```text
K_t = max( 1 , floor( K_t × 0.5 ) )
```

若最终 K_t = 0，当日空仓，并在日志中记录空仓原因（无资金 / 无仓位 / 无信号 / 风险闸门）。

F10 作为调节变量在此处发挥作用，同时也作为交互项进入模型。

## §6 组合与资金约束

| 参数 | 默认值 | 说明 |
|---|---|---|
| 初始资金 | 1,000,000 元 | |
| 单笔金额 | 30,000 元 | 按 D1 开盘价向下取整到 100 股整手 |
| 最大并行持仓 | 32 笔 | 32 × 3 万 = 96 万，留 4 万缓冲资金 |
| 杠杆 | 无 | |
| T+0 | 不允许 | A 股规则 |

执行顺序与限制：

1. **先卖后买**，当日卖出回款可用于当日买入。
2. 同一股票不允许同日既卖又买（避免在同一标的上来回摩擦成本）。
3. 单笔实际股数 = `floor(30000 / P_open(D1) / 100) × 100`；若不足 100 股，跳过该笔并记 `size_reject`。

---

## §7 买入执行

1. 成交价：D1 **开盘价**。
2. 若 D1 开盘价 ≥ 涨停价 − 0.01 元，记为 `missed`，**不补单、不顺延**。
3. `missed` 率超过 15% 触发告警。这说明信号密集堆积在涨停板附近，策略名义收益高但实际不可实现。
4. 当日实际买入数可能小于 K_t，差额留作现金，不临时改选其他标的。

---

## §8 卖出执行

### 8.1 卖出条件

三个条件，先满足先触发，均于**次日开盘**卖出：

1. **止损**：持有期内任一交易日收盘 ≤ 0.98 × 买入价。
2. **破位**：收盘价 < 该笔对应的 D0 最低价。
3. **到期**：t = 1 + N（N = 3 时即 D3 收盘）。

### 8.2 检查时点

- 从 D1 收盘开始逐日检查。
- D1 当日即检查，但**不在 D1 卖出**（T+1 限制），最早 D2 开盘执行。
- D1 开盘价已低于 D0 最低价的，不特殊处理：照常买入；若 D1 收盘仍在 D0 最低价之下，则 D2 开盘卖出。

### 8.3 卖出不可成交

| 情形 | 处理 |
|---|---|
| 执行日开盘跌停 | 顺延至下一可成交日 |
| 执行日停牌 | 顺延至下一可成交日 |
| 顺延期间 | 仓位**不释放**，继续占用仓位与资金额度 |
| 顺延上限 | 20 个交易日；超过则按第 20 个交易日收盘强制平仓，记 `forced_exit` |

`forced_exit` 是本策略最主要的下行风险来源，§14 有专门的通过门槛。

## §9 交易成本

### 9.1 基准

**往返 21.9bp**（约 0.219%），即 100 万资金买卖一轮约 2190 元。

1bp = 0.01% = 0.0001 = 万分之一。

### 9.2 显性成本拆解（单笔 3 万元）

| 项目 | 金额 | 依据 |
|---|---|---|
| 买入佣金 | 5.00 元 | 1.5bp，最低 5 元 |
| 买入过户费 | 0.30 元 | 约 0.001% 双边 |
| 卖出佣金 | 5.00 元 | 同上 |
| 卖出印花税 | 15.00 元 | 卖方单边 0.05%（2023-08-28 起减半） |
| 卖出过户费 | 0.30 元 | |
| **合计** | **25.60 元** | **= 8.53bp** |

### 9.3 隐性成本分档

按 20 日平均成交额分档：

| 20 日均成交额 | 单边隐性 | 往返合计 |
|---|---|---|
| > 10 亿 | 8bp | 16.5bp |
| 3–10 亿 | 12bp | 20.5bp |
| 1–3 亿 | 18bp | 26.5bp |
| 0.5–1 亿 | 25bp | 33.5bp |

基准 21.9bp ≈ 8.53bp 显性 + 13.4bp 隐性，对应"3–10 亿"档。若策略实际成交集中在 1–3 亿档，应改用 26.5bp 重算。

### 9.4 敏感性

四档全跑：10 / 21.9 / 35 / 50 bp。若策略只在 10bp 档为正、21.9bp 档转负，则判定不可用。

## §10 记账口径

每笔交易记录以下字段（缺一不可）：

```
signal_date, buy_date, sell_date, code, prob, rank, k_t,
buy_price, sell_price, shares, amount,
buy_cost, sell_cost, gross_ret, net_ret,
exit_reason (expire|stop_loss|break_down|forced_exit),
status (filled|missed|size_reject|skipped|untradable),
hold_days, delay_days
```

净值计算按逐日 mark-to-market，停牌期间沿用最后有效收盘价。

## §11 样本切分与验证协议

### 11.1 四段切分

| 段 | 区间 | 用途 | 允许次数 |
|---|---|---|---|
| 训练 | 2015-01-01 – 2020-12-31 | 拟合模型与标准化参数 | 多次 |
| 选参 | 2021-01-01 – 2022-12-31 | 6 个配置中选 1 个 | 多次 |
| 确认 | 2023-01-01 – 2023-12-31 | 单次确认 | **1 次** |
| 留出 | 2024-01-01 – 2026-11-30 | 最终检验 | **1 次，且仅在压力测试通过后** |

### 11.2 六个待选配置

持有期 × K 规则：

- N ∈ {3, 5, 10}
- K 规则二选一：约束驱动（§5.1 原式）/ 上限减半（K_t 再取半）

共 3 × 2 = 6 个配置，全部在 2021–2022 上跑。

### 11.3 选择规则（事前锁定）

以 2021–2022 的 **Calmar 比率**（年化净收益 / 最大回撤）最高者入选。平手取持有期更长者。

规则在跑之前写下，跑完不得修改。任何"看完结果再调选择标准"的操作，都会让确认段和留出段失去意义。

### 11.4 留出段纪律

留出段只打开一次。若结论为负，本策略版本作废，不得通过调整参数后重跑同一留出段——那不是留出，那是样本内。

## §12 对照组与显著性

| 组 | 定义 | 用途 |
|---|---|---|
| C1 | 同日池内**未被选中**的股票等权 | 检验选股是否真的有信息量 |
| C2 | 同日随机抽股，重复 10^4 次 | 构造收益分布，取 95 分位 |
| C3 | 同日全池等权命中率 | 基线命中率 |
| C4 | 三重分层匹配：ln 市值、20 日波动、20 日动量各分 5 层，取同层 | 剥离风格暴露后的残差 alpha |

C4 是关键的一个。不做分层匹配，很容易把"小市值 + 高波动"的 beta 当成 alpha。

## §13 通过条件（9 项）

全部满足才可进入留出段；任一不满足即停。

1. **命中率**：≥ 2 × 同日基线（C3），二项检验 p < 0.01。
2. **单笔净收益**：比 C1 高 ≥ 0.5 个百分点。
3. **对随机**：净收益 > C2 的 95 分位。
4. **分段稳定性**：训练后各段年化净收益均为正。
5. **超额**：相对池内等权年化超额 ≥ 2 个百分点。
6. **中性化 alpha**：C4 分层匹配后 alpha > 0 且 t > 2，至少两段成立。若 t 落在 1.5–2，记为"证据不足但方向正确"，需人工复核，不得自动放行。
7. **回撤**：最大回撤 ≤ 25%。
8. **尾部**：`forced_exit` 占比 ≤ 2%，且单笔最大亏损 ≥ −25%。
9. **容量**：单笔 3 万落在 3–10 亿成交额档内，冲击成本可忽略。若未来放大到 30 万/笔，容量结论需重估，不可线性外推。

第 8 项单笔最大亏损 ≥ −25% 的含义：一旦出现超过 −25% 的实亏，说明顺延平仓已经击穿风控假设，策略结构有问题。

## §14 压力测试

留出段打开前，必须在以下区间单独跑并留档：

| 区间 | 事件 | 关注点 |
|---|---|---|
| 2024-01-15 – 2024-02-08 | 微盘股流动性踩踏 | `forced_exit` 率、−2% 止损失效情况 |
| 2015-06-15 – 2015-09-30 | 股灾 / 千股停牌 | 停牌顺延、跌停无法卖出 |
| 2018 全年 | 单边熊市 | 持续负收益下的回撤累积 |
| 2020-02-03 | 疫情后首个交易日 | 单日跳空、止损完全无效 |
| 2024-09-24 – 2024-10-08 | 暴力反弹 | 涨停导致 `missed` 飙升、踏空 |

**硬性门槛**：2024-01 段若 `forced_exit > 5%` 或区间回撤 > 25%，先改止损参数或调整池子，修完重测，**不得直接打开留出段**。

理由：−2% 止损在跌停开盘时无法执行，这是机制性的，不是参数没调好。不修就会在留出段以同样方式亏钱。

## §15 必做诊断输出

### 15.1 分位收益曲线

按预测概率分 20 组，输出各组平均净收益。要求单调性：前 5 组的收益应显著高于后 5 组。若呈"U 形"或平坦，说明模型在排序而非选股上有效——那就该改成分位做多空，而不是只做多头。

### 15.2 K 敏感性

K 取 8 / 16 / 24 / 32，看收益、回撤、Calmar 随 K 的变化。若最优 K 恰好等于资金约束上限 32，说明策略容量已到顶，规模不能再放大。

### 15.3 必须披露的数量指标

- 平均每日信号数
- 平均每日实际成交数
- `skipped` 占比
- `missed` 占比
- 平均持仓笔数
- `effective_pct`（有效选股比例 = 实际成交 / 池内总数）

不披露这些，回测收益无法解释来源。

### 15.4 分解

年度分解、行业分解、市值分组分解、交易层分解（平均持有天数、各 `exit_reason` 占比、实测滑点 vs 假设滑点）。

## §16 实现清单

按顺序实现，每步可独立校验：

1. 数据加载：日线（含退市股）、行业分类、涨跌停价、停牌标记。
2. 池子构建（§2），每日输出池子规模，检查是否落在 1500–3500。
3. 特征计算（§3），抽查 3–5 只股票的手算结果。
4. 标签生成（§1.2），核对停牌顺延与 15 日剔除逻辑。
5. 模型训练 + 时序 CV（§4）。
6. 每日 K 计算（§5）。
7. 买入执行（§7）与卖出执行（§8、§8.3）。
8. 记账（§10）。
9. 评估与诊断（§12–§15）。

## §17 附录

### 17.1 为什么不能使用"全部满足条件的样本"

这是本策略最容易做错的一处。

**第一，基准问题。** 超额收益的定义基准是"同日池内等权"。如果持有全部满足条件的样本，那持仓就等于基准本身，超额恒为 0。选股策略的意义在于"从池子里挑出更好的那一部分"，全买等于放弃选股。

**第二，资金问题。** 按原设定"每日取概率前 1%–2%"，在 1500–3500 只的池子里每天会产生 60–90 个信号，持有 3 天，并行持仓约 180–270 笔。按单笔 3 万算，需要 5400–8100 万资金，取中位数约 **7500 万**。而账户是 100 万、上限 32 笔，资金缺口 2 倍以上（按并行持仓算）。

**第三，alpha 分布问题。** 收益的 alpha 集中在概率分位的高端，随分位下降快速衰减。全池平均的超额收益接近 0，即使模型排序正确，也赚不到钱。

**第四，K 的双边约束。** 要让收益稳定，K ≥ 30 才能保证足够的样本量和降噪效果；而资金上限决定了 K ≤ 32。两个约束把 K 夹在很窄的区间里，所以"每日尽量填满仓位"不是激进，而是这个资金规模下的唯一合理选择。

结论：选股数量必须由资金、仓位、可成交信号三者共同决定，而不是人为设定一个百分比。

### 17.3 术语

- **universe / 池子**：通过 §2 过滤后的当日可交易股票集合。
- **signal**：模型输出且通过可成交性检查的候选。
- **K**：当日实际下单数量上限。
- **skipped**：合格但因 K 限制未买。
- **missed**：下单时开盘已涨停，未能成交。
- **untradable**：训练标签中标记的次日开盘涨停样本。
- **forced_exit**：顺延超 20 日后强制平仓。
- **effective_pct**：实际成交数 / 池内总数。

### 17.4 已知风险

1. **止损失效**：−2% 止损在跌停开盘时无法执行，顺延会放大亏损。2024-01 段已证明这一点。
2. **`missed` 高估**：信号集中在涨停板附近时，回测收益不可实现。
3. **行业分类前视**：申万分类历史上有调整，需用 point-in-time 版本；否则中性化会漏出未来信息。
4. **风格切换**：时间衰减权重 + 6 年训练窗口，对 2021 年后的风格切换敏感。
5. **阈值漂移**：5% 固定阈值在市场整体波动率变化时会漂移，命中率不可跨年直接比较。
