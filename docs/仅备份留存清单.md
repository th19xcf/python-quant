## 3. 恢复方法

对每条，把下表的 `SRC` 换成对应备份侧路径、`DST` 换成同构的源侧路径即可（相对路径完全一致）：

```powershell
$SRC = 'G:\git\python-quant\reports\stock_momentum_20261105\data\panel.parquet'
$DST = 'E:\code\python\quant\reports\stock_momentum_20261105\data\panel.parquet'
Copy-Item -LiteralPath $SRC -Destination $DST -Force
```

**恢复后必须满足的校验**（三项全过才算恢复成功）：

```powershell
(Get-Item $DST).Length                         # 必须等于表中「字节」
(Get-FileHash -LiteralPath $DST -Algorithm SHA256).Hash.ToLower()   # 必须等于表中 SHA256（小写）
Test-Path $DST                                  # 必须为 True
```
