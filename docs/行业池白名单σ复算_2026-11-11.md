## 一、口径与标定

完全沿用 σ 报告，未改任何参数：

| 项 | 取值 |
|---|---|
| 月收益 | 月末收盘对上一有效月末，单位 pp；指数用 `close`（880/881 无复权事件） |
| 月末门控 | 标的中该月最后一条行情日期必须等于 `000300.SH` 当月最后交易日 |
| 未完成月 | 2026-11 剔除（末日 11-11 < 11-30） |
| σ_abs | 等权组合月收益的样本标准差（ddof=1） |
| σ(Δ) | 月初按过去 3 个月收益排序取前 K 等权持有下月；同日从同一可投域随机抽 K 只（B=200，seed=7）取均值；Δ=规则−随机 |
| MDE | `(t_{1-α*/2,n-1} + t_{0.80,n-1}) × σ(Δ)/√n`，α*=0.0025；年化取 `(1+MDE/100)^12-1` |
| 样本期 | 2019-01~2026-10（n=91 期）、2022-01~2026-10（n=55 期） |

**标定（先证明复现旧口径）**：用同一套代码重算「880 段剔除任一月 |收益|>50pp、且有效月数≥24」→ **685 → 剔 118 → 542 只**，与 σ 报告完全一致；σ_abs 全历史 **8.04**（报告 8.04）、2019+ **5.90**（报告 5.88）、2022+ **6.31**（报告 6.28）；σ(Δ) K=5 2019+ **6.08**（报告 6.16）、2022+ **5.97**（报告 6.08）。绝对偏差 ≤0.03，σ(Δ) 偏差 ≤0.11——来自随机抽样实现的差异（`numpy` 逐次 `choice` vs 报告实现），**比较时请把 ±15bp 视为噪声底**。

## 三、白名单把 σ 抬了还是压了

| 对比 | σ_abs 19+ | σ_abs 22+ | σ(Δ) K5 19+ | σ(Δ) K5 22+ |
|---|---|---|---|---|
| 880 `white`（475） vs 旧 542 | 5.90→5.75，**−15bp** | 6.31→6.08，**−23bp** | 6.08→7.02，**+94bp** | 5.97→6.70，**+73bp** |
| 881 全量（467） vs 旧 542 | 5.74，−16bp | 6.01，−30bp | 10.53，**+445bp** | 10.98，**+501bp** |
| 合并 942 vs 旧 542 | 5.73，−17bp | 6.03，−28bp | 10.59，**+451bp** | 10.91，**+494bp** |
| 217 内 `white`（100） vs 旧 542 | 6.07，+17bp | 6.11，−20bp | 8.62，**+254bp** | 8.04，**+207bp** |

一句话：**绝对波动小幅下降，相对跟踪误差显著上升**。想让「干净数据」把 σ(Δ) 压下来，这个方向是错的——两个方向都不支持。

三条证伪用的证据：

1. **880 白名单反而更差**：把 542 里 67 只 `defect`/`synthetic` 剔掉，σ(Δ) 从 6.08 升到 7.02（+94bp）。若脏数据是主因，应当下降。
2. **881 断点截断前后几乎不变**：881 全量 10.53 → 白+截断 10.82（差 29bp，在 ±15bp 噪声底两倍内）。断点不是 881 高 σ(Δ) 的来源。
3. **σ(rot) 是唯一主导项**：881 的规则篮子自身月波动 11.2~11.9pp，随机篮子只有 5.3pp。行业越细，动量选出的 5 只越集中在单一高波动主题上，K=5 摊不开。

## 四、够不够格开正式试验

**结论：不够格。**

- 目标是 σ(Δ) ≤ 4pp。这批池里**没有一个**达标：最好的是旧口径 880-542 的 2022+ K5 **5.97**（超目标 49%）、K10 **5.80**（超 45%）；所有含 881 的池都在 8.0~11.0，是目标的 2.0~2.7 倍。
- MDE 也全部不达标：行业池 K5 为 **2.52~5.95pp/期**（年化 34.8%~100.1%），宽基口径是 0.99~1.70pp/期（年化 12.5%~22.6%）。要在 55 期里识别 3.4pp 年化的真实 α，行业池连噪声都比它大一个量级。
- 差距不在数据：本次复算把「数据干净度」这个变量几乎完全控制住了——白名单、断点截断、剔除合成段，三种手段对 σ(Δ) 的影响都在 −30bp ~ +94bp 之间，甚至方向相反；而 σ(rot) 与 σ(rand) 相差 6pp 以上，是结构性差异。
- 要往下走，只有两条路，且都需要新的实测（不在本次范围）：① **把 K 抬到 15~20 甚至 20+**，用宽度换跟踪误差——K=10 只把 880 从 5.52 降到 5.5~5.8，趋势存在但斜率不足，需实测 K=15/20/25 的拐点；② **放弃行业轮动**，回到宽基（宽基 K=5 已是 2.52~2.96，K=10 更低）。
- 在此之前，`defect`/`synthetic` 名单的唯一用处是**防止把断点当收益**（例如 880633 汽车热管理 2022-07-28 单日 −70.43% 后次日 +179.89%），不是用来改善 σ。

### 4.1 结论与停线（2026-11-11 决策）

**决定：行业轮动这条线停在这里，不做 K=15/20/25 的拐点实测；行业池不进入正式试验，资源转投宽基。**

停线理由三条，任一条单独成立：

1. **加宽只会无限逼近行业平均，α 被摊薄。** K 从 5 加到 10（881 全量），σ(rot) 11.18→10.41，σ(Δ) 10.53→9.13，斜率约 −1.4pp / 每加 5 只。按此斜率外推，K=20 仍在 7pp 以上，K=40 才可能压到 5pp——那时持仓已覆盖行业池的 8~10%，组合等于行业等权指数本身，Δ 分子（规则−随机）趋零，测出来的「轮动收益」就是行业平均收益，不再是 α。
2. **根因不在宽度，在截面离散度。** 规则篮子自身月波动 σ(rot) = 8.68~12.02pp，随机篮子 σ(rand) = 5.29~5.73pp，两者相差 6pp 以上。K 只影响「选多宽的篮子」，改不了「行业之间本来就有多不一样」。
3. **不是数据问题，三条证伪证据见 §三**：880 白名单化后 σ(Δ) 反而 +94bp；881 断点截干净后 10.53→10.82（噪声内）；σ(rot) 高企与 defect/synthetic 无关。

**可翻案的唯一条件**（两条必须同时满足，缺一不翻）：

| 条件 | 现状 | 门槛 |
|---|---|---|
| 880 换成**真正的成分股加权指数**（当前 880/881 是通达信自编序列，成分、权重、编制口径不可考） | 自编、权重未知 | 用本地个股行情自行合成行业指数，成分与权重可逐期复现 |
| 重建后 σ(rot) 降到 **6 以内** | 8.68~12.02 | ≤6.0（对应 σ(Δ) 才有机会进 4pp） |

这两条都属于**另一轮工程量**：成分股映射（需 PIT 行业归属）、权重定义（市值/等权）、复权与停牌处理、编制口径与现有 880/881 的差异对拍。本轮不做，也不在 advice 主口径那轮里排。

**宽基优先的取舍代价**（必须写明，不是免费换道）：

- 宽基 16 只 K=5、3M 动量、2019+ 的 σ(rot)=5.42、σ(rand)=4.99、σ(Δ)=2.52，反解相关系数 **ρ = 0.89**（σ 报告 §3 末段）。ρ 高意味着规则组合与随机组合**高度同涨同跌**——同日市场涨跌是共同项，相减后基本消掉。
- 代价是**可实现的 Δ 同比变小**：行业池虽然噪声大（σ(Δ) 6~11pp），但潜在 Δ 幅度也大；换宽基后是用「Δ 幅度」换「噪声」，一旦策略 α 原本依赖行业分化，宽基口径会把它摊薄。
- 这个取舍的方向是明确的：**先要「能测出来」（MDE 0.99~1.70pp/期），再谈「幅度多大」**。测不出来的大幅 Δ 没有决策价值。

## 五、待办（只记方案，不动代码）：月末尾部门控改为「该月最后一个有行情交易日」

### 5.1 问题

42 只 880/881 的异常月由「月末必须有行情」这一门控造成：标的在该月最后一个交易日停牌/无该行，整月被丢弃，前后两月被合并成一次「月收益」。其中 23 只的全部异常月都由缺口造成（见 [880_881指数池白黑名单_2026-11-11.md](880_881指数池白黑名单_2026-11-11.md) §二）。

### 5.2 落点行号

文件：[prepare_monthly_samples.py](../tools/research/prepare_monthly_samples.py)

| 位置 | 现状 | 改动 |
|---|---|---|
| `tools/research/prepare_monthly_samples.py:136` | `fac = fac.filter(pl.col('date').is_in(list(mset)))` | **主落点**。改为按 `(ts_code, ym)` 取该月最后一条有行情的记录 |
| 同文件 `:104`~`:108` | `mdates = month_end_dates(...)`、`mset = set(mdates)` | 保留（市场月末仍用于对齐窗口），但不再直接作为标的取样日 |
| 同文件 `:153`~`:157` | `for d in mdates: engine.eligible_set(d, tier='strict', ...)` | **次落点**。准入仍按市场月末求值，若主落点改了取样日，二者会错位，需同步改为按「该股票该月最后一个有行情日」求值，或改为按 `(ts_code, ym)` 左连接 |
| `tools/research/build_analysis_monthly.py:234`~`243` | 读 `pv_monthly` / `eligible_monthly` | 只读消费，需确认 join 键；若按 `(ts_code, date)` 精确匹配，不改次落点会导致整月丢失 |

### 5.3 改法（主落点）

```python
# 原：只保留市场月末日当天的行
fac = fac.filter(pl.col('date').is_in(list(mset)))

# 新：每月取该标的最后一条有行情的记录（仍限定在 mset 覆盖的月份内）
ym_set = [d.strftime('%Y-%m') for d in mdates]
fac = (fac.with_columns(pl.col('date').dt.strftime('%Y-%m').alias('ym'))
       .filter(pl.col('ym').is_in(ym_set))
       .filter(pl.col('date') == pl.col('date').max().over(['ts_code', 'ym']))
       .drop('ym'))
```

要点：
- `fwd_ret` / `fwd_ret_21c` 在日频面板上算完再取样，改取样日不影响前瞻收益定义；
- 取样日不再等于市场月末日，**所有下游按日期对齐的地方都要复核**（至少 `eligible_monthly` 与 `build_analysis_monthly.py` 的 join）；
- 需新增断言：改后每月只数应与「该月有行情的标的数」一致，且不得新增空值（DG-31）。

## 七、局限

1. σ(Δ) 的随机基线依赖 `numpy.random.Generator.choice` 的实现，与本报告口径存在 ±15bp 级别差异；比较一律在同一次运行内完成，跨报告对比请看绝对值差。
2. `defect` 的截断只按 `jump_date` 单点截断，未逐只区分「编制重建」「真实无涨跌幅事件（如 2021-08-10 盐湖股份复牌）」；后者被截断属过度处理，会低估其可用性（对本报告结论无影响，两种处理下 881 都在 10.5~10.9）。
3. K=15/20/25 的拐点未实测，因此「加大 K 能否达标」目前只有趋势判断，没有数字。
