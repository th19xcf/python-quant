## 2. 判定口径与四要素

每条缺口必须同时给出四要素，缺一项即不得判「不影响可收口」：

1. **消费方路径**：`文件:行号` + 起点常量；无消费方须说明「`src/` 全库 grep 零命中」。
2. **缺失影响**：具体到函数 / 因子 / 决策。
3. **量级**：标的数 / 事件数 / 交易日数 + 占比 + 是否改变结论方向。
4. **判定**：只能取「必须补（阻断收口）」/「不影响可收口」/「能补但窗口外」/「按影响判定不采」（有真实消费方，但缺口段全部早于各入口实际生效的读取起点、覆盖外走 `unknown` 且默认放行，补数不改变默认配置下的结论——2026-11-11 新增档，首次用于事件公告：1990–2014 共 25 格归本档；2015–2019 共 5 格**初记「不属本档、补数进行中」，2026-11-11 补数完成后已重判为「可补（已补）」，见 §6.1**）。**判定还必须写明前提**：回测起点由调用方指定、代码无默认值（`src/core/usecases/run_backtest.py:735-737`），凡「零影响」只对默认路径成立。
