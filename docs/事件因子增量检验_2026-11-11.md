# 事件因子增量检验（2026-11-11）

**问题**：事件类因子能否给现有 26 因子等权合成带来真正正交的 alpha。
**结论**：正交性成立、单一事件因子确有独立信息，但并入后 OOS 增量幅度只有 +0.001~+0.006（相对 +1%~+5.5%），且多数未过多重检验门槛 → **无一能进主池**；`ev_equity_incentive` 是本轮唯一有稳定 overlay 证据的事件，其余按「卫星 / 观察」或「无价值」分档。

## 5. 增量 IC（问题 2）

三种并入方式，均只用 IS 定向 / 定权，OOS 验收：

- **A 等权直接加入**：`S1 = (26·S0 + E)/27`；
- **B 等权残差化加入**：`E⊥ = E − β·S0`（逐期截面回归），`S2 = (26·S0 + E⊥)/27`；
- **C IS 定权**：`S_w = (1−w)S0 + w·E_t`，w 在 IS 内取使 RankIC 最大，报 OOS；`E_t` 分 zscore 残差与 rank 残差两种。

基线 OOS：RankIC 0.1026、ICIR 1.0768。

**两个必须写明的发现**：

1. **结果对变换敏感，这是硬伤。** zscore 残差版在 OOS 上是**显著负**的（`ev_net_inc_big_t60` Δ=−0.0011、t=−3.49）；rank 残差版是正。差异来自稀疏事件在 zscore 后尾部到 **+46σ**（85% 为 0，MAD=0，管线的 winsorize 以中位数判上下界故不生效）。同一因子换个单调变换就反号，说明它的"增量"大部分是尾部/并列结构造成的，不是稳定 alpha。
2. **即使最优，幅度也只有 +0.5%~+1.3% 相对。** 34 个候选的 Bonferroni 门槛为 |t|≥3.18；只有 `ev_net_inc_big_t60`(3.89)、`ev_dec_t60`(3.53)、`ev_net_inc_t60`(3.34)、`EVCOMB_t60`(3.26) 过线，而它们的 ΔIC 分别只有 +0.0013/+0.0014/+0.0019/+0.0008。`ev_equity_incentive` 的 +0.0056 最大，但 t=1.85/1.57 未过门槛。

**OOS 注记（2026-11-11 补，来自 overlay 实测）**：上表两行超额是**全样本 143 期**值。按 IS（≤2021-12-31，86 期）/ OOS（≥2022-01-01，57 期）拆开后的实测见 [docs/事件因子overlay接入_2026-11-11.md](docs/事件因子overlay接入_2026-11-11.md)：t20 为 IS **+0.457%（t=3.09）**、OOS **+0.193%（t=1.46）**；t60 为 IS **+0.475%（t=3.20）**、OOS **+0.053%（t=0.58）**。即全样本的 t=3.39/3.16 由 IS 段撑起，OOS 单独看不过 1.96 门槛，t60 在 OOS 基本消失。**后续引用不得再把 +0.343%/+0.301% 当作已证实的样本外结论。** 组合层（top-100、含成本、非重叠 20 日调仓）的 overlay 实测：IS 选出的加分档位落在网格边界（触发股占权重 71.8%/87.5%，已非 overlay）、不可辨识，真 overlay 区间（λ≤0.3）OOS 增量为 −0.7~−1.3pp，判定为**不上**。

补充：`ev_equity_incentive` 的「≥2 次触发」样本只有 172 行 / 73 日期，超额 −0.92%（t=−0.96）→ 强度加权的方向不可判，**样本不足，不下结论**；建议只用 0/1 触发口径。

**caveat**：面板文档记 `ev_equity_incentive` 源端缺 6 个整月（2020-12、2021-01、2021-02、2021-07、2021-10、2022-01），其中 2021-10、2022-01 落在 OOS。实测这 6 个月该列非零股 3,069~7,684 只（见 §2），说明并非无事件、而是缺失子类导致**强度可能低估**。方向上这不削弱 overlay 结论（缺数据只会让触发集合变小、不会凭空造出 +0.343% 的超额），但「触发强度」类用法要留出低估余量；0/1 口径不受影响。**2026-11-11 补：OOS 衰减与缺期无关——缺期只覆盖 2021-10、2022-01 两个期次，而 OOS 共 57 期；衰减是真实的样本外弱化，不是缺期造成。**

## 11. 局限

1. 只有一个合成方式（26 因子等权）与一个标签（h=20、open→open）；残差化只对 S0 做，未对 26 维因子空间做联合正交。
2. 事件强度只用了 0/1 与「计数」两种口径，未做强度分档（≥2 次触发样本普遍不足）。
3. `ev_yoy_*` 只有 2025 起的数据，本轮结论对它不成立，需要 2026 年数据续测。
4. overlay 检验用 20 日超额收益，未检验更短的 5 日窗口（现有标签只有 20 日）。
5. 34 个候选的显著性判断用了 Bonferroni 门槛，未做 block bootstrap；t=3.2~3.9 的四个候选在族内高度相关，有效检验数少于 34。
