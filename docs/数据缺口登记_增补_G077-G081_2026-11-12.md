## 第 2 块：按「语义 / 实测数字 / 影响面 / 判定 / 建议处置」拆开的条目

### G-077｜18 只退市标的股本历史缺失

- **语义**：这 18 只已退市标的在 1990~2010 年代的流通股本（`float_share`）无任何生效日快照，导致其历史换手率无法按 `turn = 成交量 ÷ 流通股本` 派生。
- **实测数字**：缺 **67,213 行**（不是 68,731，也不是 67,215）。单票前五：600680.SH 5,868、000511.SZ 5,548、600806.SH 5,419、600656.SH 5,395、000024.SZ 5,211；最少 300372.SZ 515。
- **影响面**：仅 `stock_turnover` 的这 18 只历史段；18 只均已退市（`daily_index.end` 最早的 2014-04-28、最晚 2019-07-08），不进入当前 `state_vector`（分母按当日有成交标的）、不进入任何当前持仓。
- **判定**：不可补（暂不补）。
- **建议处置**：登记即可，不派任务。若将来回测纳入了这些退市标的，再按 G-078 的同一路数补源。

### G-078｜9 只在市标的零星股本缺失 + 688827.SH 2 行

- **语义**：9 只在市标的的**历史段**（上市初期）流通股本缺记录；688827.SH 是**当前段**（11-10/11-11）股本快照未刷新。
- **实测数字**：9 只共 **1,516 行** = 600018.SH 1,447（2000-07-19~2006-09-25）+ 000028.SZ 42（1993-06-08~1993-08-05）+ 001872.SZ 17（1992-05-05~1992-06-02）+ 000514.SZ 5（1993-07-05~1993-07-09）+ 600744.SH / 600618.SH / 600619.SH / 600620.SH / 000012.SZ 各 1。另有 688827.SH **2 行**（2026-11-10、11-11）。
- **影响面**：1,516 行分布在 1992~2006，只影响历史换手率；688827.SH 两行影响最近两个交易日的换手率（该票近期有行情而股本快照滞后）。
- **判定**：待定（历史段）+ 已排期（688827.SH）。
- **建议处置**：历史段等有含早期生效日的股本源再补；688827.SH 不单开任务，随下一轮股本快照刷新一并补齐。

### G-079｜000001.SZ 1991–1996 行情缺日（换手率多 24 行）

- **语义**：换手率表里有 24 个日期在本地行情中**当日无成交行**，来源是行情源该段本身不完整，不是换手率算错。
- **实测数字**：**1 只 / 24 行**，日期 1991-05-06 ~ 1996-02-09；`turnover` 现有 18,055,784 行中占 24 行。
- **影响面**：仅 000001.SZ 1991–1996；不影响任何 2000 年后的计算。
- **判定**：可补（补行情），但**本表不删**。
- **建议处置**：已在证据 JSON（`gap_breakdown.json` 的 `turnover_extra.judgement`）明确标注 **「行情缺口，非本表缺陷」**，避免以后被当成换手率脏数据清掉；行情侧另按缺口表既有条线处理。

### G-080｜`merge_parts` 分片合并 last 胜导致历史值降级

- **语义**：全量 merge 时按分片顺序「后者覆盖前者」（local 分片在 baostock 分片之后），同键的字段级来源串与历史非空值被粗粒度来源覆盖成 null / 统一来源。
- **实测数字**：被拒产物相对上一版正式表——`pe` 非空 4,464,788 → 713,026、`pb` 8,175,268 → 1,982,588、`dv_ratio` 8,175,268 → 4,247,822；**6,205,505 行**的 `source` 由字段级 `pe=…|pb=…|dv=…|mv=…` 变成 `local:shares_x_close+fin_ttm`。
- **影响面**：任何调用 `merge_parts` 做全量 merge 的入口（估值目前唯一已知）；会同时破坏 DG-19 的字段级可追溯性与 DG-20 的「既有非空值改动数为 0」。
- **判定**：可修、未修。正确行为应为「同键多来源时保留原始来源串，不做 last 胜覆盖」。
- **建议处置**：本次不修；被拒产物 `_backup/derived_catchup_20261112/rejected_valuation_merged_full.parquet`（`b4d34899…`）**不删**，留作修复后对拍的基准。修完后必须给出「既有非空值改动数 = 0」与逐列空值计数证据。

### G-081｜2026-11-11 两融源端未发布

- **语义**：`cn_market_margin_daily` 的 2026-11-11 沪深两市融资买入额/余额当日未发布，非采集链路问题。
- **实测数字**：补到 2026-11-10（8,066 → 8,068 行，沪 `fin_buy 67,333,328,834` / 深 `64,022,000,000`）；2026-11-11 缺 2 行。连带 `state_vector_daily` 2026-11-11 的 `lev_margin_buy_ratio` 为 null、`dims_available = 5`。
- **影响面**：`state_vector` 11-11 一行缺杠杆位与其分位；不回溯改写历史。
- **判定**：待采（源端未更新）。
- **建议处置**：禁止向后填充（旧值填到 11-11 会制造假观测）；下次采集自动补，补完后重跑 `tools/build_state_vector.py` 即可让该行 `dims_available` 回到 6。
