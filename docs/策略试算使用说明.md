# 策略试算使用说明

主界面「量化分析 → 策略试算」标签页：从 `config/strategy_lab/rules/*.json` 下拉选择规则，
直接看回测效果。规则解析与回测适配层在 `src/quant/strategy_lab/`，界面在 `src/ui/strategy_lab/`。

页面展示三张图：净值对比（策略 vs 基准）、回撤曲线、调仓/持仓标记；左侧指标表列宽统一走
`src.ui.table_sizing`。新增或修改规则 = 编辑规则 JSON，页面「刷新列表」后即可看到。

## 一、规则类型

`rule_type` 决定规则的字段集合与执行器，未知值或缺失一律报错，不做类型猜测：

| `rule_type` | 中文 | 用途 | 示例文件 |
|---|---|---|---|
| `stock_select` | 选股 | 全市场条件链 → 排序 → 取前 N，月频调仓 | `示例_低估值低波月频.json` |
| `asset_switch` | 强弱比切换 | 两条标的按比值中枢切换，全仓单腿 | `示例_强弱比双ETF切换.json` |
| `timing` | 仓位择时 | 单标的/组合按信号档位调仓，带滞回 | 暂无示例 |
| `dca_grid` | 定投补仓 | 单标的按跌幅分份补仓 + 止盈回撤清仓 | `示例_4%定投补仓_15%止盈.json` |

所有规则共用：`rule_version`（固定 `strategy_lab/v1`）、`rule_type`、`name`（1~40 字，
不能含 `\/:*?"<>|`）、`period`；`benchmark`（默认沪深300）、`cost`、`portfolio`、
`description`、`data_policy` 可选，缺省取内置默认。出现未开放字段即报错，不静默忽略。

### 复权口径（四类规则统一，唯一路径）

- **换算**：`复权价 = 原始价 × qfq_factor`，只有一处实现——`src/quant/strategy_lab/switch_timing.py`
  的 `_normalize()`；选股侧 `src/backtest/runner/compute.py` 的 `load_universe(..., adjustment='qfq')`
  读的是同一份因子。因子优先取本地行情 `qfq_factor`，该列缺失才退回 `hfq_factor`，
  两者都没有则按 1.0；因子为空值同样按 1.0（不插值、不猜、不造第二套换算）。
- **基准日**：前复权因子定义为「行 t 的因子 = ∏{f_e | 除权日 e > t}」（见
  `src/data/adj_factor_calculator.py`），即**行情最后一个交易日**为基准日、该日因子 1.0、
  价格不缩放；历史价按其后发生的分红与送转等比下调。数据更新后整段序列会整体平移，
  但回测内部的收益率与比值始终自洽。
- **执行**：信号、撮合、盯市都在前复权价空间，行情不再携带 `raw_open` / `raw_close`，
  除权账本一律不传（分红与送转已内含在价格里，再记一遍即重复计入）。
- **已知限制（未修复）**：本地约 65.6% 的基金复权因子恒为 1，这类标的走前复权等于没复权，
  分红不进收益，年化仍可能低估；只做如实标注。


## 二、stock_select：字段与条件

字段白名单唯一来源是 `src/quant/strategy_lab/fields.py`；界面、规则校验、文档共用，
未列入的字段一律拒绝（报「未开放」），不能靠改 JSON 绕过。

PIT 口径三种：

- `bar`：只用信号日及之前的行情 bar，滚动窗口末端必须正好是信号日；
- `asof_trade_date`：按交易日快照取「不晚于信号日的最近一条」；
- `asof_ann_date`：按**公告日**取「不晚于信号日的最近一期财报」。绝不按报告期
  （`end_date`）对齐——报告期早于公告日，按报告期取数会提前看到尚未披露的财务数据。

| 类别 | 字段 | PIT 口径 | 单位 | 来源 |
|---|---|---|---|---|
| 行情 | 收盘价（前复权）`close` | bar | 元 | quotes/stock/** × qfq_factor |
| 行情 | 当日涨跌幅 `pct_chg` | bar | % | quotes/stock/** |
| 行情 | 成交量 `volume` | bar | 手 | quotes/stock/** |
| 行情 | 成交额 `amount` | bar | 元 | quotes/stock/** |
| 行情 | 20日波动率 `vol_20` | bar | 日收益标准差 | 前复权收盘派生 |
| 行情 | 60日波动率 `vol_60` | bar | 日收益标准差 | 前复权收盘派生 |
| 行情 | 20日动量 `mom_20` | bar | 小数 | 前复权收盘派生 |
| 行情 | 60日动量 `mom_60` | bar | 小数 | 前复权收盘派生 |
| 估值 | PE `pe` / PB `pb` / PS `ps` | asof_trade_date | 倍 | valuation_daily.parquet |
| 估值 | 股息率 `dv_ratio` | asof_trade_date | % | valuation_daily.parquet |
| 估值 | 总市值 `total_mv` / 流通市值 `circ_mv` | asof_trade_date | 万元 | valuation_daily.parquet |
| 估值 | EP `ep` = 1/PE，BP `bp` = 1/PB | asof_trade_date | 1/倍 | valuation_daily 派生，仅分母>0 入截面 |
| 财务 | 营收同比 `revenue_yoy` | asof_ann_date | % | income.parquet |
| 财务 | 净利润同比 `net_profit_yoy` | asof_ann_date | % | income.parquet |
| 财务 | 归母净利润 `parent_net_profit` | asof_ann_date | 元 | income.parquet |
| 财务 | 总资产 `total_assets` | asof_ann_date | 元 | balance.parquet |
| 财务 | 所有者权益 `total_equity` | asof_ann_date | 元 | balance.parquet |
| 财务 | 资产负债率 `debt_ratio` | asof_ann_date | % | balance.parquet |
| 财务 | 经营活动现金流 `operating_cf` | asof_ann_date | 元 | cashflow.parquet |
| 财务 | ROE `roe` | asof_ann_date | % | 归母净利/权益，权益>0 才给值 |
| 流动性 | 20日平均成交额 `avg_amount_20` | bar | 元 | quotes/stock/** |

同一公告日有多期财报时取报告期最新的一期；取不到更早记录时该标的当日无值（不填占位）。

条件语义：

- 数值：`>`、`>=`、`<`、`<=`、`==`、`!=`、`between`（含端点，需上下限）；
- 分位：只允许 `>`、`>=`、`<`、`<=`，含义是「与当日截面的 q 分位数比较」。
  例如 `EP >= 分位 0.7` = 保留 EP 排在前 30% 的标的；`波动率 <= 分位 0.5` = 保留最低一半。
  分位阈值每天按**当日当前候选集**重算，不在区间内固定。
- 多条条件自上而下依次生效（后一条在前一条剩余候选上再筛）。
- 缺值一律视为「不通过」：字段无值时无法证明条件成立，不入选，也不补零占位。

选股流程：全市场洁净集（本地行情契约预筛）→ 条件链 → 按排序字段排序
（同值按代码升序，保证结果可复现）→ 取前 N。排序字段缺值的标的不参与排名。

## 三、asset_switch：强弱比切换

关键字段：

- `legs`：至少 2 个 `{code, label}`，代码须为 6 位加 `.SH/.SZ/.BJ`，不能重复；
- `switch`：`numerator` / `denominator`（必须在 legs 中）、`window`（比值中枢天数，2~250）、
  `entry` / `exit`（相对中枢的上下阈值，取值在 (0,1)）、`min_hold_days`、`initial`；
- `positions`：`{"mode": "all_in"}` 全仓单腿；或 `{"mode": "gears", "states": [...]}` 按状态给权重；
- `execution`：固定 `{"price": "next_open", "delay_days": 1}`（T+1 开盘）。

口径：比值 = 分子收盘价 / 分母收盘价的共同交易日序列；中枢 = 最近 `window` 个共同交易日的
比值移动均值。持有分母时比值高于中枢 `(1+entry)` 切到分子；持有分子时比值低于中枢
`(1-exit)` 切到分母；两次切换至少间隔 `min_hold_days` 个共同交易日。

数据不足的处理（示例文件 `data_policy` 已写明）：两腿共同交易日少于 `window+1` 时直接
报「数据不足」并停止，不缩短窗口、不补占位值、不回退到单腿。示例起点 2021-01-04 就是
按 588000.SH（2020-11-16 上市）留足 30 个共同交易日定的。

## 四、timing：仓位择时

关键字段：`target`（`{"mode":"single","code":...}` 或 `{"mode":"portfolio","codes":[...]}`）、
`signal`（`kind` 取 `ma_ratio` / `momentum` / `drawdown`，`window` 2~250）、`levels`
（至少 2 档，`threshold` 严格递增且 `position` 随阈值升高不降）、`hysteresis`（[0, 0.5)）、
`max_step_per_day`（固定 1）、`execution`（同 T+1 开盘）。

信号落在档位上，跨档需越过阈值 `hysteresis`，单日最多调一档；权重按档位仓位与标的数均分。
区间内信号始终低于最低档时返回空结果并给出原因，不静默跑出零收益曲线。

## 五、成交与成本口径

- 信号在信号日收市后生成，引擎在**下一交易日开盘**撮合（`EXECUTION_SPEC`）；
- 选股规则的卖出腿在调仓日前一交易日收盘生成，买入腿在调仓日收盘生成；
- 默认成本（`DEFAULT_COST`，与既有回测配方一致）：滑点 10bp、印花税卖出千分之一、
  佣金万 2.5、最低 5 元、冲击成本系数 0.015；初始资金 10 亿、交易单位 100 股、共享现金池；
- ETF 示例的「单边 0.15%」= 佣金 0.05% + 滑点 10bp，印花税 `fixed_0.0%`、冲击系数 0，
  在规则 JSON 里显式写出；ETF 卖出本身也免印花税；
- 成本默认值改动即改变结果，需在文档与提交里说明。

## 六、结果指标定义

| 指标 | 定义 |
|---|---|
| 年化收益 | 区间首末净值按日历天数折算（`PerformanceAnalyzer`），非简单按 252 日 |
| 最大回撤 | 日频净值序列的历史峰值回撤最大值 |
| Sharpe | 日频收益 × √252 的年化口径（`PerformanceAnalyzer`） |
| 年化波动 | 日频收益标准差 × √252 |
| 单边年换手 | 买入成交额 / 平均净值 / 年数；双边 = 2 × 单边 |
| 年化成本 | 全部交易成本 / 平均净值 / 年数 |
| 基准年化 | 基准指数（默认沪深300）区间首末收盘价折算 |
| 年化超额 | 策略年化 − 基准年化 |
| 信息比率 IR | 月度超额收益均值 / 标准差 × √12（`benchmark_eval.information_ratio`） |

净值与交易全部来自既有引擎 `PortfolioBacktestEngine`，本标签页没有第二套净值计算；
新增的只有三类规则的「信号 → 调度表」适配与上述指标汇总。

## 七、命令行

```powershell
# 字段清单与 PIT 口径
.venv\Scripts\python.exe -m src.quant.strategy_lab.cli --fields

# 列出规则目录
.venv\Scripts\python.exe -m src.quant.strategy_lab.cli --list-rules

# 跑内置选股示例（不落盘）
.venv\Scripts\python.exe -m src.quant.strategy_lab.cli --sample

# 跑指定的切换/择时规则（不落盘；加 --apply 才落净值明细到 reports/strategy_lab/）
.venv\Scripts\python.exe -m src.quant.strategy_lab.cli --rule config/strategy_lab/rules/示例_强弱比双ETF切换.json
```

## 八、已知限制（必读）

1. **参数是事后选的**：字段、阈值、分位、N、窗口、区间都可以反复调，直到曲线好看为止。
   本页面展示的是「这组参数在这段历史上」的结果，不是样本外收益预期；
   参数搜索次数越多，过拟合越严重。看结果时请同时看换手与成本，
   并至少留一段未参与调参的区间自行验证。
2. 选股最小版只有全市场洁净集，没有指数成分约束、行业中性、停牌/ST 之外的额外可交易性过滤。
3. 基准只有沪深300；基准仅用于对比，不参与组合构建。
4. 财报按公告日 as-of，但同一公告日多期取最新报告期；若数据源公告日缺失，该期不参与。
5. 规则保存目录为 `config/strategy_lab/rules/<规则名>.json`；同名保存就地覆盖，不保留历史版本。
6. `asset_switch` / `timing` 的本地行情只查 `data/local_store/quotes/fund` 与 `index`，
   股票代码（`quotes/stock`）不参与切换/择时；行情缺列或共同交易日不足会明确报错。
7. ETF/基金分红在本地 `fund_dividend.parquet` 里没有 `cash_div_fix` / `share_div_fix` /
   `no_ex_rights` 修正列，且 `clean_set` 仍以 `pending_fund_dividend` 标记未结论。
   四类规则统一走前复权价后不再读除权账本，收益靠 `qfq_factor` 体现；但本地约 65.6%
   的基金复权因子恒为 1（如 588000.SH），这些标的等于没复权，分红仍不进收益，年化可能
   低估——该限制未修复，不能视为已解决。
