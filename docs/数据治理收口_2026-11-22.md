## 6. 2026-11-22 补充：三类数据缺口处置

### 6.1 G-061 退市股缺行情分片（已补）

- 探源：tushare `pro.daily` + `pro.adj_factor` 抽样 4 只（退市年份 1999–2019）均返回完整
  OHLC / pre_close / vol / amount 与复权因子，可回补。
- 回补：`tools/backfill_delisted_shards.py --commit --allow-standalone`，
  **81/81 只全部落盘、新增 188,658 行**；q（前复权）= hfq/hfq[-1]，
  pre_close = close.shift(1) × q.shift(1)/q；hfq 对账最大相对误差 0，重复日期 0，
  OHLCV 空值 0（3 只 1990s 标的 source 缺 1 行 amount，留空不猜）。
- 结果：340 只退市股 340/340 有分片；`quotes_stock` 18,363,049 行 / max 2026-11-20。
- 个别标源端末日早于退市日（如 `000418.SZ` 止于 2019-05-07、退市 2019-06-21），
  属源端停牌终止，不补造。

### 6.2 G-067 北交所/精选层首日缺前收（已补）

`limit_daily` 原 71 行 `new_stock_legacy_unpriced`（全部为北交所/精选层个股首日，
`listing_days=1`、prev_close 空、无发行价）。推算优先级：

1. 有效发行价（沪深、2014 年后）→ 发行价 144%/64%；
2. **北交所首日（含精选层/平移）→ 制度不设涨跌幅，不限价、仅按停牌判定可交易**；
3. 非北交所首日仍缺前收但有开盘价 → 以**首日开盘价代前收**，按板块常规幅度，降为单禁
   （`new_stock_legacy_first_day_open`）；
4. 以上都不成立 → 保留双禁（`new_stock_legacy_unpriced`）。

落地：71 行全部由双禁翻为可交易（`new_stock_exempt` 7,170→7,241，
`new_stock_legacy_unpriced` 71→0），limit 表重建为 263 分区 / 16,185,845 行。
