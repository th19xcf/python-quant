## 1. 回测入口本身不选行业

[run_backtest.py](file:///e:/code/python/quant/src/core/usecases/run_backtest.py#L774-L799) 只认
`ts_code` / `ts_codes` / `data`，`industry` 与 `industry_map` 只喂风控的
`max_industry_weight` / `max_industry_hhi`，不参与选池。按行业回测的唯一入口是：

```python
from src.data.industry_universe import select_industry_universe
from src.core.usecases import run_backtest
from src.backtest.strategies.ma_strategy import MAStrategy

u = select_industry_universe('L3', '黄金', '2026-11-09')
assert u.reason is None, u.message          # 空名单必须看 reason，不能当成「无成分」
codes = u.codes                             # 已剔除当日已退市标的
result = run_backtest(
    ts_codes=codes,
    start_date='2026-09-01', end_date='2026-11-09',
    strategies={c: MAStrategy() for c in codes},
    industry_map={c: '黄金' for c in codes},
    oos_ratio=0,
)
```

`select_industry_universe(level, name, as_of, *, include_delisted=False)`：

- `level`：`L1` / `L2` / `L3`；
- `name`：行业名称（`'黄金'`）或行业代码（`'240401'`），精确匹配；
- `as_of`：`date` / `datetime` / `'YYYY-MM-DD'` / `'YYYYMMDD'`；
- `include_delisted`：默认 `False`，剔除 `stock_basic.delist_date <= as_of` 的标的；
- 返回 `IndustryUniverse`，`codes` 可直传 `ts_codes`，`reason` 非空时表示没有可用名单。

## 2. 层级：只有申万 PIT 有 L3

| 表 | 层级 | 说明 |
|---|---|---|
| `meta/industry_pit/industry_pit_sw.parquet` | **L1 + L2 + L3** | 本模块唯一输入；L1 32 / L2 166 / L3 437 个名称 |
| `meta/industry/industry_YYYYMMDD.parquet` | L1 + L2 | 通达信快照，无 L3 列 |
| `meta/industry_pit/industry_pit.parquet` | L1 + L2 | 通达信 PIT，`level` 只有这两个值 |

**通达信 L3 本地不存在。** 通达信原始行业树本身是三级（`T01` / `T0101` / `T010101`），
但 [industry.py](file:///e:/code/python/quant/src/data/industry.py#L93-L99) 在生成快照时
只取前 3 位（一级）与前 5 位（二级），三级不落盘。因此按 L3 选池只能走申万表，
不能用通达信补。

## 3. 2014-02-21 是硬边界

- 1990-01-01 ~ 2014-02-20 的记录是**申万 2003 版行业代码**，与新版的 L1/L2/L3 分类混存在
  同一张区间表里。
- 该区间的名称覆盖不完整：2010 年末 2,122 只在册标的里只有 1,182 只（55.7%）能解析出
  行业名，2011~2013 年同为 56.9%~58.0%；2014 年起升到 98.8% 以上。
- 更关键的是层级语义变了：`贵金属` / `黄金` 这一层是申万 2014 版才有的，黄金 L3 的
  首个 `in_date` 就是 2014-02-21。

因此 `as_of < 2014-02-21` 时函数**直接返回空名单**，`reason='before_sw_tree_effective'`，
`message` 写明边界日与原因。这样做是为了避免把「那 44.3% 没分类的标的」误读成
「不属于该行业」——静默返回 0 条会被当成「该行业当年没有成分」。

## 4. 概念板块表不存在

- `data/local_store` 下按文件名含 `concept` / `theme` / `topic` / `board` 的文件：0 个；
  `meta/**` 全部 parquet 的 schema 里含同类列名：0 个。
- 存在概念**指数日线**（880521 黄金概念、880328 / 881076 黄金、881075 贵金属等），
  但 `meta/index_members/` 只覆盖 6 只宽基指数，**没有任何概念指数的成分表**，
  无法从指数映射到个股。
- 结论：申万 L3「黄金」（240401）是「黄金采选」口径，不等于市场口语的「黄金概念」。
  要按概念筛，需先建 `meta/concept_members/membership_intervals.parquet` 并登记权威路径；
  在此之前只能拿到当日快照，回测历史会有前视偏差。

## 5. 退市口径

`industry_pit_sw` 的 `out_date=null` 只表示「此后没有申万分类变更记录」，**不代表仍在市**：
当前在册的 13 只黄金股里有 3 只已退市（600311.SH 2023-03-27、600687.SH 2021-03-03、
601028.SH 2025-05-26）。所以函数默认再叠加 `meta/stock_basic.parquet` 的 `delist_date`
做第二道过滤；`stock_basic` 缺失或缺 `delist_date` 列时跳过过滤并在 `message` 中注明，
不静默放行。

## 6. 已验证的事实

| 查询 | 结果 |
|---|---|
| `L3 黄金 @ 2015-01-01` | 10 只 |
| `L3 黄金 @ 2016-12-31` | 12 只 |
| `L3 黄金 @ 2021-12-31` | 原始 11 只 → 剔除 600687.SH 后 10 只 |
| `L3 黄金 @ 2026-11-09` | 原始 13 只 → 剔除 3 只退市后 10 只 |
| `L3 黄金 @ 2014-02-20` | 空，`reason=before_sw_tree_effective` |
| `L3 黄金 @ 2014-02-21` | 10 只（首个有效期） |
| 10 只短区间回测 2026-09-01~2026-11-09 | 跑通，`total_return=-0.77%`，44 个净值点，2 笔成交，风控拒单 0 |

## 7. 已知限制

- **指数成分区间表年末超计**（`membership_intervals.parquet`：000300 在 2021-12-31 推出
  328 只、原始月度快照为 300 只）。本次未修，单独登记；需要精确时点成分请直接读
  `index_weight_monthly.parquet` 对应 `trade_date`。
- 单一行业组合只有 10~13 只、同受一条产业链因子驱动，截面相关性极高，结论只能当
  「对该因子的行业 beta」，不能当个股选择能力的证据。
- 2014 年前如需按行业筛，须先补申万 2003 版分类树名称，属另一次数据口径决策。
