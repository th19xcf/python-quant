# A 股风格轮动复盘（1990–2026-10）

> 描述性复盘，**不产出交易信号、不做参数优化、不给买入建议**。结论只回答「哪段风格/行业真实存在、哪段是叙事」。
> 数据：本地 `data/local_store` 只读消费。日期口径：2010-01 ~ 2026-10 为完整月（2026-11 为不完整月，未计入）。
> 报告日期：2026-11-28。

## 0. 口径、分组规则与限制

**数据可得性**
- **2010-01 起可做全 A 横截面定量**：全 A 含退市（`meta/stock_basic.parquet` + `quotes/stock/{sh,sz,bj}/*.parquet`），收益用后复权价（`close*hfq_factor`，与 `pct_chg` 一致）；市值 = 原始收盘 × 生效总股本（`meta/factors/stock_shares.parquet`）；估值/股息取 `factors/factor_panel.parquet` 月末截面 `ep/bp/dy`；行业取 `meta/industry_pit/industry_pit_sw.parquet`（申万一级，共 31 个名称）。
- **1990–2009 仅指数层面**：本地该时段无可靠的**全 A 成分股横截面与行业归属**（行业 PIT 覆盖到 1990 但早期仅数只标的、估值/股本缺失面大），因此这 5 段只给指数涨跌/回撤，**不能做风格或行业定量验证**，逐段标注为「无法验证」。

**风格分组（每月截面独立排序，可复现）**
- 规模：按总市值 pct 排位，**小盘 = 后 30%、大盘 = 前 30%**。
- 价值/成长：`bp>0` 者按账面市值比排位，**价值(高BP) = 前 20%、成长(低BP) = 后 20%**（高 BP 即低 PB/便宜）。
- 高股息：`dy>=0` 者按股息率排位，**高股息 = 前 20%、低股息 = 后 20%**。
- 高换手：月度成交额/市值前 20%（**题材/投机代理**，噪声最大）。
- 小盘高换手：小盘 ∩ 高换手。

**四项指标（每个风格组/行业）**
1. **相对强弱**：区间「(1+组月收益)/(1+全A等权月收益)」连乘 − 1 = 累计超额，并给年化超额。
2. **成交额占比**：区间内该组成交额 / 全市场成交额。
3. **上涨扩散度**：组内「个股月收益 > 全 A 当月等权收益」的观测占比。
4. **区间累计超额与回撤**：上面累计超额 + 组自身复利净值的区间最大回撤。

**基准**：全 A 等权（全体成员当月等权平均，含退市）为主基准；沪深300 仅作指数对照。

**已处理的数据问题（务必连同结论一起看）**
- `factor_panel` 的 `bp/dy` 在 **2015–2017 全缺**，已用 `meta/research_inputs/analysis_monthly.parquet` 的 `ff_value_bp/ff_div_yield` 补齐（bp 同尺度；dy 统一为小数）。
- 月度收益仅在「上一期是紧邻上月」时计算，剔除停牌/复牌/上市跨越造成的伪收益；并按月截面 **1%/99% 截尾**抑制源端异常跳变。
- **ST 未剔除、退市股按存续期计入**（全 A 口径）。这使「价值/高股息」等宽基组合包含较多低价周期与困境股。
- 行业为「**静态现代申万一级回溯归类**」（每只股票最近一次非空名称），仅在分类层面存在前视，用于描述性行业对比，不用于交易。

**读法（重要）**
- **「成长(高PB/昂贵) 长期碾压价值(低PB/便宜)」是这段最稳定的量化事实**：8 段里成长全胜、价值全负。原因是等权「价值」桶装满低价周期与困境股（如 2023 年高BP前排是世茂、荣盛这类出险地产+银行），被价值陷阱拖累；**并不代表「低估值指数」无效**。
- **「小盘」被「大盘」全面压制**：2010–2026 每段小盘累计超额为负。2013–2015 小盘绝对收益 +178%，但同期全A等权 +252%（中小盘/创业板整体更强），等权小盘反而跑输——即「小盘」作为一个宽桶并非当年的最强风格。
- **「高换手」每段大幅为正**，但它等于「最投机/最题材的 20%」，是噪声与题材代理，**不能当作可交易 alpha 解读**。
