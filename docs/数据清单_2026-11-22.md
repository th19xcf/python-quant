# 数据清单（data/local_store）

- 盘点日期：2026-11-22（Asia/Shanghai）
- 范围：`data/local_store/**`（quotes、meta、factors、manifest、freshness 等）；`reports/`、`work/`、`tmp/`、仅作说明，不计入在用口径
- 方式：**只读**。文件数/占用取 `os.walk + os.stat`；行数取 parquet footer `num_rows`（不做抽样估算）；起止日期取 row-group statistics（date32 列）；最后更新取文件 `mtime` 最大值。未改动任何数据或代码。
- 总量：**22,950 个文件 / 4.84 GB**；其中 parquet 11,793 个。剔除 `_backup`、`_staging`、`backtest_runs` 后，在用数据 **11,640 个 parquet / 约 2.66 GB**。
- 口径提示：`quotes/**` 每个标的一对文件（`*.parquet` + `*.manifest.json`），所以“全部文件数”约为 parquet 数的 2 倍。下表“文件数”列格式为 `parquet / 全部`。

## 2. 行情日线 `quotes/`

### 2.1 公共字段（stock / index / fund 三套 schema 完全一致）

| 字段 | 类型 | 单位 | 含义 | 可空 / 已知缺口 |
|---|---|---|---|---|
| `date` | date32 | 日 | 交易日 | 否 |
| `ts_code` | string | — | 标的代码（`600000.SH`） | 否 |
| `open` / `high` / `low` / `close` | double | 元 | 未复权 OHLC | 否；停牌占位 bar 可能四价相等且量为空（见 `meta/suspension`） |
| `pre_close` | double | 元 | 交易所前收（已含除权调整） | 可空（早期/退市尾段） |
| `volume` | double | **手（100 股）** | 成交量 | 可空；实测 `amount/(volume×close)≈100`（600000.SH 2026-11-16~20 比值 98.5~100.4） |
| `amount` | double | 元 | 成交额 | 可空；同实测比值支持元 |
| `pct_chg` | double | % | 涨跌幅 | 可空 |
| `change` | double | 元 | 涨跌额 | 可空 |
| `qfq_factor` / `hfq_factor` | double | 无量纲 | 前复权/后复权因子 | 可空；由 `factors/stock_adj_factor.parquet` 回填 |

- 来源：通达信 `.day`（`h:\zxzq\vipdoc`，清单 `upstream.day_files=10,388`，`latest_day_mtime=2026-11-11 17:00`）；`python -m src.data.local_store build` 写入。
- 频率：日频，收盘后增量。
- 消费：`src/backtest/**`、`src/advice/**`、`src/api/**`、`src/data/local_store/**`。
- 门禁：`src/data/quality/freshness_check.py` 中 `LAG_OK_MAX=1`、`LAG_WARN_MAX=5`（交易日；>5 报 error 并非零退出）；`src/data/quality/clean_set.py` 的 `MAX_SOURCE_LAG_TRADING_DAYS=1` 判定“源已停更”。

### 2.2 期货 `quotes/futures/`

| 字段 | 类型 | 单位 | 含义 | 可空 / 已知缺口 |
|---|---|---|---|---|
| `ts_code` | string | — | 合约代码（`IF.CFX`/`IC1505.CFX`） | 否 |
| `trade_date` | **string（YYYYMMDD）** | 日 | 交易日 | 否；**与全库 date32 约定不一致（D-03）** |
| `pre_close` / `pre_settle` | double | 点 | 昨收/昨结 | 可空 |
| `open` / `high` / `low` / `close` / `settle` | double | 点 | 行情与结算价 | 可空 |
| `change1` / `change2` | double | 点 | 涨跌（收盘/结算口径） | 可空 |
| `vol` | double | 手 | 成交量 | 可空 |
| `amount` | double | 元 | 成交额 | 可空 |
| `oi` / `oi_chg` | double | 手 | 持仓量/持仓变化 | 可空 |

- 缺口：997 个合约文件只到 2026-11-10（其他行情到 11-20）；连续合约与展期在 `meta/multi_asset/futures_continuous.parquet`、`futures_roll_events.parquet`，不在本目录。

### 2.3 清单一致性（实测 vs `quotes/manifest.json`）

|---|---:|---:|---:|
| 总行数 | 25,963,228 | 26,125,941 | +162,713 |
| 最大交易日 | 2026-11-18 | 2026-11-20 | +2 日 |
| index 行数 | 4,656,286 | 4,803,363 | +147,077 |
| stock 行数 | 18,163,246 | 18,174,391 | +11,145 |
