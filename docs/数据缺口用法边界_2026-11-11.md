## 3. 必须写进任何回测报告的口径声明

以下 13 条，使用者不读就会误读结论。每条一句话，可直接粘贴进报告「数据口径」节。

1. **收益起点**：基金一律用「首个 `volume>0` 且 `close` 非占位」的真实成交日，不用 `fund_basic.list_date`（G-017 / G-044 / G-062~G-066）。
2. **占位标的**：84 只整只占位基金（`close≡1.0`/零成交）不计入可交易池与覆盖率分子，`full` 视图自 2026-11-10 起剔除其中 55 只（G-004~G-012 / G-028）。
3. **退市分级母份额**：17 只 `16xxxx` 母份额从来没有场内行情，需要该段历史必须改用 `150xxx` 子份额（G-027）。
4. **退市股样本**：日线只覆盖 343 只退市名单中的约 250 只；起点落在 2015–2019 时结论含幸存者偏差、方向高估，2015 年以前不得用于下结论（G-061）。
5. **ETF 复权**：只用 `fund_adj_factor`，不得用 `fund_corporate_actions_2019plus` 重建，否则黄金 5 次折算各漏 4.2%~6.4%（G-018）。
6. **估值位**：不是官方全 A PE，而是 Σ归母TTM / Σ总市值、亏损股不剔除的降级口径（G-035）。
7. **估值维缺口**：2011-01-04~04-22 共 72 日估值维为 null；含该段的 1,250 日滚动分位不可与其它时点直接比较（G-036）。
8. **换源跳变**：2018-01-02、2015-01-05 两日的盈利收益率跳变是数据源切换口径，不是行情（G-037）。
9. **杠杆位**：只含沪深两市成交与融资，不含北交所，不可称为全市场杠杆（G-038）。
10. **期货成本**：保证金率与手续费按当前值近似，无历史值，历史费后收益不可复核（G-055）。
11. **财务 PIT**：每报告期只有一个版本、无采批时间戳，PIT 结论是「最新修订版近似」，不能声称是历史当时可见的数据（G-068）。
12. **候选集**：状态机回测的 731 个候选信号无法拆到标的，任何「某类标的是否进过候选集」只能回答「未证实」（G-067）。
13. **2004 年基金覆盖率**：该年覆盖率由约 40% 变为 100% 是分母修正（当年多只基金尚未成立），不是补到了数据（G-026）。

### 5.9 规则建议（写进登记表开头或维护说明，下次不靠人眼）

1. **取号前先求最大值**：`Select-String -Path docs\数据缺口登记.md -Pattern 'G-(\d{3})' -AllMatches | ForEach-Object { $_.Matches } | ForEach-Object { [int]$_.Groups[1].Value } | Measure-Object -Maximum`，新号 = max + 1。当前 max = G-068。
2. **退役号不复用**：G-040~G-043 已被 §16 声明不复用；同理 G-015 若选备选 B，退役的那个号也不得再分配给第三个缺口。
3. **撞号自检**：拟用编号先全文计数一次，`G-0xx` 出现次数 > 1 即为撞号（G-015 现状正是 2 次）。表格行计数：`(Select-String -Path docs\数据缺口登记.md -Pattern '^\| \*{0,2}G-\d{3}' | ForEach-Object { ($_.Line -split '\|')[1].Trim() } | Sort-Object -Unique).Count`。
4. **汇总与正文必须相等**：每次改完跑两个数——「正文表格去重编号数」与「§十四 各档编号并集数」，不等即未收口，不得发布。
5. **历史流水只增不改**：§十四 的「N 次更新」行是流水账，改口径只能追加一条并说明「历史行中的 55/56/57 为当时口径」，不得回改历史行。
6. **一个编号只对应一个缺口**：同一字段被两条覆盖时，字段级条目优先，另一条改为指向（5.2 即此规则的首个案例）。
