> **口径状态（2026-11-11 更新）**：主检验期限已由 h=60 切换为 **h=20**（理由见 `docs/策略调优纪律_2026-11-11.md` §1.1，

本文定义「每日推荐」策略的两把尺子：**尺子 A 测选股能力（效应）**，**尺子 B 测可执行性（事实）**。

## 0. 一句话定位

- **A 是效应指标**：回答「这套选股规则有没有超越同日期、同只数的随机组合」。会被「试了很多次才挑出一个」污染，
  因此必须配 Bonferroni 试验预算（当前剩余 **19 次**），且**不设绝对收益门槛**——年化不能当能力证据。
- **B 是事实指标**：回答「按这套交易规则真的能买到、能卖出、扣完成本还剩什么」。它测的是成交率、时滞、成本、
  规则自缚、路径风险，**不消耗试验预算**。
- **禁止混用**：不得用 B 的漂亮数字去凑 A 的显著性，也不得用 A 的显著性掩盖 B 的成交失败。
  两者并列时只能说「选股 X、执行 Y」，不能合成一个「总体得分」。

**共同前提（任一不同则两数不可并列）**：

1. 同一批信号（同一信号日集合、同一打分口径）；
2. 同一时间区间；
3. 同一成本常数 **0.724%**（一次完整往返：双边佣金 + 卖出印花税 + 双边冲击，见
   `src/advice/config.py::TradingCosts.round_trip_rate` 与 `src/backtest/costs/cost_model.py::COST_DEFAULTS`）；
4. 同一主检验期限 **h=20**（2026-11-11 由 h=60 切换，理由见 `docs/策略调优纪律` §1.1：
   h=20 有 81 个独立样本、h=60 只有 26 个；IC 随期限单调上升、不存在衰减，持有期应由成本决定）。
   h=60 的数字一律保留为**稳健性对照**，不是主口径；
5. **同一资金分配口径**（槽位数 / 单票权重 / 现金缓冲 / 现金收益率，现金收益率主口径 **1.5%**）。

**基准三件套（缺一条都不可比）**：`h=20` + `现金 1.5%` + `同一资金分配口径`。
任一条换掉，收益差可以翻转符号（§2.7 六格矩阵即为例证），因此三条必须同时写进任何并列结论里。

## 1. 尺子 A：选股能力（固定持有期口径）

口径与现有产物一致（前向检验、`tools/tune_advice.py`），**本体系只登记字段、不重算**。

### 1.1 主指标（唯一）

| 字段 | 定义 | 单位 |
|---|---|---|
| `delta_excess_pp` | 每期扣成本后净收益 − 「同日、同只数、随机抽 **200** 次」的均值 | pp/期 |
| `delta_t_nw` | 上述差值的 **Newey-West** t 值（滞后阶数按持有期重叠度取 `h-1`） | — |
| `delta_ci95` | Δ 的 95% 置信区间（经 NW 方差修正） | pp/期 |

判定：`delta_t_nw` 显著为正才算「选股有能力」；不显著即视同无证据，不得改口径凑显著。

### 1.2 辅助六项

| 字段 | 定义 |
|---|---|
| `n_independent_periods` | 有效独立期数（非重叠，按持有期 h 折算：`n_periods / h` 向上取整） |
| `delta_win_rate` + `win_rate_ci95` | Δ胜率（策略胜 − 随机胜）及其置信区间 |
| `quantile_monotonic` | Q1~Q5 分组净收益序列与单调性（Spearman 秩相关 + 是否严格单调） |
| `factor_ic` | 因子层面：RankIC / ICIR / t 值 / 三期限（5 / 20 / 60 交易日）衰减 |
| `group_yearly`、`group_regime` | 分年度、分市场状态（多头排列占比分档）的 Δ 与样本数 |
| `attempts_log` | 尝试次数记账（已用次数 / 剩余预算 19 次 / 每次的参数指纹） |

### 1.3 明确不用的指标

- **年化收益**：不是能力指标，仅作参考展示，不得作为通过/不通过的判据。
- 单区间累计收益：受区间长度与市场状态支配，不能跨区间比较。

## 2. 尺子 B：可执行性（状态机口径）

逐日推进：每天用当日及之前的数据重算信号 → 按**生产链路同一套卖出规则**（最小持有期、卖出确认日、
单次换手上限、成本门槛）决定「新进 / 维持 / 退出」→ 持仓跟着状态机走 → 在 T+1 开盘按可成交性撮合。

### 2.1 六项必输出字段

| # | 指标组 | 字段 | 定义 |
|---|---|---|---|
| 1 | 成交可行性 | `signal_to_fill_rate` | 成交笔数 / 信号笔数 |
| | | `blocked_limit_up`、`blocked_limit_down`、`blocked_suspended`、`blocked_no_quote` | 各拦截原因的笔数与占比 |
| | | `blocked_limit_up_amount` | 因涨停未成交的金额（占计划金额比） |
| 2 | 时滞 | `delay_histogram` | 信号日 → 成交日的间隔分布（交易日；当前规则为 T+1，故应全部为 1） |
| | | `overnight_gap_cost` | 隔夜跳空成本：`Σ |open(T+1)/close(T) − 1| × 计划金额`（含符号分量） |
| 3 | 成本分解 | `cost_commission`、`cost_stamp_duty`、`cost_impact` | 三项分项合计（元、占初始权益比） |
| | | `cost_by_size` | 冲击成本按资金规模 **10 万 / 50 万 / 200 万** 三档分别给出 |

| 5 | 路径风险 | `max_drawdown`、`drawdown_duration` | 最大回撤与最长回撤持续交易日 |
| | | `worst_period_return`、`max_consecutive_loss_periods` | 单期最差收益、最长连续亏损期数 |
| 6 | 差异分解 | `decomp_early_exit`、`decomp_late_exit`、`decomp_unfilled`、`decomp_cost`、`decomp_residual` | 见 §2.2 |

### 2.2 差异分解（必须能对上总差）

基准：**同一批信号 + 固定持有 60 个交易日**（在 T+1 开盘买入，持有满 60 个交易日后卖出）。

对状态机实际成交的每一笔持仓：

- 实际收益 `r_actual` = 实际卖出价 / 实际买入价 − 1 − 往返成本；
- 反事实 `r_hold60` = 买入后第 60 个交易日收盘 / 实际买入价 − 1 − 往返成本；
- 单笔差额 `d = r_actual − r_hold60`（按该笔实际投入金额加权）。

分桶规则：

| 桶 | 归属条件 |
|---|---|
| `decomp_early_exit`（早卖） | 实际持有 < 60 个交易日时的 `d` 之和 |
| `decomp_late_exit`（晚卖） | 实际持有 > 60 个交易日时的 `d` 之和 |
| `decomp_unfilled`（未成交） | 每个未成交的买入意图 `−r_hold60` 之和（错过的收益为负贡献；错过亏损为正贡献） |
| `decomp_cost` | 两口径成本总额之差（状态机总成本 − 固定持有总成本） |

恒等式（必须单独列出残差，**不允许调平**）：

```text
总差 ≈ decomp_early_exit + decomp_late_exit + decomp_unfilled + decomp_cost + decomp_residual
```

残差的合法来源：仓位规模与现金缓冲不同（状态机不满仓）、未投资现金的时间价值为零、持仓期跨越窗口边界。
残差过大（> 总差的 30%）本身即为结论：说明两口径的差异主要来自仓位管理而非单笔择时，必须在文档与输出里写明。

### 2.3 前视约束（必须显式声明）

- 信号只用 `as_of` 当日及之前的数据（`AdviceEngine.generate(as_of=...)` 已保证面板截断）；
- 成交一律在 **T+1 开盘**，用 T+1 开盘价与 T+1 的涨跌停价判定能否成交，不使用 T+1 收盘/最高价回填；
- 涨跌停价只用 T 日收盘价与板块规则推导，不使用未来信息；
- 状态机写入下一日的持仓状态时，只能用「今日已成交」的事实，不得写入「明日打算买」的意图；
- 若某条规则依赖当日盘后才知道的信息（例如需要当日收盘后公告），必须在输出 `lookahead_notes` 里逐条列明，
  并说明当前如何处理；**不得用未来数据凑结果**。

## 2.5 尺子 B 的优化路径（短窗口摩擦排序，120 个交易日口径）

> 本节的摩擦排序与三条降换手 / 降冲击建议**全部来自 §2.4 的 120 日短窗口**。
> 全区间（1,818 日）复核后摩擦结构反转，见 §2.6。本节只保留为「短窗口」下的局部结论，
> 不得单独引用为全区间结论。

**摩擦排序（按对总差的绝对贡献，pp/120 交易日）**

| 排名 | 摩擦 | 实测贡献 | 性质 |
|---|---|---|---|
| 1 | 早卖（实际持有 < 60 日） | −6.04 | 卖出规则砍收益 |
| 2 | 未解释残差（仓位规模/现金缓冲） | −2.27 | 仓位管理差异 |
| 3 | 晚卖（实际持有 > 60 日） | −0.63 | 卖出规则砍收益 |
| 4 | 成本差 | −0.27 | 摩擦，但量级小 |
| 5 | 未成交（错过收益） | +0.27 | 反向贡献 |
| — | 涨停 / 跌停 / 停牌拦截 | 0 笔 | 本窗口不是瓶颈 |

**三条降换手**（目标：把年化单边换手从 2.23 压向基线的 0.56，且不碰阈值）

1. **建仓频率从日频降到旬频**：当前 119 个交易日逐日扫描，41 天产出候选、21 笔意图；
   改成每 10 个交易日集中调仓一次，意图数按比例下降而不改变选股口径。
2. **最小持有期与 `validity_days` 对齐**：现在 20 日最小持有、60 日有效期，20~59 日之间的
   持仓只能靠「确认日 + 成本门槛」退出，容易反复进出。先对齐到同一窗口再评估换手。
3. **卖出确认日 3 → 5 日**：实测只挡下 1 笔、平均延迟 2 日，说明当前确认期太短、
   挡不住的噪声交易直接变成换手；延长确认期是纯规则参数，不涉及阈值。

**三条降冲击**（当前冲击 5,789 元，占显性成本 80.2%）

1. **单笔规模分档**：实测单笔约 6.4 万元，按 28.5bp/边线性缩放，三档冲击分别为
   9,120 / 45,600 / 182,400 元；资金上到 200 万级时必须把单笔拆到 ≤ 50 万元，
   否则 0.724% 的成本假设失真。
2. **ADV 参与率硬约束**：`portfolio` 已有 10% ADV 上限，但状态机脚本未接入；
   接入后可把大单自动拆成 2~3 日，冲击从「一次性开盘」降到摊薄口径。
3. **T+1 分批执行**：当前 100% 以 T+1 开盘价成交，隔夜跳空绝对值 6,407 元（0.64pp）；
   改成开盘 + 收盘两段 TWAP，可把跳空成本的对冲掉一部分，且不引入前视。

**可行性前移**（结论：瓶颈在信号端，不在撮合端）

1. **成交前移已完成**：涨停从「建议层拦截」改为「`limit_up_risk` 标注」，成交判定前移到
   撮合层按 T+1 开盘价执行（`RULES_VERSION 2026-11-11.3`）。
2. **未成交意图保留到下一日**：当前买入意图当日未成交即丢弃（卖出有 3 次重试）；
   改为挂单式保留 2~3 日，可提升 `signal_to_fill_rate`（当前 95.24%，已接近上限）。

   是「候选→意图」这一步（仓位空位、换手上限、成本门槛），而不是成交环节；
   在不动阈值的前提下，先解决「空位与意图不匹配」（见降换手第 1 条）。

### 2.6.3 四块分解与残差（不调平）

恒等式校验：`−4.3755 + (−0.2830) + 20.5051 + (−5.1316) + (−9.6814) = +1.0336pp`，与总差一致。

| 桶 | 贡献（pp） | 占总差 | 占绝对值之和 |
|---|---|---|---|
| `decomp_early_exit` | −4.3755 | −423.3% | 14.4% |
| `decomp_late_exit` | −0.2830 | −27.4% | 0.9% |
| `decomp_unfilled` | **+20.5051** | +1,983.9% | **67.7%** |
| `decomp_cost` | **−5.1316** | −496.5% | 16.9% |
| `decomp_residual` | **−9.6814** | **−936.69%** | — |
| **总差** | **+1.0336** | 100% | — |

残差占比 −936.69% 远超 §2.2 的 30% 阈值。按 §2.2 的定义，这本身即为结论：
**两口径的差异主要来自仓位管理与现金规模，而不是单笔择时**。已核实的三条来源：
① 状态机按 1/15 建仓 + 10% 现金缓冲，基线按 3 槽×33.33% 分槽，平均现金占比相差 23.5pp；
② 未投资现金按零收益计（见 2.6.5 的两版口径）；
③ 恰好持有 60 个交易日的持仓有 **1 笔**，其单笔差额按规则既不算早卖也不算晚卖，整体计入残差
（`closed_exact_60d_into_residual = 1`；无 60 日目标的持仓 `closed_without_60d_target = 0`，
即没有因窗口边界而补不出的反事实，也没有用未来数据补齐）。前两条已写入
`summary.decomp_detail.residual_sources`，第三条写在计数字段里。

**「74.6% 早卖主导」这个结构在长区间不成立**：
（74.6% 是成本口径修正前的短窗口读数，修正后为 §2.4 的 67.6%；两者同为「短窗口早卖占比」，
下表的对照因此都用修正后的 67.6% 作短窗口基准。）

| 口径 | 短窗口（120 日，§2.4） | 全区间（1,818 日） |
|---|---|---|
| 早卖 / 总差 | −6.04 / −8.94 = **67.6%** | −4.3755 / +1.0336 = **−423.3%** |
| 早卖 / 绝对值之和 | 83.7% | **14.4%** |
| 排第一的桶 | 早卖（83.7%） | **未成交（67.7%）** |

短窗口里「卖出规则自缚」是主项；全区间里它退到第四位，主项变成「未成交」与「成本」两股方向相反、
量级相当的力量（+20.51 vs −5.13pp），总差被抵消到 +1.03pp。**总差近零，不得读作「状态机优于固定持有」**。

### 2.6.4 未成交诊断（+20.51pp 从哪里来）

| 项 | 数值 |
|---|---|
| 未成交买入意图 | 99 笔，计划金额 6,589,741.62 元（占全部计划金额 17,742,413.42 元的 **37.14%**） |
| 拦截原因 | 换手上限 **97 笔**（6,466,295.67 元）、涨停 2 笔（123,445.95 元）；跌停/停牌/无行情/现金均为 0 |

### 2.6.5 残差再压一次：现金收益两版口径

方法：在已记录的逐日现金余额上**事后累加**利息（`现金 × 年化利率 / 252`），一次性加到期末净值；
不改写成交、持仓与复利路径，因此是量级敏感性，不是复利重跑。

| 口径 | 状态机期末净值 | 状态机累计 | 基线期末净值 | 基线累计 | 两口径差 |
|---|---|---|---|---|---|
| 现金按 **0%**（默认） | 985,237.13 | −1.48% | 974,901.42 | −2.51% | **+1.034pp**（状态机优） |
| 现金按 **1.5%** 年化 | 1,051,588.28 | +5.16% | 1,063,933.11 | +6.39% | **−1.234pp**（状态机劣） |
| 差额（1.5% − 0%） | **+6.635pp**（利息 66,351.15 元） | | **+8.903pp**（利息 89,031.69 元） | | 翻转 2.268pp |

结论：现金收益口径足以让「谁更好」翻转，且翻转方向由现金规模决定——基线平均 86.14% 的现金
吃到 89,032 元利息，状态机只有 62.62% 的现金、吃 66,351 元。这说明残差的 −9.68pp 里有一大块
就是「现金多与少 × 现金收益率」，与选股、择时都无关。

**口径决定（2026-11-11 复核，改动前后并列）**：**现金收益 1.5% 改为主口径**——现金真实生息，
按 0% 算等于系统性低估持仓更多的那一方；0% 保留作对照。改动前后：状态机 0% → 1.5% 为
−1.48% → **+5.16%**；次口径基线（slots=3）−2.51% → **+6.39%**，两口径差由 **+1.03pp 翻转成 −1.23pp**。
主口径下的完整对照见 §2.7。

## 2.7 基线三档资金分配 × 现金收益两档（口径敏感性矩阵）

### 2.7.1 三档基线怎么定义（`a` 为与尺子 A 同构的主口径）

**先查实 A 的实际分配**（代码 + 实际仓位序列，不是推断）：

| 项 | 事实 | 位置 |
|---|---|---|
| 信号日 | 每个自然月最后一个交易日，共 `rebalance_days = 92` 个扫描日 | `run_forward_test.py::rebalance_dates()` |
| 仓位 | 取生产管线的 `target_weight`，单票上限 1/15；**每期合计仓位 5.40%~39.72%，均值 22.49%**（56 个有票日、209 行） | `signals.csv`（tier=mid、variant=on、`ok_60` 口径） |
| 期收益 | 该期所选标的净收益的**等权平均**（不加权、不与其它期共享资金） | `run_forward_test.py::analyze()` |
| 撮合 | T+1 **开盘**买入，持有 h=60 个交易日后按**收盘**卖出 | `run_forward_test.py::price_labels()` |

所以 A **不是满仓、也没有槽位预算**——它每期只投约 22.5% 的仓位，各期独立度量。据此定义三档：

| 档位 | 定义 | 定位 |
|---|---|---|
| `a` | 逐笔复现 A 的 209 行：每票 `target_weight × 当日权益`，T+1 开盘买、第 60 个交易日收盘卖，全部 lot 共享一个现金池、跨月叠加、不预分配不锁仓 | **主口径**（与 A 同构） |
| `slots` | 按相邻信号日间隔反推 `slots=3`，每槽预算 equity/3，票按 `target_weight`，到期开盘卖 | **次口径**（原 §2.6 基线） |
| `slots60` | 日频旧行为在月频下的样子：每槽预算 equity/60 | 对照口径（说明「闲置」有多严重） |

`a` 档的仓位画像是：平均现金 60.46%、平均在手 6.65 只（上限 15）、**日均总仓位 39.54%**（峰值 91.14%）。
比 A 的单期 22.49% 高 1.76 倍，原因是 60 日持有叠加月度信号后平均同时在场约 2 个期次——
这是资金池共享后的结构差异，不是放大杠杆。

### 2.7.3 这个差距能说明什么、不能说明什么

**不能**说「执行规则输给固定持有 14.9pp」：`a` 档的候选集是 A 自己的 209 行（56 个有票日、日均 3.7 笔），
而状态机一侧用的是 `select_candidates` 的 847 个候选（39 个有候选日、日均 21.7 个）。
两者**候选集不同源**，−14.9pp 里混着「选了哪些票」的差异，本次没有拆分。

**能**说的是三件事：

1. 基线口径本身足以让符号翻转，所以「状态机 vs 固定持有」在口径未锁死前不构成证据（这也是
   §0「共同前提」要求的第四条：资金分配口径也必须是同一套）。
2. 与 A 同构的两档现金口径都指向同一方向（状态机落后），这个方向比 `slots` 档更稳定。
3. 状态机的成本（8.04%）低于 `a`（9.99%）、换手（1.56）低于 `a`（1.70），但收益更差 →
   差距不在成本，而在「买了什么、拿了多久」，与 §2.6 的分解方向一致。

### 2.7.4 近似处理点（全部已在 `report.md` 与 `summary.json` 登记）

1. `signals.csv` 没有 `exit_date_60` 列，用同口径 `shift` 反推，并用 `exit_close_60` 逐值校验
   **209/209 精确命中**。
2. A 的价格是后复权，撮合用的 `raw_close` 不能估值 → `a` 档估值统一用面板后复权 `close`；
   201 笔到期卖出与 `exit_close_60` 的平均相对差 **0.00%**。整手取整按 `raw_open`，避免高价复权票被误判买不起。
3. 停牌/缺当日收盘时沿用该 lot 最近可得收盘价（首次回退买入开盘价），共 **279 个 lot-日**回退。
4. `a` 档 NAV 按真实现金流乘法扣 0.724%/往返，与 `net_60` 的加法扣减差 1~2bp；`net_60` 只用于口径对拍。
5. 期末 3 只 lot 未到期，按最后收盘价计价（不计为成交）。
6. 口径对拍：`a` 档在「不限现金」下每期净收益均值 = **0.0272108998**，与 `stats_main.csv` 的
   `rec_net` 完全相同（绝对差 3.47e-18）。

## 3. 判读矩阵（结论的唯一合法读法）

| A | B | 结论指向 |
|---|---|---|
| 显著为正 | 正 | 可用，进入容量评估 |
| 显著为正 | 负或零 | 选股行、执行不行，先改交易约束 |
| 不显著 | 明显更差 | 摩擦在吃钱，先降成本与换手 |
| 显著为负 | 任何 | 不动 B，回去修选股 |

补充：A 显著为正且 B 为负时，**不得**通过放宽 B 的规则把数字做正——先定位是成交失败、时滞、成本还是规则自缚，
