## 4. 三档判定规则

```
if max|rho| >= 0.95                                  → 不纳入（重复）
elif t 过阈值的期限数 >= 2 且 OOS 覆盖 >= 0.60 且三期限同号
     且 max|rho| < 0.90 且 ΔR²(h=20) >= 0.02%        → 值得纳入
elif |t(h=20)| >= 1.8 或 t 过阈值期限数 >= 1          → 观察
else                                                  → 不纳入
```

补充口径：`|t| >= 3.1` 作为「过阈值」的近似基准（N≈20 时 h=20 的 t\*=3.163），
因此该分档对 N 的变化不敏感，但真正启用时仍以当次 N 对应的 t\* 为准。

## 5. 分档理由

### 5.1 值得纳入：`g_sue`

- 三期限同号且 h=5、h=60 的 |t| 分别为 4.35、3.56，是被测候选里唯一在
  「残差 IC 幅度 × 稳定性 × 低重复度」三项同时靠前的因子。
- 与 28 因子的最大相关仅 0.487（其余「观察」项多在 0.75~0.94），
  说明它带来的是**新维度**（盈利意外）而不是既有动量/波动的换名。
- ΔR²(h=20) 0.30% 不是最高（`g_revenue_yoy` 0.35%），但 `g_revenue_yoy` 的相关 0.341 也低、
  幅度更大却在 h=60 掉到 t=1.77，稳定性弱于 `g_sue`。
- **限制**：N=30 时 h=20 的 t\*=3.301，`g_sue` 的 2.66 不过线。
  所以准确表述是「h=5 明确、h=20 边缘、h=60 接近但不过 N=30 门槛」。
  启用前应先在 h=5 上做组合层验证，而不是直接按三期限加权。

### 5.2 观察（有增量但重复或覆盖/稳定性不足）

| 因子 | 观察理由 |
|---|---|
| `v_ivol_60` | 残差 IC 绝对值最大（h=20 达 −0.0289，t=−6.62），但 |rho|=0.927 与现有波动类高度重叠；是「同一维度的更锐利表达」，不是新维度 |
| `v_max_5d_21` | 同上（rho=0.943），h=60 已掉到 t=−1.30 |
| `v_skew_60` | 相关 0.759 相对干净、三期限同号且 h=60 仍在 t=−2.60，但幅度小（h=20 仅 −0.0124），未过 N=20 门槛 |
| `q_ocf_to_profit` | 幅度与 t 都够（h=5 t=2.68、h=60 t=2.29），但覆盖率只有 81%/76.7%——净利≤0 时按定义记空，行业性缺失（金融、周期底部）会带来截面偏差，需先解决覆盖再谈启用 |
| `g_revenue_yoy` | ΔR²(h=20) 0.35% 为全候选最高、相关仅 0.341，但 h=60 t=1.77 不稳 |
| `q_accruals` | 三期限同号、经济含义清晰（应计异象），但幅度小且 h=20 t 仅 −1.99 |
| `v_cfp` | h=5 t=3.20 过 N=20 门槛，h=20/60 掉到 1.97/1.85；相关 0.503 可接受，属「方向对但期限不稳」 |

## 6. Bonferroni 预算：N 从 20 增到 30、40 的代价

按 α\*=0.05/N、t 临界值取自由度 T−1 的 t 分布分位（T_oos = 234/57/18），
MDE\_IC = t\* × median(IC 时序标准差) / √T；单期最小可检出收益 = t\* × 3.52% / √19
（沿用 60 日期框架 σ=3.52%、n=19）。

| N | 期限 | α\* | t\* | MDE\_IC | 单期 MDE 收益 |
|---|---|---|---|---|---|
| 20 | h=5 | 0.00250 | 3.057 | 0.0101 | 2.469% |
| 30 | h=5 | 0.00167 | 3.182 | 0.0105 | 2.569% |
| 40 | h=5 | 0.00125 | 3.268 | 0.0108 | 2.639% |
| 20 | h=20 | 0.00250 | 3.163 | 0.0219 | 2.555% |
| 30 | h=20 | 0.00167 | 3.301 | 0.0229 | 2.666% |
| 40 | h=20 | 0.00125 | 3.396 | 0.0235 | 2.743% |
| 20 | h=60 | 0.00250 | 3.510 | 0.0434 | 2.835% |
| 30 | h=60 | 0.00167 | 3.692 | 0.0456 | 2.982% |
| 40 | h=60 | 0.00125 | 3.822 | 0.0472 | 3.086% |

**每多纳一个因子的成本**

- 20 → 30（+10 个检验）：h=20 的 t 门槛抬 0.138（+4.4%），MDE\_IC 抬 0.0010（+4.3%），
  单期可检出收益从 2.555% 抬到 2.666%（+0.111pp）。
- 30 → 40（再 +10 个）：t 门槛再抬 0.095，MDE\_IC +0.0007（+2.9%）。
- 20 → 40 累计：MDE\_IC +7.4%，单期 MDE 收益 +0.188pp。
- 边际成本递减（+4.3% → +2.9%）是因为 t 分布尾部变平，但**绝对门槛单调上升**，
  意味着：每纳入一个「边缘显著」的因子，都会让所有因子的准入门槛一起变高。
  按当前 N=20 的预算，`g_sue` 是唯一「加进去不亏」的（h=5 t=4.35 远高于 3.18）；
  `v_cfp`（h=5 t=3.20）在 N=30 下就落到门槛下方，属于「加它会把预算吃掉」。

**主口径改为 h=20 后的重述（2026-11-11）**：`g_sue` 的 h=20 实测 t=2.66，低于 N=20 门槛 3.163、
更低于 N=30 门槛 3.301——**h=20 下不达标，不纳入本批**。它在 h=5（t=4.35）与 h=60（t=3.56，
仍低于 N=30 的 3.692）上的表现不作为纳入依据，不得因短/长周期过线而保留。

| 个股融资融券余额（券余额占流通市值） | 个股两融明细 | 仅有 `cn_market_margin_daily`（**市场层面**总量），无法下沉到个股 |
| 分红 / 拆股事件驱动 | 已有 `ff_div_yield`，事件表 `meta/events/events.parquet` 存在 | 事件驱动需逐事件窗口建模，不属于横截面因子，本轮不做 |

另有两类「数据有但口径不满足」的：

- **财报附注类**（研发费用率、存货周转、应收账款周转）：`income` / `balance` 已含部分字段，
  但字段缺失率在 2015 年前后不一致，做全历史会引入结构性断层；本轮只做已确认完备的 6 个质量指标。
- **行业中性化后的残差因子**：需要行业分类的 PIT 版本，现有 `meta/industry` 为静态快照，
  无法保证历史时点不泄露，本轮不做。

## 9. 局限与未做的事

1. **只做单因子残差 IC**，没有做组合层（多因子同时加入后的边际 Sharpe / 换手成本）。
   单因子显著不等于组合里有用，`g_sue` 若启用仍需组合层验证。
2. **未做行业/市值中性化**（见 §7 静态行业快照问题），残差里可能仍含行业暴露。
3. **未做交易成本与容量测算**，MDE 收益是毛口径。
4. **is 段与 oos 段的分档只看 OOS**；IS 数值保存在 `residual_ic.csv` 供复核，
   但刻意不参与分档，避免用样本内挑因子。
5. 分档阈值（0.95 重复线、3.1 t 线、0.02% ΔR² 线）是**本轮一次性口径**，
   已在 `analyze.py` 中硬编码并写明，后续如需调整须重跑并对比。
