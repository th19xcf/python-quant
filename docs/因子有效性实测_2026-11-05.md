## 一、结论三句

1. **真正有用的因子集中在"低流动性 / 低波动 / 短期反转"三条线上**：`liquidity_log`（= `amount_ma20` 的对数变换）IS ICIR **-0.83**、Q5−Q1 年化 **-20.7%**；`volatility_20` **-0.64**、`atr_pct` **-0.53**、`downside_risk_20` **-0.38**、`max_drawdown_20` **+0.39**；短期反转/均线偏离 `momentum_1m`(= `ret_20`) **-0.55**、`ma20_gap` **-0.51**、`ma60_gap` **-0.54**。价值/股息线也稳定：`ff_value_bp` **+0.40**、`ff_sales_yield` **+0.39**、`ff_div_yield` **+0.56**。30 个因子 IS 与 OOS 同号率 **30/30**，OOS 仍有 **21/30** 个 |t|≥2。
2. **"小市值错觉"很小，但不是零**。规模因子 `ff_size` 自身在 IS 不显著（ICIR -0.146，t=-1.13，OOS 才到 -0.318/t=-2.11）；技术因子与 ln 市值秩相关普遍只有 |ρ|≈0.08~0.23，只有流动性一对达到 **0.544**。行业+市值中性化后多数因子 ICIR 反而**上升**（`volatility_20` -0.449 → **-0.637**），唯一被明显削弱的是 `amount_ma20`（-0.781 → -0.606，约 **22%** 的 ICIR 来自规模/流动性水平）。
3. **最值得补的三个**：① **20 日真实换手率**（公式 `ext_turnover_20` 已写好，但对月度面板不成立，必须回日频算，几乎零成本）；② **行业相对强度**（行业分类 + 本地行情截面聚合，几乎零成本）；③ **盈余修正 SUE**（本地利润表 2016Q1 起含 `ann_date`，2018 年起可完整回测）。

### 2.1 三项必须随结果一起看的口径披露

**（1）行业中性化用的是 2026-11-05 单日行业快照，不是 PIT。** 评估代码读取 `data/local_store/meta/industry/industry_20261105.parquet`，把这份“今天的行业归属”直接套到 2015-2026 的每个历史截面。也就是说，回测 2015 年用的行业分类是 2026-11-05 才形成的分类。本地只有 `industry_20261103/04/05` 三份连续快照，`tdxhy.cfg` 也只有当前映射，`block_*.dat` 仅有 2019-09-17 单份且为概念/风格板块而非逐年行业分类——**没有逐年行业分类快照可用，公开源同样没有**。因此这件事有两个硬事实：**漂移对 IC/ICIR 的影响无法量化，且用现有数据无法修复**。不能用“轻微漂移”来描述；只能接受“用今天的行业归属做历史中性化”这一近似，或改用只对市值中性化的保守口径（两者数字不同，不可混用）。

**（2）234 只 `unknown`（快照口径 234/5,812 = 4.03%）如何进入中性化。** 评估里的实际处置是：先把行业空值 `fill_null('unknown')`，再做 `pd.get_dummies(drop_first=True)`；由于 `unknown` 按字典序排在最前，它被 `drop_first` 选为**基准组**（等价于“unknown 有自己的截距、其它行业为相对哑变量”），**不是把该行丢弃，也不是把 unknown 当作缺失跳过该因子**。因此 unknown 标的的观测全部保留：IS **13,641 条（占 4.97%）**、OOS **1,537 条（0.73%）**；分年占比从 2015 年 **8.28%** 降到 2022 年 **2.37%**、2025 年 **0.26%**。方向性影响：unknown 组只由截距吸收，组内无法再按行业细分；由于 unknown 主要是小盘/已退市标的，若某因子的收益主要来自这一组，其组内共同均值会被扣掉，IC 被压低而非放大——处置方向偏保守，且不引入前视。

**（3）`ff_*` 的 IS 实际只有 2018-2022，与价量因子的 2015-2022 不能横比。** `valuation_daily` 自 **2018-01-02** 才有数据，`ff_size / ff_value_bp / ff_value_ep / ff_sales_yield / ff_div_yield` 的 IS 覆盖率只有 69.1%~70.6%，有效月份仅 2018-2022；下一节排序表按 IS ICIR 混排了这两个不同区间的因子组，**二者的 ICIR/t 不可直接横向比较**，只能组内比较。`ff_investment` 用利润表/资产负债表，2017 起才有数据，同样不属于 2015 起的价量样本区间。

### 3.1 需要提醒的读数

- **ICIR 高 ≠ 多空收益大**：`ff_div_yield` ICIR 最高（0.557），但 Q5−Q1 只有 **3.28%/年**，属于"很稳但很弱"；多空收益真正大的是流动性/波动率/反转类（10~20%/年）。

- **重复列**：`momentum_1m` 与 `ret_20` 秩相关 **1.000**、`liquidity_log` 与 `amount_ma20` 秩相关 **1.000**（后者只是前者的 `log(x+1)`），24 列实际只有 **22 个独立定义**（再剔除前视的 `history_rows` 后为 21 个可用）。
- **高相关簇**（日均秩相关）：`kdj_k~kdj_d` 0.94、`rsi_14~ma20_gap` 0.876、`volatility_20~atr_pct` 0.858、`sharpe_ratio_20~ret_20` 0.884。做组合时应按簇降权，而不是把一簇里的 5 个因子各给 1/5 权重。

### 5.1 "小市值错觉"到底多大

用三组证据量化：

1. **规模因子自身**：IS ICIR -0.146、t=-1.13（不显著）；只有到 OOS 才 -0.318、t=-2.11。2015-2022 的 strict 池里"小市值溢价"本身就不稳。
2. **因子与市值的截面秩相关**（IS 月均）：技术因子 |ρ| 多在 0.04~0.23；只有 `amount_ma20`/`liquidity_log` 达 **0.544**。价值类为正（+0.09~+0.19，高股息/高 bp 偏大盘）。
3. **中性化前后的 ICIR 变化**：`amount_ma20` 从 -0.781 降到 -0.606（**约 22% 的 ICIR 来自规模/流动性水平**）；`ma20_gap` -0.343→-0.508、`momentum_1m` -0.400→-0.548、`volatility_20` -0.449→-0.637、`atr_pct` -0.381→-0.533 —— **中性化后更强**，说明这些不是小市值替身，而是行业轮动/规模暴露掩盖了真实信号。

结论：**用"技术因子只是小市值"来解释这批结果是不成立的**；唯一需要打折的是成交额/流动性绝对值因子（约 1/5 的力度来自规模），但打折后仍是全场最强。

## 六、前视审计（红线项）

### 6.1 `history_rows` 是前视因子，必须剔除

`src/advice/factor_panel.py:68` 定义为 `pl.len().over('ts_code')` —— 它返回的是**输入面板的总行数**，不是"截至 T 的已有行数"。

本次截断审计（同一标的、同一日期，全量面板 vs 截至 T 截断面板重算）：

- 价量因子共 **874** 个（标的×日期×因子）组合，**不一致 0 个**；
- `history_rows` 38 个可比较组合 **38 个全部不一致**（例：000011.SZ 在 2018-06-29，全量 8195 vs 截断 6171）。

如果照原样使用，它会把"这只票在数据里活到多晚"编码进因子，等价于**未来生存信息**。把它按中性化流程算一遍会得到 IS ICIR 0.223（t=2.19）、OOS 0.358（t=2.38）的"可用"假象（其原始 IC 仅 0.010/0.006，是中性化残差把它变成了市值/行业替身；证据见 `history_rows_invalid.json`）。**已从排序表剔除，不计入任何结论。**

> 建议：`history_rows` 只应作为"面板深度"诊断量；若想做上市年龄因子，必须用 `cum_count over ts_code`（本次已用 `hist_seq` 做历史长度掩码）。

### 6.2 其余价量因子无前视

`momentum_* / rsi / macd / kdj / volatility / atr / ma*_gap / trend_slope / ret_20 / amount_ma20 / liquidity_log / volume_* / sharpe / max_drawdown / downside_risk` 全部通过截断重算，0 不一致。因子只依赖 `.shift()` / `rolling_*` 的向后窗口，结构上不可能看到未来。

### 6.3 财务因子可见性

- `ff_*` 走 `ann_date` 的 as-of 连接（`fundamental_factors.py:138-146`），TTM 只用已公告报告期。
- 独立复核：随机 30 个（标的×日期），用"只取 `ann_date ≤ T` 的报表"重算 TTM 营收，与 `ff_sales_yield × total_mv` 反推值比较，**最大相对偏差 1.64e-16**。
- 残留口径风险：`ttm_from_cumulative` 用"上年年报"时按财年 join，未再校验该年报的 `ann_date` 是否早于本期公告日；30 个抽样未命中异常，但这是**低概率口径风险**，建议补一条单测锁定。

## 九、局限（必须带着看）

1. **容量与成本未计入**：所有多空收益为等权、未扣费、无冲击成本。`liquidity_log`/`momentum_1m` 的空头端是低流动性小票，实盘无法按等权全量成交；真实可实现收益会显著低于表中的 -20%/-16%。
2. **前瞻收益的生存偏差**：只有"T+21 仍有行情"的标的才计入收益；21 日内退市的样本被丢弃（少量），会给所有因子带来轻微正向偏差。
3. **行业分类非 PIT（影响无法量化、无法修复）**：中性化与行业相关度用的是 2026-11-05 单日快照，回测 2015 年用的是“今天的行业归属”；本地与公开源都没有逐年行业分类快照，故漂移对 IC/ICIR 的影响**无法量化，也无法修复**（详见正文 2.1 第 1 条）；234 只 `unknown` 标的的处置与观测数见 2.1 第 2 条。
4. **市值代理**：用"原始收盘价 × 当期流通股本"，与 `ff_size` 秩相关 1.000，但和交易所口径的 `circ_mv` 仍有细微差异；`valuation_daily` 的 `circ_mv` 只有 2018 起，无法全程统一。
5. **IS/OOS 样本起点不同**：`ff_*` 的 IS 实际只有 2018-2022（估值数据 2018 起），与价量因子的 2015-2022 不完全可比；表中已按有值月份计算，覆盖率列已标明（正文 2.1 第 3 条与第三节前已单独提示）。
6. **月度重叠**：T+1 开盘→T+21 收盘约 20 个交易日，相邻月样本有约 1 天重叠；年化按 12/月数 折算，是近似值。
7. **判定阈值是自定的**：|ICIR|≥0.30、|t|≥2 属于行业常用门槛，不是绝对真理；`ff_value_ep` 恰好 0.2999 被判"边缘"。
