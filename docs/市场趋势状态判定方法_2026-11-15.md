# 市场趋势状态判定方法（2026-11-15）

> 来源：`tmp/趋势算法.txt` 中六份回答去重后按层归类，只保留与本项目本地数据可衔接的部分。
> 代码：`src/quant/analysis/market_trend_state.py`（纯计算）、`src/quant/analysis/market_trend_local.py`（本地装配 + CLI）。
> 定位：判断「市场处在什么状态」，不选股、不预测点位、不构成投资建议。

---

## 1. 目标与边界

- 目标周期：未来数周到数月的中期趋势（不是日内，也不是季度配置）。
- 只回答三件事：方向（趋势）、上涨是否覆盖多数股票（宽度）、资金与成交是否支持这个方向（量价资金），再用波动情绪与估值宏观做验证。
- 选股因子（动量、反转、规模、价值、质量、红利、拥挤度）只用于解释风格，不参与本模型打分。
- 本模型是**状态分类器**，不是收益预测器；分数不是上涨概率。

## 2. 统一口径（先读这一节）

### 2.1 时间与 shift(1)

- 所有指标在交易日 `t` 收盘后计算，使用截至 `t` 收盘的数据；标签 `S_t` 表示 `t` 日收盘状态。
- 可交易口径必须滞后一天：`S_exec,t = S_{t-1}`（shift(1)）。本模型的 CLI 与界面展示的是 `S_t`，用于当日复盘与次日计划，不得按 `S_t` 在 `t` 日收盘价成交。
- 滚动窗口均按交易日计数，不按自然日；停牌、无成交的标的当日不进宽度分母。

### 2.2 阈值一律滚动分位

- 禁止使用绝对点位（如上证 3600、全 A 5000）与绝对成交额（如 1.5 万亿、2 万亿）。
- 所有强弱判据统一转成滚动分位：`pct_t = (窗口内小于 x_t 的个数 + 0.5 × 等于 x_t 的个数) / 有效样本数 × 100`（并列值取中位秩）。
- 趋势 / 宽度 / 量价资金 / 波动情绪使用 **250 个有效交易日**窗口（`min_samples=250`，不足 250 个有效值给 null，不插值、不退回全样本）。
- 估值使用 `state_vector_daily` 已算好的 **1250 个有效交易日**滚动分位（`QUANTILE_WINDOW=1250`，满窗才给值）。1250 ≥ 250，符合「≥250 日」要求。
- 扩张窗口（expanding，最少 250 个样本）只作为敏感性对照，不作为主判据。

### 2.3 宽度分母：全市场含 ST 与 strict 洁净集

| 口径 | 用途 | 分母 | 落地文件 |
| --- | --- | --- | --- |
| 全市场含 ST | **本模型宽度层** | `quotes/stock/**` 全部有成交个股，含 ST，剔除旧码、上市不足 60 交易日、当日无成交 | `data/local_store/meta/breadth/breadth_ma_daily.parquet`、`breadth_daily.parquet` |
| strict 洁净集 | 选股 / 回测可交易池 | 在 standard 之上再要求当日因子可用、剔除除权事件存疑等 | `src/data/quality/clean_set.py` 的 `eligible_set(..., tier='strict')` |

- 两者**不可混用**：宽度回答「全市场有多少股票在涨」，strict 回答「哪些股票可以买」。用 strict 池算宽度会系统性高估（剔除了 ST 与弱势标的）。
- `breadth_ma_daily` 的样本口径见 `tools/build_breadth_ma.py` 模块文档：含 ST、剔除上市不足 60 个交易日、当日无成交不进分母。

### 2.4 复权与基准

- 个股均线、250 日新高新低使用后复权价 `adj_close = close × hfq_factor`（`breadth_ma_daily` 口径）。
- 主基准指数：**中证全指 `000985.SH`**（覆盖全市场，避免上证指数权重失真）。风格对照备用：沪深 300 `000300.SH`、中证 1000 `000852.SH`、创业板指 `399006.SZ`。
- 指数成交额用 `000985.SH` 的 `amount` 作为「全市场成交额」代理；严格全市场成交额需逐股聚合，本模型 v1 不做，差异写在第 6 节。

### 2.5 层权重（待检验的建模选择）

| 层 | 权重 | 理由 |
| --- | --- | --- |
| 趋势 | 0.30 | 方向是第一位的，权重最高 |
| 宽度 | 0.25 | A 股最有信息量的验证层 |
| 量价资金 | 0.20 | 决定行情能否持续 |
| 估值宏观 | 0.15 | 赔率与背景，不负责精确择时 |
| 波动情绪 | 0.10 | 风险与情绪验证，避免与宽度重复计分 |

权重是建模选择，不是上涨概率；同一层内高度相关的均线指标已做删减，避免重复加分。

## 4. 合成与状态标签

### 4.1 指标得分

对每个指标：

```
q = 滚动分位（0~100）
score = direction × (q - 50) / 50        # direction = +1 或 -1，落到 [-1, 1]
```

### 4.2 层得分与贡献

```
layer_score = Σ(指标权重 × 指标得分) / Σ(有效指标权重)
layer_contrib = layer_weight × layer_score
```

- 某指标缺失（无有效分位）时，该指标不参与层内加权，层内权重重新归一化。
- 某层全部指标缺失时，该层不参与总分，层权重重新归一化。
- 缺失只跳过，不填充、不插值、不用其它层替代。

### 4.3 总分与五档标签

```
total = Σ layer_contrib（层权重已按可用层归一化）
```

标签阈值来自来源文件「十分制模型」的 8~10 / 6~7 / 4~5 / 0~3 分档，线性映射到 `[-1, 1]`：

| 总分区间 | 标签 |
| --- | --- |
| `total ≥ 0.60` | 强趋势上行 |
| `0.20 ≤ total < 0.60` | 弱上行 |
| `-0.20 < total < 0.20` | 震荡 |
| `-0.60 < total ≤ -0.20` | 弱势下行 |
| `total ≤ -0.60` | 强下行 |

- 阈值是分档映射，不是校准后的上涨概率；必须用滚动样本外回测校准后才能改。
- v1 不额外加「跌破 200 日线强制弱势」等硬规则：本地没有 B200 表，且绝对阈值与本方法「一律滚动分位」的口径冲突。需要时先补 B200 数据并单独成单。
