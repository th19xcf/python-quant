## 一、结论摘要

**一句话：这批持仓赚到的钱，几乎全部能用市场 beta 解释，选股 alpha 在统计上是 0；扣掉换手成本后 alpha 全部为负。所谓"策略收益"主要是"少仓位 + 低 beta + 小盘/中盘暴露"的组合结果，不是选股能力。**

四个可直接引用的数字：

1. **市场 beta 显著但远小于 1**：short 0.311 / mid 0.434 / long 0.611（EW；VW 为 0.316 / 0.462 / 0.630），t 值 11.2~15.5。**换算成满仓口径（β ÷ 平均仓位）仍只有 0.77 / 0.79 / 0.86** —— 说明不只是"钱没投出去"，选出来的股票本身就是低 beta 的。
2. **市场 alpha 全部不显著**：日频 alpha 分别为 −0.75% / −0.10% / +0.79%（EW），t 绝对值全部 ≤ 0.16（NW lag=1）。加上三个风格因子后，**残差 alpha 是 −0.65% / +0.04% / +0.41%**，|t| ≤ 0.14。R² 从 0.13~0.25 提到 0.15~0.34。
3. **收益主要来自市场 beta**：beta 项贡献毛收益的 64%~229%，风格净贡献 −40%~+11%，残差 alpha 占 −89%~+34%。换句话说，`long` 档 2.57%/年的毛收益里有 1.89% 来自 000300 的 beta，0.28% 来自小盘/中盘的净倾斜，0.41% 是残差（不显著）。
4. **扣换手成本后 alpha 全为负**：short −4.12%/−3.92%、mid −2.08%/−1.38%、long −0.28%/−0.15%（年化，EW/VW）。**long 档接近打平，short/mid 明确为负。**

**分年度看 beta 不稳定**：EW 口径 short 0.169~0.456、mid 0.199~0.613、long 0.320~0.863（VW 口径 short 最高到 0.502），同为最高/最低相差 **2.7 倍（long）~ 3.1 倍（mid）**。市场暴露随仓位与持仓漂移，不是被主动管理的常数。

**没有一年出现显著 alpha**：12 条（档位 × 口径）年度 layer1 回归与 12 条 layer2 回归里，年度 alpha 的 t 绝对值最大分别为 **1.12** 与 **1.14**，全部不显著。

## 二、口径（说明清楚，便于复核与复现）

| 项目 | 定义 |
|---|---|
| 组合收益频率 | **日频为主结论**（组合逐日市值加权收益，含现金），另给**调仓期频**（91 期复合）作稳健性对照 |
| 组合构成 | 每个调仓日的完整持仓（BUY + HOLD），权重取生产输出的 `weight`（占总权益），月内随价格漂移，下个调仓日重置 |
| 现金 | `cash = max(0, 1 − Σweight)`，收益记 0。短期档平均仓位 40.4%、mid 55.0%、long 71.1%，是 beta 偏低的第一个原因 |
| EW 口径 | 持仓内等权（`1/n`），再乘 `(1−cash)` |
| VW 口径 | 持仓内按 `total_mv`（`meta/financials/valuation_daily.parquet`）加权，缺失值用同档同期的中位数填补（实测 0 例需填补），再乘 `(1−cash)` |
| 因子收益 | 全部用**指数日线**：`000300.SH`（mkt）、`000905.SH`（中盘）、`000852.SH`（小盘）、`399006.SZ`（成长） |
| 风格因子构造 | **价差**：`r_905 − r_300`、`r_852 − r_300`、`r_399006 − r_300`。因此 `β_mkt` 是"相对 000300 的市场暴露"，三个风格 β 是"相对 000300 的规模/成长倾斜"，不是绝对因子暴露 |
| Layer 1 | `r_p = α + β·r_300 + ε` |
| Layer 2 | `r_p = α + β_mkt·r_300 + β_500·s500 + β_1000·s1000 + β_growth·sgrowth + ε` |
| 标准误 | Newey-West Bartlett 核，**lag=1 为主结论**，lag=5 作稳健性；t 分布用 `df = n − k` |
| alpha 年化 | `α_daily × 252`；月频为 `α_period × 12` |
| 无风险利率 | rf = 0（Jensen alpha 未减无风险利率；对差值结论无影响，对"是否跑赢存款"需另算） |
| 成分股基准 | **未使用**。本报告只用指数日线，不涉及成分股集合，因此用户提示的"年末区间表超计"（000300 推 328/快照 300 等）在本报告不构成风险 |

## 三、第一层：市场 beta（对 000300，日频，1,860~1,875 个交易日）

| 档位 | 口径 | **β_mkt** | t(β) | **alpha(年化)** | t(NW1) | t(NW5) | R² |
|---|---|---|---|---|---|---|---|
| short | EW | **0.311** | 11.35 | **−0.75%** | −0.152 | −0.165 | 0.162 |
| short | VW | **0.316** | 11.19 | **−0.30%** | −0.053 | −0.055 | 0.131 |
| mid | EW | **0.434** | 14.97 | **−0.10%** | −0.018 | −0.019 | 0.237 |
| mid | VW | **0.462** | 13.78 | **+0.88%** | 0.120 | 0.123 | 0.164 |
| long | EW | **0.611** | 15.53 | **+0.79%** | 0.103 | 0.111 | 0.232 |
| long | VW | **0.630** | 15.21 | **+0.82%** | 0.109 | 0.120 | 0.248 |

**读法**：

- **beta 全部显著小于 1**，且显著性很高（t>11），说明"低 beta"是稳定特征而不是噪声。
- 现金只解释了一部分。把 beta 除以平均仓位得到满仓口径 beta：short 0.311/0.404 = **0.77**、mid 0.434/0.550 = **0.79**、long 0.611/0.711 = **0.86**。这与生产配置的因子方向一致——legacy 因子除 `long.max_drawdown_20` 外全部 `direction=−1`（低动量、低量能、低偏离、低 RSI、低 ATR 得分高），天然选到低波动低 beta 的标的。
- **alpha 全部不显著，|t| ≤ 0.16**。mid EW 和 short 的 alpha 点估计为负，long 为 +0.8%/年，但在 NW lag=1 与 lag=5 下都稳定在 0.1 的 t 值量级——不能与 0 区分。
- **R² 只有 0.13~0.25**：组合日收益方差只有 13%~25% 能被 000300 解释，剩下是选股特质波动与现金。这是"beta 低 + 组合分散度低（short 平均 5.4 只）"的直接结果。

## 四、第二层：加风格 beta（000905 / 000852 / 399006 价差）

| mid | EW | 0.484 | **0.226 (2.33)** | **0.253 (3.47)** | **−0.186 (−4.74)** | **+0.04%** | 0.008 | 0.339 |
| mid | VW | 0.488 | 0.256 (1.77) | 0.077 (0.85) | −0.102 (−1.93) | **+0.74%** | 0.102 | 0.190 |
| long | EW | 0.650 | **0.369 (2.79)** | **0.276 (2.53)** | −0.169 (−2.03) | **+0.41%** | 0.056 | 0.324 |
| long | VW | 0.661 | **0.356 (2.78)** | 0.100 (1.02) | −0.125 (−1.58) | **+0.54%** | 0.073 | 0.289 |

（括号内为 NW lag=1 的 t 值；α 的 lag=5 t 值与 lag=1 同量级，最大差 0.008）

**读法**：

- **风格倾斜是真实存在且统计显著的**：short/mid/long 都**正暴露于中盘（000905）与小盘（000852）**、**负暴露于成长（399006）**。mid EW 的 `β_1000 = 0.253 (t=3.47)`、`β_growth = −0.186 (t=−4.74)` 是最强的一组。含义是：这批持仓不是"选出了好公司"，而是"系统性地买了比 000300 更小、更偏价值的股票"。
- β_mkt 从 0.311 升到 0.353（short）、0.434 升到 0.484（mid）、0.611 升到 0.650（long），R² 明显提高（0.16→0.22、0.24→0.34、0.23→0.32）。说明**加入风格因子后，收益被解释得更充分**，留给 alpha 的空间更小。
- **残差 alpha 全都更接近 0**：short 从 −0.75% 变成 −0.65%，mid 从 −0.10% 变成 +0.04%，long 从 +0.79% 变成 +0.41%。**控制风格后 alpha 没有变大，而是变小**——这是"没有选股能力"的直接证据。
- **不要逐条读单个风格 t 值**：三个风格因子都是 `指数A − 000300` 的价差，彼此以及与 β_mkt 存在共线性（月频回归里 long EW 的 `β_500` 跳到 0.720、t 只有 1.79）。可靠的是方向与量级：正小盘、正中盘、负成长。

## 六、扣成本后的 alpha

成本口径：`replacement_mean`（调仓期被替换的持仓比例）作为每期双边换手率，乘以 0.724%/期，年化 ×12。

| 档位 | 口径 | 换手（每期替代率） | 年化成本估计 | **毛 alpha(年化)** | **净 alpha(年化)** |
|---|---|---|---|---|---|
| short | EW | 0.399 | 3.47% | −0.65% | **−4.12%** |
| short | VW | 0.399 | 3.47% | −0.45% | **−3.92%** |
| mid | EW | 0.244 | 2.12% | +0.04% | **−2.08%** |
| mid | VW | 0.244 | 2.12% | +0.74% | **−1.38%** |
| long | EW | 0.079 | 0.69% | +0.41% | **−0.28%** |
| long | VW | 0.079 | 0.69% | +0.54% | **−0.15%** |

**读法**：

- **毛 alpha 本来就是 0，扣成本后必然为负**。short 每年付出约 3.5% 的换手成本去换取 −0.65% 的毛 alpha，净结果是 −4.12%；mid 每年付 2.1% 换 +0.04%，净 −2.08%。
- **long 档最接近打平（−0.28% / −0.15%）**，原因是它换手极低（每期仅 7.9% 持仓被替换），不是因为它有 alpha。
- 这与前向检验的结论一致：`short h=60` 净收益差 −4.438%（t=−2.589）在方向与量级上都和这里的 −4.12% 净 alpha 对应；`long h=60` 的 Δ净收益 +0.048%（t=0.017）与这里的 −0.15%~−0.28% 也对应得上。

**读法**：

- 月频 alpha 的 t 值**比日频还小**（最大 0.21），方向也不稳定（long 在月频 layer2 变负）。**频率选择不影响"alpha 不显著"这一结论**。
- 月频 β_mkt 的点估计普遍比日频高（short 0.38 vs 0.31、long 0.71 vs 0.61），但**估计精度大幅下降**（t 从日频的 11~15 降到 4~5）。91 个观测下 0.05~0.10 的 β 差异在小样本噪声范围内，不足以判定"结构性差异"；两种口径的共同结论是 **β 显著小于 1**。
- 月频 n=91，**有效独立样本就是 91 个调仓期**，这是全报告最强的独立性口径。日频 1,860~1,875 个观测因持仓期内重叠而高度自相关，NW lag=1 已处理残差序列相关，但本质上仍是一条权益曲线，因此**主结论以"日频 NW + 月频同向"双口径同时成立为依据**，不以日频自由度为准。

## 十、数据口径与注意事项

1. **未用成分股自建基准**，只用指数日线。用户提示的"年末成分区间表超计"（000300 推 328/快照 300、000905 推 550/500、000852 推 1,100/1,000、000016 推 55/50）在本报告**不适用**，因为本报告没有任何一步按区间表推导成分集合。
2. **风格因子是价差（指数A − 000300）**，不是绝对收益因子。因此 `β_500` 应读作"相对 000300 的中盘倾斜"，不能直接和 Fama-French 的 SMB 对比。
3. **指数日线取自本地** `data/local_store/quotes/index/{sh,sz}/`，四只指数在 2019-01-02 ~ 2026-11-09 全覆盖，未做外部源对拍。若指数序列存在跳变，会同时影响因子收益与 alpha 的绝对值，但"组合收益扣除 beta 与风格后还剩多少"这一对照关系不受影响。
4. **α 未减无风险利率**。若按 1.5% 的年化无风险利率，所有 alpha 还要再减约 1.5%，结论只会更负。
5. **幸存者偏差**：持仓来自本地现存标的清单，已退市标的不在池内，绝对收益因此偏高；但 beta/alpha 的偏误方向不明（幸存标的通常 beta 更低、质量更好）。
6. **权重漂移近似**：月内权重随价格漂移、下个调仓日重置，与生产 `weight` 的原始定义一致；未建模分红再投资与拆股以外的公司行为（后复权价已含分红与拆股）。
7. **成本是估计值**：用 `replacement_mean` 单边替代率 × 0.724%/期，未区分买卖方向与冲击成本的规模效应，是保守下界（实际冲击成本随规模上升）。
8. **日频观测不是独立样本**：1,875 个日收益来自 91 条调仓期持仓，同涨同跌。NW lag=1 只修正残差自相关，不改变"有效样本约 91"这一事实。**任何 |t|<2 的日频结论都不应被当作"接近显著"。**
