# 个股端动量回测协议（草案 · 未开跑）

- **日期**：2026-11-05
- **状态**：方案文本，**不执行任何回测**；等用户 `go` 后按本协议启动
- **上游依据**：ETF 动量轮动已定案弃用（`docs/ETF动量轮动基线结论_2026-11-05.md`），本协议把该线踩过的坑全部前置写明
- **原则**：口径先写死、再跑数；样本外只跑一次；净收益为准

---

## 1. 目的与边界

用个股（A 股全市场，非 ETF）做 12 个月动量 + 趋势过滤的月度轮动，验证它是否具备成为主策略的资格。

边界：

- 只读 `data/**`；**不读 `quotes/**` 的实时写入段**（另一任务正在补行情与因子，先确认 `meta.json` 的 `updated_at` 早于当前时间再读 `factors/`）；
- 不做空、不加杠杆、不做 T+0；
- 所有参数在样本内定死，样本外只跑一次，跑完不回改。

## 2. Universe

### 2.1 主口径：`clean_set` 的 `standard` 档

- **as-of 2026-11-04 三档池厚（当前口径）**：个股 `full / standard / strict` = **5,572 / 5,376 / 4,770**；全部类型 = **9,030 / 8,834 / 6,054**。
  - 对照 as-of 2026-11-03：个股 5,570 / 5,378 / 4,772；全部类型 9,093 / 8,901 / 6,055。
  - 11-03→11-04 的 standard/strict 各 +1 来自 `302132.SZ` 因子快照 15:25:09 落盘后由 `structural_factor_bad` 转可用，与 universe 重建无关。
  - 旧值 `5,377 / 4,769` 属 11-03 前口径，已作废。
- 定义：`full`（当日有行情）再剔除**结构性缺陷**（无本地行情、内容不一致、重复除权键、因子缺失/不可逆）与**当日 ST**；容忍因子末端滞后与历史缺口。
- **为什么不直接用 `strict`**：

| 问题 | 说明 |
|---|---|
| 永久剔除配股存疑 | `strict` 一旦标的出现过"无独立第二源"的配股，**其后所有日期都不再进入**。这是核验口径，不是策略口径：会把一批与动量无关的标的永久踢出，且早期老代码事件更多 → 早期保留率系统性偏低，等于在时间维度上制造选择偏差 |
| 因子核验 pending 连带剔除 | 因子可逆性/事件匹配 pending 属于"数据未核验"，不是"数据不可用"；用它做 2015 年截面判定，等于用 2026 年的核验结果筛 2015 年的股票（**前视**） |
| 池厚 | `strict` 个股 4,770 只，比 `standard` 少 606 只；动量策略需要足够厚的池降低 Top-N 集中度 |
| 基金 pending | `strict` 基金为 0（分红口径未定），本协议只做个股，不受影响，但说明 `strict` 不是"更干净的全市场" |

> 结论：主口径用 `standard`（5,376 只，as-of 2026-11-04），并把"历史缺口/停牌"显式处理（§2.4）。`strict` 只作一次敏感性对照，不参与判定。

### 2.2 ST

- 用 `meta/st/st_intervals.parquet` 的**区间**判定：命中当日即当日不可选；摘帽后自动回归，**不做永久黑名单**。
- 区间覆盖不到的日期返回 `unknown`，默认放行并标记；不编造历史 ST。
- `suspected_st` 默认不参与剔除（当前快照 0 只）。

### 2.3 上市满 N 日

- 动量窗口 252 日 + 缓冲 20 日 ⇒ **上市满 272 个交易日**（约 13 个月）。
- 同时要求窗口内**有效行情行 ≥ 250**（缺口率 ≤ 1%），避免长期停牌股用"补出来的"动量入选。
- 有效行判定：该日存在行情行且 `vol > 0`（停牌/零成交行不计）。

### 2.4 流动性与缺口

- 主口径：**ADV20（近 20 个有效交易日成交额中位数）≥ 5,000 万元**。
- 敏感性：2,000 万元 / 1 亿元两档，只用于稳健性，不参与判定。
- 缺口处理：滚动窗口内缺行**不 ffill 价格**；动量用"窗口内实际收益"（首末有效收盘），若有效行 <250 则该标的当日不入选。

### 2.5 复权

- 信号与净值一律用**后复权**序列（`factors/stock_adj_factor.parquet` 的 `hfq`），不用 `quotes/*` 里的前复权副本。
- 成交价用**当日原始开盘价**（未复权），并按"hfq/raw 比例"换算股数，保证同一笔成交的价格口径一致；**禁止在同一笔成交里混用前复权价与原始价**。

## 4. 信号与成交

| 环节 | 规则 |
|---|---|
| 信号时点 | T 日**收盘后**计算（只用 T 日及之前的数据），生成 T+1 的目标组合 |
| 成交时点 | **T+1 开盘**成交；禁止用 T+1 收盘、T+2 开盘或任何未来价 |
| 涨跌停（买） | T+1 开盘价相对 T 日 `pre_close` 涨幅 ≥ 板块限幅 ⇒ **不可买**，顺延至下一可成交日 |
| 涨跌停（卖） | T+1 开盘价相对 T 日 `pre_close` 跌幅 ≥ 板块限幅 ⇒ **不可卖**，顺延 |
| 板块限幅 | 主板 10%、创业板/科创板 20%、北交所 30%、ST 5%（ST 需叠加 §2.2 区间） |
| 停牌 | T+1 无行情行或 `vol = 0` ⇒ 不可成交；订单保留，最多顺延 **5 个交易日**，超时撤销并记入 `failed.csv` |
| 退市 | 按**真实末行**强制结算（117 只已补数）；若末日 `amount/vol` 为 NULL 视为**不可成交**，只能按最后有效收盘估值结算，并在日志单独标记 |
| 撮合守恒 | 每日校验 `现金 + Σ(持仓×收盘) = NAV`（误差 <1e-8）；成交额不得超过当日该票成交额 |

**防未来函数的三条硬检查**（结果文件必须附）：

1. 信号日与成交日必须严格 T / T+1，逐笔可审计；
2. 调仓日志里的每个价格都能在行情文件中按 (code, date) 命中；
3. 任何用到 `pre_close` 的判定，`pre_close` 必须来自 T 日或更早。

| 项 | 口径 |
|---|---|
| 佣金 | 双边 0.05% |
| 印花税 | **卖出单边 0.05%**（按用户指定）；分时段敏感性：2023-08-28 前按 0.10%、之后 0.05%（差异约 0.05pp/年，按年换手 2x 计） |

| ADV20 | 滑点 |

## 6. 风控（只保留一层）

- **默认叠加波动率目标**：日收益 60 日实现波动 ×√252，取 **t-1 及之前**数据；仓位 `min(1, 12%/实现波动)`，**不加杠杆**。
- **下界：放开**（实现波动不设 15% 上限，暴露最低约 0.48）。理由：ETF 版实测"放开下界"是唯一同时改善回撤深度与水下时长的改造（8.21% / -20.95% / 39 月），而带上界（暴露 ≥0.80）只能把回撤压到 -36%。个股波动更高，若只放开不设任何下限，极端行情下会出现"名义空仓"，因此加两条护栏：
  - 暴露硬下限 **0.30**（低于此值按 0.30 执行，防止流动性枯竭期完全退出）；
  - 单日暴露变动 ≤ 10pp（死区），防止抖动带来的额外换手。
- **明确禁用**：
  - **回撤刹车**：ETF 版实测净收益 8.17% → 1.50%、水下 51 → 61 个月，负反馈；
  - **类别权重上限**：3 持仓下退化成降杠杆（平均暴露 0.51），不是分散。
- 单票上限：**5%**（配合 N=20）；不做行业/板块上限（会重蹈类别上限的覆辙）。

**空量停牌行的库内惯例**：本库默认不保留空量停牌行，**停牌日无行属正常，不是缺数据**。全库 5,812 只股票行情中，含 `volume=0/amount=0` 行的只有 254 只（4.4%）、合计 5,707 行，其中 118 只已退市或长期停牌；仍在交易到 2026 的只有 136 只、269 行。抽查 `002129.SZ`（10/29–11/04 三根空量）、`688121.SH`（10/29–11/04 五根空量）、`000016.SZ`（9/4–10/22 三十一根空量）均与本地无行一致。254 只带 0 量行属历史遗留例外，不构成惯例；`605081.SH` 的 4/30–6/5 共 27 天本地本就为 0 行，与其自身历史口径自洽，不补。

**`pe_static` 留空说明**：`valuation_daily` 对 2019-09-18 后的 103,817 行 `pe_static` 保持为空；本地财务三表（`income/balance/cashflow`）对这 117 只均为 0 行，拿不到归母净利润/年度 EPS，baostock 的 `eps` 字段为空、仅有净利润合计口径，属推导/拼接来源，按“不编造”原则不使用估算填充。

**退市标的财务三表缺口**：117 只 2019-09-17 截断标的在 `income` / `balance` / `cashflow` 中均为 **0 行**（全表 5,608~5,611 只均不含这批退市票）。影响：凡依赖财务报表的因子（`ff_value_ep`、`ff_sales_yield`、`ff_investment` 等）在这批标的上无值，回测中只能按“缺失即剔除”处理。边界：baostock 对这批只返回 `netProfit`（净利润合计，非归母）且 `eps` 为空，口径与东财“归母”不一致，**不做估算填充**。结论：这是外部数据条件不具备，不是本地漏采；`valuation_daily` 的 `pe/pb/dv_ratio/total_mv/circ_mv` 已由本次补数解决，财务类因子仍缺。

**由缺口直接产生的三条限制（写进报告，不许省略）：**

1. 退市段（117 只）2019-09-18 后已补估值与换手，但 23 只股本用最后已知值近似，且 2015-2017 无估值 → 市值加权基准在退市股段可用但须标注近似范围，不得声称精确；
2. 2015-2017 无 `valuation_daily` → 样本内调参若用到市值/估值因子，只能从 2018 起，**2015-2017 的调参结论不可外推**；
3. 停牌靠"无行"推断，会把"本地缺行"误判为停牌 → 必须在报告里给出缺行率与受影响标的数。

## 8. 验收标准（写死，不事后调整）

| # | 维度 | 门槛 |
|---|---|---|
| 1 | 收益 | 年化净 **≥10%** |
| 2 | 风险 | 最大回撤 **≤-20%** 且 最长水下 **≤18 个月** 且 Calmar **≥0.5** |
| 3 | 超额 | 相对基准超额 **≥5%** 且 IR **≥0.5** 且 α t **≥2** |
| 4 | 稳健 | 样本外净 **≥8%** 且 衰减 **≤40%** 且 ±20% 参数扰动不塌方（最差组合净 ≥6%） |
| 5 | **换手与容量** | 单票单日成交额 **≤ ADV20 的 10%**；组合月换手 **≤40%**；年换手 **≤8x**；超限即视为不可实施 |

**第五条的执行细则：**

- 容量：按"计划成交金额 ≤ 0.1 × ADV20"逐票检查，超出部分按比例缩量，缩量后再校验组合权重偏离；
- 换手：用缓冲带控制（持仓排名跌出 **2N** 才卖，进入前 **N** 才买，N 为持仓数），而不是靠"少换"硬压；
- 报告必须给出"被容量约束削减的成交占比"，>20% 即说明该策略容量不足。

> 以上五条全过才算"可留用"；任一条不过即进入"可考虑/弃用"二分，不允许用"综合评分"模糊化。

**① 回撤是否达标**：**是（IS −16.99%）**，但它是用 0.20 暴露上限换来的，代价是水下 91 个月、Calmar 0.13，风险维度整体仍不达标。

**② 收益与超额**：IS 净 +2.22%、毛 +2.62%；相对 EW 超额 **−12.77%**、IR −0.45、α t 0.33。收益、超额两项均远不达标。

**③ 做不到 10%，上限与卡点**：在"回撤 ≤20%"约束下，可达到的上限约 **IS +2.2%~+2.8%**（±20% 扰动中 IS 最高为 N−20 的 +2.77%；ALL 区间最高 +1.13%）。卡点有两层：

1. **信号层：A 股 12 个月动量本身是负边际**。同一面板实测：动量 Q4−Q0 年化 −1.30%；Top20 次月平均 +0.17%，而 EW 全市场 +1.50%；12−1 动量 +0.567%；反而是低波动 +1.107%/月、高波动 −1.013%/月。动量方向选错，风控只能压波动、压不出 alpha。
2. **约束层：20% 回撤上限 vs 全市场自身 −52.44% 的 IS 回撤**。等权全市场 IS 年化 +12.14%，但最大回撤 −52.44%；要把回撤压到 20%，暴露只能给到 0.2~0.38 倍，理论上限约 4.8%（12.14% × 0.38），再扣 0.36~0.39pp 成本，**在"无 alpha 的纯 beta 暴露"下上限即 ~4.5%**；实测策略 beta 仅 0.105，连这部分 beta 收益也没拿到（暴露 0.20 且选股偏离基准），所以只剩 2.2%。

**明确不做的三件事**：不放宽 20% 回撤阈值、不删 OOS 段、不为凑 10% 调参与口径。若要把收益做上去，方向只能是**换信号**（低波动/质量/反转）或**引入真正的 alpha 源**，而不是继续在这条 12 个月动量线上调参；但那已超出本协议范围，需另开协议。

### 13.6 必须逐条披露的口径缺陷

**13.6.1 行业分类非 PIT（影响无法量化、无法修复）**
`industry_20261105.parquet` 是 **2026-11-05 单快照**。回测 2015 年时，用的是"2026 年的行业归属"给 2015 年的股票分组。它同时污染两处：(a) 行业中性化里的行业哑变量（本阶段 A/A2 的中性化直接使用）；(b) 若构建"行业相对强度"因子也会同样漂移（本阶段未把它作为独立因子）。**影响方向不确定、幅度无法量化，且在本库现有数据条件下无法修复**——不能写成"轻微"，也不能用"行业中性化已消除"来辩解：中性化消除的是当期行业均值，消除不了"当期行业标签本身来自未来"这一事实。IC 实测文档（`docs/因子有效性实测_2026-11-05.md`）中的行业中性化版本同样受此影响。

**13.6.2 行业 unknown 的 234 只（4.03%）**
- 规模：**234 只 / 5,812 只 = 4.03%**；行数 **15,178 / 485,894 = 3.12%**。
- 处置：**不跳过，归入独立的 `unknown` 行业组**，与 13 个已知行业并列参与行业去均值与市值中性化。
- 是否系统性偏向：在"行业去均值"这一步，unknown 组只与同组股票比较，不会被已知行业的均值带偏；但它们与已知行业之间的可比性缺失，等于默认"unknown 内部同质"。这不会给 unknown 组整体加上固定偏好，但会改变其组内排序的参照系。**无法进一步量化**，此处如实标注，不声称无偏。

**13.6.3 2015-2017 股息率用事件法，不许向前填充**
- 2015-2017：`stock_dividend` 的 `ex_date/cash_div` 事件法，滚动 365 天（`ex_date ∈ (t−365d, t]` 的现金分红合计 / 当日 `raw_close`）。
- 2018 起：与 `valuation_daily.dv_ratio` 口径一致（2020-06-30 截面相关 **0.99999**、中位比值 **1.0**）。
- **没有使用任何向前填充**；无分红事件记 0，不是缺失。事件法依赖分红事件表完整性，已知该表存在漏记（§7），因此 2015-2017 的股息率仍有事件漏记风险，方向未知。

**13.6.4 `history_rows` 前视已排除**
截断审计 38/38 命中前视（`history_rows` 本质是"截至当日的历史行数"，在月末截面上等价于未来信息）。本阶段 `FACTORS` 字典**不含 `history_rows`**，A/A2 合成分数均未使用；它只出现在上游分析面板的列清单里，未进入打分。

**13.6.5 换手与 20% 上限**
A 组 IS 单边换手 **2.940x/年（约 24.5%/月）**，20% 月度上限**几乎每月都触顶**，实际执行的是"先整只退出、预算不足则延后退出，新进按 expo/N"，因此 A 组的收益是在"被 20% 上限持续约束"下取得的，不是无约束结果。年成本 2.03pp（净毛差 2.19pp 年化）。**这是本阶段最重要的可实现性约束**：若放开上限，毛收益会更高但换手/成本同步上升，净收益未必改善。

**13.6.6 规模暴露**
组合分数与 `ln_mv` 的月度 rank 相关均值 **+0.069**（绝对值均值 0.081）。即组合**轻微偏大市值**（约 7%~8% 秩相关），规模因子未单独入选，但通过中性化残差与因子相关性仍残留这一暴露；比例很小，不能解释收益差异。

**13.6.7 阶段 1「IS 净 +2.2238% / 单边换手 0.544x」复核**
- 定位：该数字对应 `reports/stock_momentum_20261105/runs/base_net/`（全库池、`capped_inv_vol` 权重、暴露死区，**引擎内没有 20% 换手预算这一段代码**）。
- 实测（`trades.csv` + `daily_nav.csv`，IS 2015-01~2022-12）：79 个有成交月份，**单边换手 >20% 的月份为 0 个**；最高 **17.8%**（2015-02 首月建仓，非稳态），次高 13.4%，均值 **5.44%**。
- 结论：**已复核、20% 换手预算从未触顶**；换手缩放 bug 不适用于该运行，**+2.2238% 不作废、无需重跑**。

### 13.7 要"净 10%"需要多少 α

以 A 组 IS 回归为基准：EW 全市场 IS 年化约 **14.53%**（由 A 净 0.37% + 超额 −14.16pp 反推），β≈0.283。要净 10%，需年化 α ≈ 10% − 0.283 × 14.53% ≈ **5.9pp**；当前 IS α 为 **−3.53pp**，缺口约 **9.4pp**。若换 000300 基准，β≈0.368、基准 IS 年化约 3.0%，需 α≈8.9pp、当前 α≈−0.55pp，缺口约 9.5pp。**两套基准结论一致：缺口在 9pp 量级，不是靠调参能补的。**
