# 前向记录：收窄版「不买名单」剔除（drop vs keep）

> 起始 2026-12，只记录不优化。分组口径在 2026-11-28 冻结，之后不改规则、阈值与字段。
> 回测依据：`../收窄版重跑.py` / `../result_narrow.json`；冻结说明见 `../预注册.md`。

## 一、记录什么

每周最后一个交易日收盘后，把**可交易池**按两条规则分成两组，记录**每只股票**下一周的持有收益：

| 组 | 定义 |
|---|---|
| `drop` | 命中 R1' 或 R3 任一（被剔除） |
| `keep` | 两条都不命中（留下） |

- **R1' 短期超买**：`BIAS12 = 收盘 / 12 日均价 − 1 > +10%`。只用 BIAS12 单条件，不含预注册版 R1 里的「5 日涨幅 > 10%」与「RSI14 > 70」。
- **R3 高换手**：20 日平均换手率处于**当日池内最高 20%**（`turn20` 的池内百分位 > 0.80）。
- 可交易池：沪深 A 股（不含北交所、B 股），按信号日状态剔除 ST/\*ST、退市整理期、上市不足 60 个交易日、当日停牌、当日一字涨跌停、前 20 日停牌超过 5 天、20 日平均成交额 < 5,000 万元。含退市股。

## 二、字段（`records.csv`）

| 字段 | 含义 |
|---|---|
| `date` | 信号日：该自然周（ISO 周，按 000300.SH 交易日历）最后一个交易日 |
| `ts_code` | 股票代码 |
| `group` | `drop` / `keep` |
| `ret` | 下一周持有收益（后复权）：信号日后第一个可买 bar 的开盘价买入 → 下一信号日后第一个可卖 bar 的开盘价卖出；停牌或一字跌停顺延到之后第一根可卖 bar；退市按最后收盘价 |

- 每期收益差：`diff = mean(ret | drop) − mean(ret | keep)`（两组等权，与回测同口径）。
- `ret` 为**毛收益**，不含成本；成本敏感性见 `../result_narrow.json`（21.9 / 35 / 50bp 三档）。

## 三、运行与幂等

```powershell
.venv\Scripts\python.exe work\不买名单剔除_2026-11-26\前向记录.py
```

- 每次重算**所有已成熟周**，按 `(date, ts_code)` 覆盖同键旧行，不清除其它周；重复运行结果不变。
- 成熟判定：该周池内 ≥90% 的股票已能算出下周收益（下周入场日已存在且有行情），否则整周跳过，下次运行自动补上。
- 当前（2026-11-28 建库）本地行情最新交易日为 2026-11-27，故文件只有表头；2026-12 起每周运行后逐周追加。

## 四、评估口径

- 积累 12 个月以上再评估；主判据沿用 RD-10：`diff` 月均值连续 12 个月同号且 Newey-West(lag=3) `|t| ≥ 2.0`，累计记录 ≥24 个月。
- 回测里同一口径（5.80% 基准、21.9bp）年化 +4.96%、超额 −0.84pp、t 0.36、DSR(N=10) 0.115：**未达显著**。前向记录的作用是验证这条过滤器在样本外是否仍成立，而不是继续调阈值。
- 已知限制：等权、不建模盘口深度与整手、不设资金规模；退市股按最后收盘价结算。
